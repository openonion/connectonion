# Why Granola uses semantic maintenance

Unstructured notes do not provide Jira's explicit project/reporter/assignee
identities. Mandatory project binding would move organization work to the user.
Init inventories only approved snapshots; the existing whole-notebook Maintain
turn searches and organizes semantic pages. Note-specific source instructions
retain uncertainty, and existing project-writer/cooling protections are enforced
at promotion so broad organization cannot overwrite a protected page. Exact
source-qualified citations retrieve newer versions during Investigate without
requiring the page title in every note. This is retrieval, not entity identity.

A Reader citation must use numbered source definitions. The observed inline
free-form spelling is normalized only for this source's pinned local imports;
canonical records and shared page templates are unchanged. Source collection
remains separate and read-only. See the acceptance record for measured limits.
