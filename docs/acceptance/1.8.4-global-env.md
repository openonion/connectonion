  ordinary settings, project-only keys, whole process records, custom global directory,
  invalid selectors, and a valid selector with malformed global configuration.
- Google/Microsoft refresh preserves omitted fields, never writes inherited process
  credentials over a saved account, rejects a concurrent account change, and reuses a
  valid refresh from another process. The two-process test also checks unrelated saves.
- Six provider clients accept missing scope metadata without inventing permissions.
  Known missing scopes and broker/provider errors remain distinct. Microsoft refresh-only
  records recover; new consent removes the prior account's metadata.
- Auth, identity and diagnostics select the same source. Global initialization rejects
  a project-env selector. Deployment transports the selected app settings and points
  the remote runtime at its own identity.
- Full offline candidate verification is recorded in the PR after completion.
