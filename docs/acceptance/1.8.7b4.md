- 10,848 offline tests passed, 30 skipped, using the release marker selection and four workers.
- 60 Wiki CLI tests passed with forced ANSI color; the full suite verifies plain output as well.
- 13 clean-wheel installation tests passed.
- uv lock check, wheel/sdist metadata checks and release visual manifest passed.
- Docs lint passed with 162 existing warnings, blog checks passed, production build passed using the supported webpack option (the local shared node_modules symlink prevents Turbopack), and generated blog metadata/build checks passed.

the SSH fixture issue. It was retained as a failed attempt; after correction the
suite ran with loopback access and passed. No production credentials or keys
were generated by the corrected fixtures.
