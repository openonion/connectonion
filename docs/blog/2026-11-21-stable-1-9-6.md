# 1.9.6 is stable

`pip install connectonion` now installs 1.9.6. Forty-eight release candidates
fed it. It is rc48's code, unchanged.

## What changes on day one

Before, `co init` set up an identity and stopped. Now it also leaves a Host
running:

- launchd on macOS;
- a systemd user unit on Linux;
- a Scheduled Task at logon on Windows.

`co host` shows that Host. One line in `~/.co/runtime/host/.co/host.yaml`
(on a Mac, `mac-host`) decides who answers it:

```yaml
model: claude-code            # the Claude Code you are logged into
model: claude-code/<model>    # a specific Claude model
model: codex                  # native Codex
model: co/gemini-4-hydrogen   # the co-ai agent on a managed model
```

Changing that line needs no API key and no change to the front end. The first
deployment depends on exactly this: a team whose agents answer through their
own Claude Code accounts.

If you only wanted keys and skills, run `co init --no-host`. A machine with no
user service manager, such as a container, a CI runner or an SSH login without
linger, gets the same setup with the Host step skipped, and `co init` says so.

## What else is in it

- **REM's new desk.** The reader is redesigned. Tags join pages into a
  knowledge graph. Three privacy levels cover every place a passage shows.
  Hand-offs to Codex and Claude run where you can watch them.
- **Files between agents.** `co send` and `co receive` move files between
  agents, checked by sha256, and an interrupted send resumes.
- **Local history.** `co wechat` reads your own WeChat for Mac history,
  read-only. WhatsApp can link by pairing code.
- **Windows hosts work end to end.**

The full list is in the [1.9.6 notes](../releases/1.9.6.md).
