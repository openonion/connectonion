# The repair that guessed

The owner's rule about pronouns is short: never guess one. The code that enforced it guessed.

It replaced a pronoun with "the user" when the nearest name before it in the sentence was the user. On a page about a former intern that turned "the user was her direct manager" into "the user was the user's direct manager", and "submitted her reference" into "submitted the user reference". The nearest name is not the referent; English puts the object after the verb. The fix is narrower and says less: only he, his and she, never her or him, and never the form the page itself uses for its subject ("Avery said she"). It now misses more and invents nothing.

The same day's upkeep test found a worse loss. Replaying real extraction notes into one-page upkeep, three reruns per arm, a page with twelve quotes came back with none, and lost its First contact. Upkeep promoted a rewrite as if it were a first investigation: nothing compared it with the page it replaced. Enrich and muse already carried the old page through promotion and asked for every dropped quote and source back; upkeep now does the same. The First contact was lost for a smaller reason: the line that puts a contact date back over `Unknown` did not recognise a date followed by "(earliest mail found)".

Project pages got their own quote round, and the first version made them worse: the edit was given only the owner's messages, so the claim audit refuted every section that cited the repository, and the edit was undone four times out of six. It now carries the whole first-write material.
