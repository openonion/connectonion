# The owner's page kept a heading meant for someone else

A fresh first run of `co rem init` finished with a clean report. The owner's
own page was written, the checks said nothing was wrong, and then the page
opened on a section called "How the user writes to them", filled in with
Unknown.

That heading is for a person you write to. It is where the notebook records
that you open with "你好" and sign a certain way. On the page about you, it
has nothing to point at. One real owner page had answered it "Not applicable",
which is a heading for a blank.

The prompt already told the writer to leave the section off, and the list of
sections an owner page must have already left it off. Neither of those is a
check on the page that comes back. The normaliser treated every extra heading
as something to keep, and the review only asked whether each required heading
was present once. Unknown under a heading the page was not supposed to have
was still a valid page, so it was saved.

An empty answer can go. Unknown, Not applicable, and a blank line are the
scaffold saying "nothing here", and the promotion removes that section before
the page is kept. A section that actually says something, or cites a message,
is a different problem: those words were found somewhere, and deleting them
to make the heading disappear would hide the finding. That page is refused,
the candidate is kept, and the detail has to move into a section the owner
page does have. A page about someone else is unchanged, and still carries the
heading.

The lesson is the one the prompt could not teach. A section the owner page
must not have is a property of the page that gets saved, not of the
instructions that asked for it.
