# Three matches, zero retained evaluations

In an invented phone trial, the `invoice-check` Skill page said it had three
recorded invocations. Farther down, Run evidence said zero observed invocation
attempts. A reader had opened one page and found two apparent answers to the
same question: had this installed Skill run?

Both numbers could be right. The first counted coding-session attempts matched
by the Skill's name. The second counted retained evaluation attempts for that
name. Neither identified which installed copy ran, and neither said the
requested work succeeded.

The distinction was hidden in the implementation. A reader saw “recorded
invocations” beside an installed file and could reasonably take that as a
verified history of this copy. On a phone, the explanation sat below the full
memory, long after the number. The original `Run evidence` line also said
“invocation attempts,” giving two different scopes nearly the same name.

The reader now calls the first number **skill-name matches** and says
“version unverified” beside it. The sentence below the count names the two
scopes before the page's main finding. The eval collector calls its own number
**retained evaluation attempts**. Its records remain available in Full memory;
zero there no longer appears to contradict three name matches above.

The phone review exposed a second consequence. Adding the explanation pushed
the mapped page's investigation command below the first 812 pixels. Moving
**Copy investigation command** into the lead card put its 44-pixel action at
y603–647 in the final invented-page trial. All three Skills list names became
44-pixel links. A separately rendered written Skill kept its source actions in
the first screen. These measurements describe sampled layouts at 375×812 and
1440×900, not every notebook or a real Skill execution.

The product rule is that a number should name what was counted where the
number appears. When evidence for a narrower claim lives elsewhere, the page
should tell the reader that limit before inviting a conclusion.
