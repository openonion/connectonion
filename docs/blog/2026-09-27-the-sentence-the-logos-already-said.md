# The sentence the logos already said

For a few days the top of the README carried one careful sentence: *connect
your AI agent to your mail, chat apps, a real browser, your files and your
coding agents.* We had rewritten it several times. It was accurate, and every
clause mapped to a command.

Then we put the logo wall under it. Forty-one tiles, grouped as mail, chat
apps, browser and files, coding agents: Gmail's red M, WhatsApp, Telegram,
Chrome, Drive, Claude Code, Codex. The founder read the page top to bottom
and said the sentence was redundant. They were right. It had become a
caption for a picture sitting a few lines below it, and a slower one. A
reader recognises the Gmail logo before they reach the word "mail".

It is tempting to keep a line like that as insurance, in case someone skips
the image. But a reader who skips the image also skips the sentence above
it, and a reader who sees both reads the same thing twice at the moment
their attention is shortest. The wall already has alt text, which lists
every connection in words for anyone who cannot see it, and that covers
the case the sentence was insuring against.

So the README now opens with the name, the category and the wall, the
same order as connectonion.com and the docs home. The sentence has not gone
anywhere it still earns its place. It stays in the page descriptions that
search engines and link previews show, where there is no picture next to
it.

The lesson we keep relearning: when you add something that shows, go back
and cut what only tells.
