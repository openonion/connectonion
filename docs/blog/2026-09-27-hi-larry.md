# Hi Larry

The owner looked at their People list and asked a fair question. Every mail
has the other person's name on it, so why did 195 pages show only an email
address, like `larryleework7@gmail.com`?

We pulled the real headers. For 190 of those 195, the owner had written to the
person and never heard back, and the To line the owner typed held no name,
just `larryleework7@gmail.com`. A name only appears in the headers when that
person writes back. The map was reading the headers correctly. For these
people, the headers had no name to read.

We tried the address books next, because Gmail and Outlook both keep contacts.
The owner had saved none in Google. Gmail's automatic list held 385 people, 102
of them with a name, and those named 4 of the 195. Outlook's 128 contacts named
none. The APIs worked. The owner just doesn't keep an address book.

The name was in the mail the owner wrote. The first line of almost every one
was a greeting: "Hi Larry,", "Larry 你好，", "子明，". Gmail and Outlook
already return that first line as a preview when they list messages, so
reading it costs nothing extra. The map now takes a person's name from the
name they write under, then from a saved contact, then from the owner's
greeting in a mail sent to that one person. "Hi Larry," sent to three people
could mean any of them, so it names none.

We checked the result on the owner's real mailbox. 176 of the 195 now have a
name, and no name the map already had was changed. The greeting got names
right that the address could never give, for example `woo.woo.ter@gmail.com`
is Peter.

Two bugs turned up along the way. When a To line listed several people, the
map had merged two of their names into one. And the Outlook listing received
each recipient's name from Microsoft, then dropped it and kept only the
address.

Organisations had the same kind of noise. `accounts.google.com` and
`ad.unsw.edu.au` were each an organisation of their own, and so were 121
domains that only ever sent automated notices. Now a company's subdomains fold
into it, and a domain nobody real writes from gets no page. On the owner's
notebook that is 138 organisations instead of 269.
