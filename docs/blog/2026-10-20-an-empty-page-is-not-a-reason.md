# An empty page is not a reason

Left to choose for itself on a fresh copy of a real notebook, deepen picked three projects and one person. The projects grew between three and nine times. The person had sent five mails, and their page was almost empty, which is exactly why the picker chose them. A round on them added one quote. Twenty people who write to the owner far more often waited behind them.

The picker multiplies how much activity there is behind a page by how thin the page is. With both terms weighted equally, an empty page about nobody in particular could outrank a half-written page about the owner's co-founder. Now the activity term is squared. On the same notebook, the people it picks have 274, 55, 30 and 43 mails, and the five-mail person drops to sixtieth.

The first organisation it had picked was an event platform. Its only "person" was a one-way stream of registrations. An organisation whose people are all automated or one-way is now not a candidate. Its page still exists, because initialisation wrote it, but deepening won't spend a round on it.

A slot also stops starting new pages after an hour. One round on a long project history took about an hour by itself. Two such rounds in one slot would run into the next scheduled slot.

The rerun turned up one more bug, in the line restorer. A project page had a diagram in a code block, and one of its rows was just a down arrow, the letter "v". When the restorer looked for the writer's shortened copy of a lost line, it measured how much of each row appears in the lost line. A lone "v" appears in almost anything, so it scored a perfect match, and the lost quote was written into the diagram. There the page's quote check could not see it, so the page was refused. Now the restorer only matches rows outside code blocks, at least a third as long as the line it restores.

That bug also exposed a hole in the resting rule. The picker rests a page whose round changed nothing. But a round the review refused changes nothing too, and that says nothing about how much is left to find. The refused project would have been set aside for a month. Now a page rests only after a round in which both enrich and muse completed.

The rerun found one more over-correction. A person page already carried a broken quote: a name inside the quote marks had been turned into a link, so the text no longer matched any source. The writer fixed it by splitting it into two accurate, cited quotes. The guard treated the broken quote as lost and put it back, and then the quote check refused the page for that same broken quote, twice. A quote the page had that is not in its cited source is now not guarded. If the writer replaces it, the replacement stands.

The last hole was a leftover. Before the promotion-time guard existed, enrich and muse checked the page once more after saving it, and put the whole page back if a quote or source id was missing. With the guard in place, that second check could only do harm. It ignored the broken-quote exemption. It also compared against a page that had been renumbered when it was saved. On the rerun it quietly undid two rounds the review had accepted, one of which had three insights. The guard at promotion is now the only one.
