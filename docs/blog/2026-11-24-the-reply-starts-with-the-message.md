# The reply starts with the message

A meeting time can pass while a reply waits in Today. When the meeting already happened, the owner needs to mark the item done. When it still needs arranging, the owner needs the original request, their own calendar and a place to write. Seeing a prepared reply gives the owner enough context to choose between those paths.

We explored a calendar-first card and a letter-first card. The letter made a better default because it showed what the recipient would read. The calendar became useful once the owner chose to change the time. Putting every control in the draft menu saved space but hid the very action a person who had finished the work offline needed most.

The design therefore separates decisions about the item from decisions about the letter. Completion, deferral, ignoring and handing work to an agent belong to the item. Choosing a time or rewriting a sentence belongs to the draft. Offering a time says only that the owner can make it. The recipient still gets to decide.
