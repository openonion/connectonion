# The notes nobody wrote

The owner opened his notebook and asked a fair question: what is *Notes* for?

We counted. Every real notebook on the machine had the same thing in `notes/`:
three generated maps and one run report per installed skill — 157 files in the
1.9.0 acceptance notebook. Not one note. The category promised reflections and
held bookkeeping, so it read as noise.

1.9.1a1 gives the bookkeeping its own name, **Run logs**, and keeps `notes/` for
what the name says: the AI's own working notes, shown as **AI notes** once there
are any. Nothing is lost; old notebooks move the files on their next command and
the skill pages follow them.

The same preview widens the first map from 90 days to **180**. A quarter missed
the people you see every season but did not write to this quarter. Half a year
finds them, at about twice the mapping time.

This is the small half of 1.9.1. The large half is depth: a person's page is
still written after reading a few percent of the threads it was given. The next
previews investigate each page in rounds until its threads are read, then enrich
it from the company's own website and the PDFs in those threads.
