# The page retold what it could quote

A notebook page about a former intern said she had nominated the user for a reference, that the user submitted one early, and that a second reference was still waiting on a link. All true, all paraphrased. The mail it cited had the sentences the user would act on — the exact ask, the condition, the apology — and none of them was on the page. Across the notebook, 93 of 141 pages carried no quote at all.

The quote rule existed. It lived in the investigation skill, and the pages had been written before it, then kept by daily upkeep, whose skill never carried it. A rule that only one stage reads is a rule the notebook mostly ignores. It now lives in the page skills, which every stage that writes a page composes.

The same page said `First contact: Unknown` beside cited mail a year old. That was a decision, not an accident: the earliest retained mail does not prove when a relationship began. It was honest and useless, and worse, the claim audit refuted any date the writer did give, because code computed the last contact and not the first. Code now writes the earliest direct mail it read, marked `(earliest mail found)`, and puts it back when the audit removes a different date. The qualifier keeps the honesty; the date makes the field worth reading.

Some rules are better as code than as prose. Told "newest first", three of five pages still put one History line out of order. Sorting by date is a function; asking a model to sort is a hope.

We measured on a copy of a real notebook: five people and two projects, written from scratch as a first run would. Quotes per person page went from 6.8 to between 9.8 and 17.2 across four reruns, every one verbatim in its source. First contact went from 1 of 5 to 5 of 5, Uncertainties from 2 of 5 questions to 5 of 5. The spread between reruns on identical evidence is the next problem: a model that quotes seventeen times on one run and ten on the next has learned the rule, not the habit.
