# The default that costs twice as much

*2026-11-13*

The first idea was to make the most expensive Gemini 4 model the default, on the
theory that people judge a framework by its first answer. We did the sum before
the change. A ten-turn agent run that reads 200,000 tokens and writes 10,000
costs $0.19 on 3.8 Flash. On Carbon it costs $0.50 today and $1.00 from
December, before counting the extra thinking Carbon does: asked whether 221 is
prime at high effort, it spent 564 tokens where Hydrogen spent 240. A new
account starts with $5. Carbon would have made the first impression slow, and
then it would have spent the free credit.

So the default is Hydrogen, the cheapest Gemini 4 model, at $1.50 in and $7.50
out. That is still twice 3.8 Flash until New Year, when Flash's promotional
price ends and the two cost the same.

Before we changed anything, Hydrogen had to work on the account a stranger gets.
The free list in the code says each entry was checked by authenticating a fresh
identity and completing a real call, so we did that: a new key in an empty home
directory, $5.00 of credit, a tool-calling agent asked about the weather in
Sydney, and a spoken sentence sent through `transcribe`. Both came back right,
for $0.0018.

Then the guard that kept 3.7 from coming back as a default was pointed at 3.8 as
well. It found 55 places still teaching the old model: in docstrings, in the
prompts `co ai` reads to learn our own API, and in the docs. Two of them were
sentences we had written ten minutes earlier.
