# Ninety thousand was a promise

1.9.0a5 was merged and ready to tag. Its first run announced, before spending
anything, what each page would cost: about ninety thousand billed input tokens
per project, about a minute each. We ran it on the owner's real mail and
sessions before tagging, because every preview this week had found something
only real data shows.

The two project pages it wrote cost 614 thousand and 922 thousand tokens, four
to five minutes each. It meant to write thirteen of them, and three people pages
that read 150 days instead of the fourteen the run was asked for. Left alone, the
first run a new user sees would have billed more than ten million tokens while
saying it would cost a small fraction of that. The owner's own page, meanwhile,
gave him a partner's job, taken from a mail where he was describing her.

None of that was visible in tests, which used fakes with the old numbers. The
ninety thousand had been measured once, on an earlier version, and then written
into the code as a fact.

So the preview waited a day. The first run now writes your page, three people
and three projects, and says in one line what that will cost, estimated from the
notebook's own completed runs rather than a number in the source. On the next
real run it announced 1.4 million and spent 1.25. Your page has its own shape, a
role is yours only when you or someone else says it of you, and your name comes
from how people address you.

The lesson: a cost printed before you spend is a promise. Measure it where it is
spent, keep measuring it, and never let one old measurement become a constant.
