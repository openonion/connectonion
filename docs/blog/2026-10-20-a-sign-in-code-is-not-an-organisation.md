# A sign-in code is not an organisation

The first run turns every domain someone writes from into an organisation candidate. An events platform became one on a fresh notebook: its only correspondent sent sign-in codes and registration notices, and the user never wrote back. The page it got was a page about nothing the user does.

Deepening had already learned to skip such organisations. The map now applies the same rule before any page exists: a domain whose every correspondent is automated, or writes only one way, gets no organisation page. One real correspondent on the domain is enough to keep it, with the automated senders still listed beside them.
