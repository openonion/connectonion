# 158 people who were skills

Once the reader opened in Chinese on a real notebook, we went through every
kind of page with fresh eyes, on a desktop and a phone. The worst thing we
found was a counting sentence. The Skills list said "158 人中已撰写 156 人":
156 of 158 people written. The category line had been translated once, with
the noun for people, and every other category inherited it. Decisions became
"3 页".

Most of the other problems were English left behind in a Chinese page: the
lede of Waiting on you, the description of each category, the run names in
Activity, a refusal reason ("Changed page has no numbered evidence
references"), a "+2 more". Each of these appeared because a string was
formatted in place rather than passed through the translation table. We
searched the template for every user-visible English string that is not
page content and translated each one. English output stayed byte-identical.

Some problems were not about language. The navigation said 等你回复 while
the rows said 等你处理, so one obligation had two names. Inside the "waiting
on you" section every row repeated a "you owe" tag the heading had already
stated. Skill and project pages repeated their first open thread just above
the list of open threads. A decision's sources showed a raw session id 60
characters long. Each of these now appears once, or reads as a name and date.

The detected language had been saved only when the daily run completed
cleanly; it is now saved whenever the run takes its lock. And memory
changes from last night get one quiet entrance. The dot fades in and the
underline under a changed field draws once, in about 600ms. Neither
plays when the reader has asked for reduced motion.
