# A purpose needs its evidence

The Home page showed a Project name and a recent finding, but sometimes the
name was a folder label rather than a description of the work. A reader could
learn what changed without knowing what the Project was for. The written page
already had a short, cited purpose. Bringing that purpose into the changed
Project card gives the finding a frame of reference; the card still keeps the
finding as a separate statement.

The detail page had the reverse problem. Its purpose preview was useful and
compact, but on a phone the two-line clamp could hide the source link at the
end of the sentence. The large **View sources** action remained available
lower in the same first screen, yet the citation was no longer next to the
claim. The purpose's existing citations now appear as individual links beside
the displayed purpose. When there is no supported current finding, that
purpose leads the page once instead of being repeated. A long purpose starts
as a three-line preview with an expansion control, while Full memory retains
the complete wording. The page does not
invent a source or claim that those citations have been independently audited.

In one private Project sample, three 44-pixel citation links opened three
distinct source dialogs on both a 375-pixel phone and a 1440-pixel desktop.
The phone's main source action still fit in the first 812 pixels, including
an invented longer Project page. The Home card offered a 44-pixel route to
the detail page and its sources. We also gave
the desktop privacy control the same 44-pixel target already used on a phone.
This was a reader check on one written Project, not a new investigation or
an audit of every Project claim. The [preview notes](/releases/1.9.0a37)
state the measured scope.
