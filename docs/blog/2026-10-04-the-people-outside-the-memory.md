# The people outside the memory

The owner looked at a new REM notebook and asked where everyone was. The first
five-day trial had been narrowed further for a page test: `--first-people 0`
meant it wrote no person memories at all. Removing that cap would still not
answer the larger question. The normal map read only ninety days of mail, and
one short exchange did not earn a Markdown page. Those contacts existed in
private metadata but disappeared from the People view.

Making a page for every address would repeat an earlier failure. A real
notebook once held hundreds of empty person templates, including newsletters
and the owner's other inboxes. A mail header is evidence that an address was
seen; it is not proof of who a person is, or what the relationship means. The
new directory keeps those claims apart. A person REM has written about remains
in the main table. A one-off correspondent can be found in a separate,
searchable list, marked as an unreviewed contact, with a terminal command to
prepare a memory when the owner recognizes them.

The history question has a cost before a model writes anything. An isolated
metadata-only scan of one connected Outlook account traversed its available
years since 1970 in 393 seconds. It observed 18,737 message headers, mapped
509 people and 13 projects, and retained 575 low-signal correspondent groups
for review. The other connected mailbox timed out before its address list was
read, so these are a lower bound. The directory says when coverage is
incomplete. A timed-out time window is split, and any day still unavailable is
recorded rather than counted as scanned.

The partial map alone offered 461 person investigations and ten projects. The
current defaults estimate 142 million billed input tokens and about ninety
minutes with twelve workers. That estimate has no completed page samples in
this isolated notebook, so it is a planning number, not a promise. The twenty
percent weekly target is advisory; the configured safety floor still stopped
new model work. REM can now show this forecast without a model turn or a
historical body archive. A full all-person run and claim-by-claim review remain
separate work, because finding an address is only the start of remembering a
person well.
