# 1.9.2b15: answered once, whenever it is asked

When the agent that took over your work asks a question, your agent answers
it. This preview makes that true for as long as the handoff lives.

A question asked a month later gets its answer. Two parts of co checking at the
same moment send one answer, not two. A session that ran for days still sends
its copy, keeping the newest part when the whole is too big, and a session that
has since been deleted still gets a reply that says so. A busy inbox is read
all the way to its newest message.

Each of these was found by asking what happens after the first day, and each
one now has a test that would have caught it.
