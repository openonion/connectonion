# 1.9.2b19: one host, whichever way you start it

Set an agent up once and it should do everything you set it up for. In this
preview it does: `co host`, `python agent.py`, `co deploy` and `co ai` all serve
the agent, your REM pages and the chat channels you listed, from one process
on one port.

`co host` is new, and it is the command `co create` now prints. It works on a
machine set up a minute ago with the one-line installer, which is where most
people meet co for the first time.
