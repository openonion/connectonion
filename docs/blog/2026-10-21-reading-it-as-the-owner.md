# Reading it as the owner

We ran a full first init on the current code and read five pages the way their owner would: is the lead right, are the open threads right, is any contact wrong, is anything stale or missing that the mail plainly shows.

The contacts held: every phone was the person's own, no address was invented. The quotes held too. What failed was judgement in a few places the rules had left loose. A lead said "the user owes" an answer the user had never promised, though the same page's Open threads wrote it correctly as "asked the user". A lead's next step was "reply by email, the fastest way to reach them" — a sentence about a channel, not an action. One History was a single line that compressed eight threads; the audit refuted it and the section came out empty. The owner's page quoted a private diary folder. A project page said `Repository: Unknown` beside a GitHub remote.

The lead now uses the same four shapes as Open threads, and its third sentence is the user's next action on the live item. History keeps a line for every thread of the last year. The owner's page no longer reads diary folders, the same rule that keeps them from becoming project pages. And the checkout state now names the repository's remote, so the page has something to cite.
