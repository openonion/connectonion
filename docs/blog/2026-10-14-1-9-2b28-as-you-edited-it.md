# 1.9.2b28: as you edited it

*2026-10-14*

Preparing a handoff for a group of students, the reviewer rewrote a sentence in
the draft that mentioned a sleep study. The page changed. The session copy that
goes with it did not: it was rebuilt from the session file, which still had the
original sentence. The only way out was to drop whole messages.

Now each message is recorded as it was drafted, and anything you changed goes
as you changed it. The preview also names the messages that mention health,
visas, the law or money, so you find them before you send instead of after.

```bash
python -m pip install --upgrade 'connectonion==1.9.2b28'
```
