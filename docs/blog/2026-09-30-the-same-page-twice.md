# The same page, twice

O Chat got a new look this month. The owner went back to how it looked on 2
September, kept that structure, and took the colour down to green and white.
Green now marks four things only: the one button you are meant to press, the
dot that says an agent is live, the item you are on, and the ring around
whatever has focus. Everything else is text on one light ground.

Then we opened an agent's own Home page inside it, and it looked like it came
from somewhere else. It had a "Control Center" label over the name, a coloured
square with the first letter in it, a card that said "Use Chat for live
status", and three more cards stacked under that, each with its own shadow.
Nothing on it was wrong. It was just built in a different style.

So the Home page now follows O Chat's agent screen. At the top is a bar with a
live dot and the agent's name. Under it is the name again, large and in a
serif, then one line about what the agent does. Below that is a fold labelled
SKILLS with a count, and inside it one plain row per skill: the name, then what
it does. The skills have no boxes or tiles around them. The Diagnostics fold
sits at the bottom, closed.

The headline serif is the system one: New York on a Mac, Georgia elsewhere.
O Chat's own design loads a web font, but a Home page has to render on a host
with no internet connection, and one missing font file shouldn't change how
the page is laid out.

The owner keeps two things they need often: the address people use to reach
the agent, and the invite code that lets someone in. Last week the invite code
moved into the terminal where you start `co ai`. That doesn't help when you are
on your phone and a friend asks how to join. So the code is now also on the
Home page, in a small monospace line under the address. It appears only when
the page is built for the owner's own verified connection. A contact or a
stranger gets the same page without that line.

The Control Center is the interactive version of this page, and a test keeps
the two using the same colours. It got the same changes, plus the composer at
the bottom, which is the only green button on the page. On a wide screen its
skills start open. On a phone they start folded, so the composer isn't pushed
off the screen.
