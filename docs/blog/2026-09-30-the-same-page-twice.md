# The same page, twice

O Chat got a new look this month. The owner went back to how it looked on 2
September, kept that structure, and took the colour down to green and white.
Green now marks four things only: the button you are meant to press, the dot
that says an agent is live, the item you are on, and the ring around whatever
has focus. Everything else is text on one light ground.

Then we opened an agent's own Home page inside it, and the page looked like it
had come from another product. It had a "Control Center" label over the name,
a coloured square with the first letter in it, a card that said "Use Chat for
live status", and three more cards stacked under that, each with its own
shadow. Nothing on it was broken. It had simply been designed on its own,
before the app it lives in had settled what it looked like.

That was the real problem. The Home page is not a separate website. It is one
pane inside O Chat, and anyone reading it has just come from O Chat's own agent
screen. When that screen shows a name and a list of skills one way, and the
Home page shows the same two things a different way, the reader has to learn
the agent twice.

So we stopped designing the Home page and copied the screen it sits next to.
There is a bar with a live dot and the agent's name. Under it is the name
again, in a serif, then one line about what the agent does. Below that is a
fold labelled SKILLS with a count, and inside it one plain row per skill: the
name, then what it does. The "Control Center" label, the letter badge, the
status card and the shadows are all gone. Diagnostics is still there, closed at
the bottom.

The Control Center app, the interactive version of the same page, got the same
treatment. A test already made the two share their colours, so changing one
meant changing the other. The only extra thing on it is the message box at the
bottom, and its send button is the one green button on the page.

What we took from this: a page that lives inside another app should look like
that app. The Home page had been trying to look good on its own, and inside O
Chat that just made it look like a different product.
