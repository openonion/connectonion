# A morning brief, not a contents page

REM is named after the part of sleep where memory is sorted, so its home
page should read like a morning brief. Until today it opened on a large
chart of last night's runs, then a list of what was waiting, then a week of
rewritten pages, then cards for every category. Everything on it was
accurate, but the page did not say what to do first.

Home now reads top to bottom. A date line, then one sentence: "1 change
overnight · 1 due soon · 4 waiting on you". **Overnight** lists only field
changes the run log can back with a source, such as a role that went from
"Partnerships lead" to "Head of Partnerships". A page that was only reworded
does not count as a change, and a quiet night says so. **Today** lists what
is overdue or due within three days, in either direction. It looks three days
ahead so that a Friday deadline shows up on Tuesday. **Open threads** shows
the three most important things waiting on you that Today did not already
show. After those comes a search field with a few task links: who do I owe,
what changed this week, people, projects. The run chart, the week's rewrites
and the maintenance details are still there, folded away.

Every open thread now has two buttons. **Copy prompt** puts a prompt on the
clipboard for Codex or Claude Code. It names the thread, the page with its
`co rem show` command, the cited source ids and their dates, and it asks the
agent to draft and not send anything. **Mark done** hides the thread in this
browser only. The reader is a static file and has no way to write to the
notebook. It says that plainly, offers Undo, and the thread closes for real
when the next pass reads your reply.

The same request often appears on several pages: a person's page, their
organisation's, a project's. The reader already merged copies that cited the
same message. It missed the copies that wrote the date out ("by 23 October
2026" next to "by 2026-10-23"), so it now reads written dates. Our first
version of the stronger rule went too far. On a real notebook it merged two
different questions that one person had asked in the same email, because
both mentioned the same sprint. The rule now asks that one copy mostly repeat
the other's distinctive words, not merely share a source. On that notebook,
Waiting on you went from 20 items to 19, and the one removed was a real
duplicate.

The People table also got lighter. Each cell is one line, the full text
appears on hover, the coloured pill and the column rule are gone, and a row
is about half as tall. The README now shows the reader in English and
Chinese, on desktop and phone, using the invented example notebook.
