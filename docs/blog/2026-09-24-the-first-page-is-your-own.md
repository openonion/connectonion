# The first page is your own

A new notebook had 399 people in it, and the one page every other page depends
on was blank. It was titled "Account owner". Apart from four email addresses,
every section said "Unknown — not investigated yet".

The map knew more than that. It had just read ninety days of mail headers and
a thousand coding sessions. It knew the owner writes most to Ody, then Dora,
then Tamara. It knew most of the owner's sessions ran in one workspace, and
that the next largest project was connectonion. Outlook even had a name on
file. The map had all of this and wrote none of it onto the page it was
written for.

That page matters more than any other, because every other page is written
from its side. "Our relationship" means the owner's relationship, and an
address in the owner's list is never someone else's. A first-time user who
opens their own page first should see what the notebook has learned about
them, not a form to fill in.

The map is a script, so the page holds only what the script can stand behind.
It records who the owner writes to most, how much, in which mailboxes, and
which projects the sessions ran in, all cited to the map's own record. The
title comes from `init --name`, else the mailbox's display name. Role, company
and working language are not in mail headers, so they stay Unknown until an
investigation reads the messages. A section that has already been filled is
never written over on the next map.

One more detail changed. The map already asks about addresses the owner keeps
writing to that never write back, which is how a second personal Gmail looks.
On the real mailbox that list also held two colleagues who answer on other
channels. Asking about them at the end of init is fine. Printing "possibly
also the owner's" next to a colleague's address on the owner's page is not.
The page now names only the addresses that carry the owner's own name. The
full list stays in init's output, as a question.

The same run turned up a page named after the owner that wasn't them: GitHub
notifications, 95 in and 1 out, sent under the owner's display name. It had
become a person because the owner once replied to a notification by mail. An
automated address that receives ten times what it sends is now a notice, even
if the owner has replied to it once.
