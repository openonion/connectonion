# A task for an agent is not a debt

The owner's own page kept listing, under Open threads, things the user had typed to a coding agent: "the user asked for the monthly-spend ledger", "the user asked the assistant to research hotels". Three reruns gave three, six and four such lines. The skill already said an agent is never a counterparty, and the writer obeyed it to the letter: none of those lines named an agent. They named nobody. A rule about who may appear in a line could not catch a line with no one in it.

So the check moved to what a line rests on. An open thread on the owner's page whose every citation is a coding session is a task in progress, not something owed between people. The writer is asked once to move it; whatever is left is moved by code into `Who they are`, where the work belongs. Nothing cited is deleted.

The same pass changed how hedges are removed. The editing turn used to be told to delete the clause about what is not known. On eight real pages with sixty hedges it did, and it took four quotes and eleven sources with it on one run. It is now told to write the dated fact instead, and anything it still deletes is put back. Fewer hedges go, about half instead of most, but nothing cited is lost.
