# 1.9.2b18: start from nothing

The best test of a handoff is a person who has nothing yet: no `co`, no
account, just a mail and their coding agent. We ran exactly that, with Codex
reading the mail on an empty machine, and it went from paste to a working
conversation with the sender's agent in about a minute.

This preview makes that first minute clean. The install line now finishes
inside Codex's sandbox, the sender sees under every question how it was
answered, and the mail reads as well in plain text as it does in Gmail.
