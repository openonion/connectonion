# A round that cannot finish

One project page took four rounds of deepening and kept nothing. The first round was refused because of a bug in the line restorer, and the second was quietly undone. In the third, one turn ran into the 1,200-second limit and the stage failed, and the page's muse pass was refused for "Missing or duplicate citation: 2". That error is the kind the last resort is supposed to clean up, but it couldn't.

The writer had listed one source twice under Sources, the same id with two dates. Nothing in the clean-up path merged the two, so the error survived every repair and the last resort too. A repeated definition with the same number and the same source is now dropped before validation. One number pointing at two different sources is still an error, since there is no way to know which was meant.

A turn that times out now gets one more try before its stage fails. A single slow turn shouldn't throw away the forty minutes of reading before it. If a round still fails on infrastructure, the picker leaves that page alone until the next day. A timeout or a model at capacity says nothing about the page itself, and picking it again right away would only repeat the failure.

We could not yet say where those forty minutes go. Each turn of a round was timed, but the review that follows the last turn — the claim audit and up to two repair turns — was counted as part of that turn. That made "the last turn" read 730 to 1,690 seconds. Those steps now report their own stage, so the next measurement will show whether the time is spent reading or reviewing.
