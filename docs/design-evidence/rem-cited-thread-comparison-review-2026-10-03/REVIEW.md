Candidate in draft PR #2141; actual automatic reconciliation remains tracked in

with marketing and UI experience, without claiming human-founder participation.
Private identities, native IDs, mail bodies and screenshots remain local.

## Problem and candidate

After later retained mail became available, investigation still removed every
source mentioned under the page's Sources. A newly gathered reply could lose
the original request it needed to resolve. The comparison also used substring
matching: an attachment citation could incorrectly suppress its carrier email.
Coverage text assumed the existing page already represented earlier material
correctly, discouraging correction from newly supplied historical originals.

The candidate uses exact parsed source IDs. A newly supplied mail message with
a nonempty exact provider thread can retain previously cited saved originals
from that thread, including a request before the requested update window.
Same subjects, cross-provider thread strings, empty threads, attachments and
chat messages do not seed this comparison. No new threaded mail means no
archive comparison; already-cited mail alone still stops without a model call.

Canonical initial metadata takes precedence over later observations when
supplying provider-thread identity. Each comparison retains its real author,
sent date, participants, capture/retention limits and relationship scope.
Comparison scope labels it as old evidence. Owner sent-only filtering and
explicit mailbox unsubscribe remain effective. Direct facts are extracted
before the older comparison originals are added, so they do not move contact
dates or create personal obligations from dropped-recipient context.

The new coverage separates uncited gathered inputs from reread originals and
allows source-backed correction of an existing interpretation. Missing originals
and unknown provider threads remain unreviewed; the page cannot substitute for
the original. This is retained-source access, without a provider recovery query.

A further regression found that the first live retained-message handoff omitted
the saved capture time, retention time, input scope and body format. These fields
now reach the investigator immediately, using the same first snapshot as the
body and headers. Unknown original capture time remains absent; no clock is
invented for a run without an archive.
