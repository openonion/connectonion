# Initial project source and experience review — 2026-10-03

This is an independent AI role review from a technology-founder perspective
with marketing and UI experience. It does not claim that a human founder participated.
Private source bodies, repository identifiers and rendered screenshots remain outside this repository.

## What changed

The initial project writer previously received README/package/Git metadata and
could not inspect implementation. A reviewed PDF project led with stale checkout
housekeeping and historical verification requests while omitting useful source findings.

Initial writing now supplies a fixed tracked tree and a searchable index of at
most 60 eligible source files, including declared CLI entry points, implementation,
configuration and tests. Files over 1 MB and excluded paths have no supplied bodies;
the tree states those limits. Non-Git inventory is partial. Source snapshots preserve
supplied text, bind citations to origin and body, and retain only cited accepted evidence.
Selected source reads cost extra beyond the initial/index estimate. No quota override was used.

The real page was manually corrected from 17 exact indexed native user inputs
and 11 retained repository packets. This is a semantic correction, not proof that
automatic generation follows the new instructions.

## Supported findings and boundaries

- A documented browser download link has no handler in the complete inspected
  fixed tree; Next config supplies no rewrite. No runtime 404 was observed.
- The CLI renderer uses a separate path. Without an explicit config variable or
  either CWD JSON candidate, the loader selects the bundled example. An explicit
  missing path fails when read; it does not fall back.
- Three fixture cases directly render the PDF component and check page counts
  and selected text. They bypass CLI/config resolution. No fixture execution,
  installation, publication or deployed app was verified in this round.

## Verification

- 166 focused unit checks passed.
- Six relevant browser checks passed, including the new Unknown status regression.
- The actual-page harness produced nine baseline, 33 correction and 33 final frames
  at 1440, 768 and 375 pixels. Final nine source sequences exercise citation open,
  shown/hidden/restored context, close and restored focus. The privacy toggle uses
  its UI handler through the harness. No JavaScript errors, external requests or
  checked page/dialog overflow were observed.
- The independent reviewer actually inspected all nine baseline and 33 correction
  frames, then 15 targeted final frames: all three page views, all three full notes,
  and config-source shown/hidden/restored states at three widths. This is 57 stage
  inspections. The other 18 final frames were not independently viewed again.
- The reviewer independently compared all 17 native inputs to indexed bodies and
  checked the 11 retained origin/body identities, permissions and final page hash.
  No new P1 remained in this inspected sample.
