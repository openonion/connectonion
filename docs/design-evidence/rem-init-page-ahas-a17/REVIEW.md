# REM first-run project page: evidence before prose

## What was compared

- **Problem:** a written project `Insight` paraphrased recent requests, while a fixed 17-section note exposed unsupported fields. The published 1.9.0a15 private five-day run had one investigated project with 17 headings, 7 `Unknown` occurrences and no internal links. Its lead did not establish a verified change.
- **Change:** a bounded local packet now supplies README, package metadata, checkout freshness and up to five commit subjects as separately citable evidence. The writer compares these with user messages and omits unsupported optional sections. Commits do not count as proof of tests or deployment.
- **Real candidate check:** two isolated five-day a17 inits each exited 0 with 3 mapped and 3 final project pages, one project and the owner written, and 0 source errors. The first still led with a dated request. After a writer-guidance revision, the second project's 14 headings held 1 `Unknown` in required Facts and 3 cited Insight bullets. One joined a local commit with a repeated user request, without claiming the commit proved a passing test. It still had 0 internal links. The owner page had 5 links but its lead remained a broad request summary.
- **Privacy:** real names, page text and local source bodies are not in these public screenshots. The screenshots use the invented Harbour notebook from the browser fixture.
