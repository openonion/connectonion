# First-map reader screenshots

These screenshots use an invented notebook, not a user's mail or files. The
fixture has 613 mapped People records: 575 visible rows and 38 possible
contacts held for review. Every page is marked not investigated.

- `overview-phone.png`: first-run Overview at 375×812, with the mapping result,
  zero-written limit, next actions, and held count in the first screen.
- `people-last-contact-phone.png`: People at 375×812 with the table scrolled to
  its right edge. The sticky Name column leaves the Last contact heading
  readable.

The private 3,650-day map was separately rendered and reviewed at 1440×900 and
375×812. Its aggregate results are described in the linked issues and PR;
private captures and source material are not included here.
