## Useful finding and primary evidence

At source revision `3290462d7113c7c2e86684ff3ca4b5a5c6750b85`,
`@connectonion/react`'s detailed guide supplies a required string `sessionId`
and documents fire-and-forget hook input. The README's first component example
still supplies only the address. The package's conditional ESM entry re-exports
the root entry and the same implementation; a different optional-session
overload does not explain the example. Stable caller-owned session IDs key both
the live-agent cache and persisted store. This is an adoption-relevant source
finding, not a reproduced compiler/runtime failure or npm publication check.

The real page uses 12 new immutable bounded packets after complete primary
reads of 16 available files across two fixed revisions; two older modules were
absent. One additional legacy README packet was uncited and not retained.
The packets include exact hook/guide/example windows, manifests, exports,
cache/store implementation and separately captured Git metadata. Each is at
most 9,000 characters; the largest is 7,674. New captures do not recover the
missing historical mutable-path citations.

The remaining README issue is recorded in
[connectonion-react #113](https://github.com/openonion/connectonion-react/issues/113),
with fixed-revision primary links and explicit source-level verification limits.
