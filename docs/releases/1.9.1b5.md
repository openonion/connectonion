# ConnectOnion 1.9.1b5 (preview)

## Install this preview

Stable remains 1.9.0. Install this beta by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.1b5'
```

## One session scan per run, whatever the window

1.9.1b4 kept the coding-session window for the run, but only for the range it
was built over. People pages asked for 180 days, organisation pages and the
background mail backfill for two years; each wider request threw the kept
window away and scanned again behind the lock, so people still waited minutes
to start. The window is now built once over two years and every page filters
it by date. The background backfill, which exists to fetch older mail, no
longer reads coding sessions at all.

## Verification and limits

The co rem unit suite passed (2,453 tests), with regressions that failed on
1.9.1b4 first: a 180-day, a 730-day and a 180-day request scan once, and the
backfill is given mail subscriptions only. A full first run on this beta
decides whether it becomes 1.9.1.
