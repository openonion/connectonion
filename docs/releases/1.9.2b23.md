# ConnectOnion 1.9.2b23 (beta)

## Install this preview

Stable remains 1.9.1. Install this opt-in beta by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.2b23'
```

## A note from someone you know

- **The mail comes from you** (#2478). A handoff goes from whatever mailbox you
  have, in this order: your AI's own mail tool (a Gmail or Outlook MCP in Claude
  Code or Codex), your Gmail or Outlook connected to co, and your agent's mailbox
  only when there is nothing else. The preview says which one, and the notices
  about questions and "done" reach you there too.
- **It reads like a note, in your language.** The subject says who passed what,
  with no co jargon. Then come a sentence or two on what you worked on and with
  which AI, and one paragraph to paste, which a triple-click selects. If you
  worked in Chinese, the mail is in Chinese.
- **The opened session keeps going** (#2479). `co handoff open` fetches the
  handoff from the backend and feeds your answers back into the session until it
  is done.
- **Smaller fixes** (#2477). The brief says when your code travels with it, and
  the paste says to let a slow install finish right after a release.
