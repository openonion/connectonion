# 1.9.0a12 — REM opens safely on Windows

This opt-in preview carries the [1.9.0a11 morning reader](1.9.0a11.md) and
fixes `co rem open` on Windows. Stable remains 1.8.10.

The reader renders the private notebook into a local HTML snapshot. Earlier
previews used the POSIX-only `O_NOFOLLOW` flag to protect the predictable
snapshot filename. Windows Python does not provide that flag, so the command
could fail before opening the page.

The reader now writes a complete snapshot under a private random name and
atomically replaces the public filename. A planted symbolic link is refused;
the write does not follow its target. The notebook itself remains unchanged.

The Windows CI builds and installs the wheel, then runs `co rem open --no-launch`
twice from outside the source checkout. Unit tests cover a planted link and
repeat opening, and browser tests cover the generated page. The [morning reader
screenshots](1.9.0a11.md) remain the visual evidence for the unchanged UI.

## Install

```sh
python -m pip install --upgrade 'connectonion==1.9.0a12'
co rem open
```

## Known limits

The reader is still a read-only snapshot. It cannot yet compare claims before
and after a pass (#2096), save recall feedback (#2097), or answer questions
inside the reader (#2071). See the [a11 notes](1.9.0a11.md) for the full
product audit and other open work.
