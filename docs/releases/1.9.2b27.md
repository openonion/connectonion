# ConnectOnion 1.9.2b27 (beta)

## Install this preview

Stable remains 1.9.1. Install this opt-in beta by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.2b27'
```

## Only what you approved

- **The session copy is the conversation you approved.** Your messages and the
  AI's replies in full, nothing you removed with `--edit`, and never a command or
  its output. In a session that ran `co rem`, command output held whole pages
  about other people and your own mail.
- **Names from your co rem pages are masked**, in the page and in the copy, along
  with links to other handoffs. Yours and the recipient's stay. The preview says
  how many, and how big the copy is.
- **Only the person who accepts can read it.** The full handoff is read with the
  code's secret, and the first agent to read it claims it; anyone else holding a
  forwarded link is told it is taken. A handoff nobody accepts is gone in a week.
- **No waiting forever.** `co handoff status --wait` gives up after 10 minutes and
  says to carry on with a stated assumption.
- **See where the recipient is named** before you send: the preview counts it, and
  `--mentions <name>` lists each place.

## Verification and limits

- Each change has a test that failed first; the handoff and trust tests pass.
- Checked against a real 7 MB session that had run `co rem`: the copy is 589 KB,
  with no command output and no names from co rem pages.
- Send with 1.9.2b27 or later: the server no longer serves the session copy of a
  handoff sent by an older co. The install floor is 1.9.2b27.
