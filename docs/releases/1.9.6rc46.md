# ConnectOnion 1.9.6rc46 (release candidate)

Stable remains **1.9.5**. Python **3.11+**.

## A Host that is not serving says so

- **Windows background Host** (#3225): `co host --background` and `co init` used to report the
  Scheduled Task's state, which stays Running while every start exits (a port that is taken, a
  missing key). Running now means this project's Host answers `/info` on the port it claimed. If
  none answers within 30 s, the error shows the last lines of both logs and how to run it in the
  terminal.
- **A refused announce stops the Host** (#3125): when the relay answers an ANNOUNCE with an
  ERROR (for example "Too many endpoints"), the Host exits with
  `[host] The relay rejected this agent's announce: <reason>` instead of running unreachable.
