# ConnectOnion 1.9.7rc2 (release candidate)

Stable remains **1.9.6**. Python **3.11+**.

- **`co wechat` just works on WeChat 4.1 for Mac (#3265, #3261).** Tested live on WeChat 4.1.15:
  - Each database has its own key. `co wechat key capture` asks once, opens a re-signed copy of WeChat under
    Apple's debugger while you log in, saves each key by its database's salt to `~/.co/wechat/keys.json`
    (0600), and reopens the real WeChat. The real app is never changed.
  - The databases are in WAL mode: committed `-wal` frames are applied, so every database opens and the
    newest messages are there.
  - Bare `co wechat` sets up what is missing (Full Disk Access, keys) and lists recent chats, numbered.
    `co wechat read N|name` shows a chat, and `co wechat search WORDS` searches. When several accounts are on
    the Mac, it reads the one in use.
  - `co wechat tables` replaces `chats`; a database no key opens is reported, not a traceback.
- **README (#3248):** WeChat, Asana and Obsidian join the integrations wall.
