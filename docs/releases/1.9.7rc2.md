# ConnectOnion 1.9.7rc2 (release candidate)

Stable is **1.9.6**. Python **3.11+**.

- **`restricted: env`**: a restricted claude-code Host names the variables its tools need
  (`env: [FRESHDESK_API_KEY]`); their values come from the Host's environment, never from host.yaml. Before this,
  the claude CLI's child environment dropped them, so a script that needed an API key failed on every call.
- **The caller in the environment**: each restricted turn sets `CO_CALLER_ADDRESS` and `CO_CALLER_TRUST`, so a
  tool can check the caller's role in code as well as in the prompt.

Found on a Windows 11 PC running 1.9.7rc1 `restricted:`: every `.env` canary was blocked and the balance stayed
flat, but the support lookups it was built for failed. See [1.9.7rc1](1.9.7rc1.md) for the rest of this line.
