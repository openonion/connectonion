# ConnectOnion 1.9.2b18 (beta)

## Install this preview

Stable remains 1.9.1. Install this opt-in beta by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.2b18'
```

## A handoff a stranger can start from nothing

The person you hand work to may never have used ConnectOnion. This preview makes
their first run clean:

- **The install line finishes inside Codex's sandbox.** Codex keeps `~/.codex`
  read-only there, and `co init` crashed linking skills into it, so the install
  reported failure although `co` worked. A directory `co init` cannot write is
  now skipped with a line saying so (#2436).
- **The sender always knows where each question stands.** `co handoff status`
  shows under every question whether your agent answered it and how: with the
  session copy, pointing to it, or without one because the session is gone.
- **The mail's text version reads properly.** An agent reading the mail as text
  no longer sees words run together. The HTML is unchanged.

## Verification and limits

- Found by a 1.9.2b17 end-to-end run from empty machines: a real Claude Code
  session on a Mac sent, Codex on Linux pasted the block from the mail,
  installed co, accepted, asked, and had the automatic answer with the session
  copy in 36 seconds. Codex did not open an unrelated skill on the way (#2391).
- Each new test failed on 1.9.2b17 and passes; the handoff suites pass.
- The install floor is 1.9.2b18, so the mail installs the version with the
  sandbox fix.
