# ConnectOnion 1.9.2b13 (beta)

This preview makes the first handoff easier to receive. The email presents the
sender, task and current status before the single prompt to paste into Codex or
Claude Code. The prompt uses the official isolated installer on macOS and Linux
and uv on Windows, then accepts the handoff and introduces the recipient's agent
to the sender. An HTML mail cannot offer a reliable in-message copy button, so
the prompt remains one selectable block.

The root README also gives the same version-pinned install command and a prompt
for someone who finds the repository before receiving a handoff. `co init`
creates the agent identity and mailbox; personal Gmail and Outlook connections
are optional.

```bash
curl -fsSL https://raw.githubusercontent.com/openonion/connectonion/main/install.sh | CO_VERSION=1.9.2b13 sh
```

This remains a preview. Stable installs still resolve to 1.9.1. See
[the handoff guide](https://docs.connectonion.com/cli/handoff) for the full send and receive flow.
