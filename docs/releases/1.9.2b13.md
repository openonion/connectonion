# ConnectOnion 1.9.2b13 (beta)

## Install this preview

Stable remains 1.9.1. Install this opt-in beta by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.2b13'
```

## Questions answer themselves

When the agent that took over your handoff asks a question, your agent now
answers it by itself, without waiting for you. The first answer brings a copy of
the session the handoff came from. The other agent saves it next to the brief
and searches it before asking again.

- **What the copy holds.** Every message, what the AI said, and every tool call
  with its output. A long output keeps its start and end. Reasoning is left
  out. The brief is still short and approved by you word by word; the copy is
  there to be searched.
- **Only what you handed off.** The copy covers the messages from `--since`
  up to the moment the handoff was sent. Credential-shaped strings, handoff
  codes, and the values in your keys.env are removed before it leaves.
- **Wherever your side checks.** `co ai`'s watcher, `co handoff status` and
  `status --wait` all answer, and each question is answered once. You still
  see every question, and `co handoff answer` adds your own answer.
- **The recipient** finds the copy at `~/.co/handoff/accepted/<id>/session.md`;
  `co handoff status` prints the path. The install floor is 1.9.2b13, the first
  version that saves it.

## Also in this preview

- **The Code section names the branch** (#2416). When a session changed into
  another repository, the client recorded the branch as `HEAD`, and the
  handoff said "detached" for a worktree that was on a branch. It now names the
  branch at that commit, and says detached only when no branch has it.

## Verification and limits

- Measured on a real three-day session: the whole session packs to 2.2 MB,
  under the 5 MB inbox limit, in 2.4 seconds, with 16 credential-shaped strings
  removed. The handed-off part was 150 KB.
- Reading what the redaction left on that session found 44 handoff codes,
  each the secret for accepting one handoff, some of them for other people.
  They are now removed too, and a brief that contains one is refused like any
  other credential.
- The handoff suites pass (171 tests). The new tests failed first on 1.9.2b12.
- A session too large for the inbox limit cannot be answered this way; the
  sender's side reports it, and the question stays for a person to answer.
- The automatic answer is the copy and a pointer to it, not a written answer
  to the question. The recipient's agent does the searching.
