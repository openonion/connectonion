# 1.9.7rc20

Release candidate for 1.9.7. Stable remains 1.9.6.

## Private tag pages are distinct and their titles carry no mark (#3386, #3385)

- A tag page's title is its plain name: the page check refuses a `[personal]`/`[sensitive]` title, and the page build
  moves an old title mark onto the page's passages once (local, no model, Undo kept).
- A page that stays masked reads 个人事项 1, 2 …, numbered once in the order it was first masked and stored in the page;
  a new page never renumbers the others and a deleted number is not reused. Opening or building writes no state.

## Course and team codes read as names (#3389, #3388)

- 课程 3900 / 团队 … wherever an organisation's name shows: the org page, breadcrumb, tree, graph, chips and links.
  A private page stays masked first.

## A gone mail is no longer promised a retry (#3393, #3392)

- A mail the mailbox answers is gone is asked for once more 24 hours later; then the night stops waiting and Today says
  N 页引用的邮件已不在 Outlook，不再等. 会再试 counts only pages that will be retried. The page is never changed.

## The night curve shows the whole night (#3394, #3391)

- The page carries every run of the night (capped at 400), so the curve starts with the night's first run; a stuck
  stretch of 15 minutes or more keeps its own caption; the axis ends ten minutes after the last run.
