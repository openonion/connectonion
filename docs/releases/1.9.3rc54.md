# ConnectOnion 1.9.3rc54 (release candidate)

Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

## Hotfix: scheduled `codex exec` turns reach the network

- On 1.9.3rc53, the macOS `codex-exec` scheduler started Codex in its `workspace-write` sandbox,
  which blocks the network by default. Every scheduled turn stopped at `co rem next` with
  `ConnectError: nodename nor servname provided` while reading mail, so no round did any work.
- Turns now run with `sandbox_workspace_write.network_access=true`. The only writable directory
  added outside the notebook is the account directory (`~/.co`, or `AGENT_CONFIG_PATH`), so a mail
  token refresh can save its result.
- Nothing to do after upgrading: the next saved time uses the new command.

## Install after publication

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc54'
```
