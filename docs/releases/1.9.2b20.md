# ConnectOnion 1.9.2b20 (beta)

## Install this preview

Stable remains 1.9.1. Install this opt-in beta by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.2b20'
```

## A handoff nobody has to babysit

The person you hand work to pastes one block into Codex or Claude Code, and
their agent does the rest:

- **It accepts by itself** (#2447). It tells them in a few lines what the task
  is, then does it in that folder. It asks only before something that cannot
  be undone or that leaves the machine. The brief is still the sender's text
  and does not override them.
- **It tells you when it is done** (#2448).
  `co handoff done <code> "what I did" --file result.patch` puts "Done, …" in
  your `co handoff status`, saves the file under `~/.co/handoff/results/<id>/`,
  and `co ai` prints it.
- **A later handoff reaches the person, not only their agent** (#2449). A
  handoff to someone who is already a contact is mailed to them as well as put
  in their agent's inbox.
- **The preview says what they cannot get** (#2450, #2451). Unpushed code gets
  a warning, because the recipient cannot fetch it, and every private detail
  is listed.

## Verification and limits

- Found by a 1.9.2b19 end-to-end run: a real Claude Code session on a Mac sent,
  and Codex 0.162.1 on Linux, starting from an empty home directory, received.
  There were two rounds, a first handoff and one between contacts. The work
  was right both times; the person had to step in twice in the first round,
  and the result came back outside the handoff.
- Each new test failed on 1.9.2b19 and passes; all 110 handoff tests pass.
- The install floor is 1.9.2b20, because step 6 of the prompt runs
  `co handoff done`.
- The mail's From line is still the mail service's bounce address
  (openonion/oo-api#260); that fix ships with the email worker.
