# 1.9.7rc22

Release candidate for 1.9.7. Stable remains 1.9.6.

## A tag or search view never scrolls sideways (#3407, #3404)

- A privacy curtain's cap is a length, not a width, so a long masked passage wraps inside the view instead of pushing it
  wider than the screen.

## Today: when before how old, each event once, and a phone fit (#3408, #3406, #3379)

- A line says when something happened before how long ago, and an event shown in one place is not repeated in another.
- On a phone the night's captions wrap inside the card instead of running off its right edge.

## A facts card keeps short values whole and speaks Chinese (#3409, #3405)

- A short value is never broken across lines, and the card's labels read in Chinese.
