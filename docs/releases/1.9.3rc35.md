# ConnectOnion 1.9.3rc35 (release candidate)

Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

## REM: same-person judgements are counted

- The daily round's same-person judgements (new in rc34) are now a run of their own,
  `same-person`. A run is reserved only when a pair is waiting, and it is capped to the calls
  the day has left. It shows in `co rem logs --usage` as its own stage, counts in the
  day's runner calls, and counts toward the week's investigation points.
- A pair whose judgement fails is recorded with the date and skipped for the rest of the day,
  so the pairs behind it are asked; it is due again the next day. Answered pairs are
  never asked again (#2743, #2741).

## Install after publication

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc35'
```
