# ConnectOnion 1.9.0a24 (preview)

## Manual page merge command

Alpha **1.9.0a24** adds the `co rem merge` CLI command to manually fold duplicate
or multi-identity pages (such as people communicating across multiple email
addresses, or duplicate project stubs) into one authoritative page:

- **Full content folding**: Written lines from the old page are merged into the
  matching sections of the kept page, renumbering citations sequentially.
- **Archive and alias**: The old page is safely moved to `.state/archived/`, its
  record is stored in `aliases.json`, and links across all other notebook pages
  are updated to point to the kept page.
- **Safety checks**: The command locks the notebook during operation, verifies
  that both pages exist, and prevents merging a page into itself or its active aliases.

## Verified fixes

- Resolves #2200 (partially): Support manual merging of multi-address people pages.

## What is in this preview

- `connectonion/cli/commands/rem_commands.py`: `co rem merge KEPT OLD [--reason TEXT]`.
- `connectonion/cli/commands/rem_help.md`: CLI documentation under Advanced management.
- `tests/unit/test_rem_merge_command.py`: unit test suite covering merge operations, error boundaries, and JSON output.
