# ConnectOnion 1.9.3rc27 (release candidate)

Preparation record: availability requires the matching public PyPI package and
GitHub prerelease. The published/installed baseline during preparation was rc26.
Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

## Keep retained words once, with their original identity

An extended quotation can retain an earlier literal payload without appending the
old sentence again. Spacing, case and word boundaries remain exact, inside one
quotation, with the same immediately bound original identities. Citation
renumbering can preserve identity; missing/ambiguous definitions, another quote's
citation or an ID elsewhere in Sources cannot. File targets retain their complete
paths, revisions and hashes. Definitions in later sections do not count.

If introductory evidence really is lost, restoration stays above the first content
section and keeps the new lead. This does not delete duplicates already authored
in a candidate or automatically repair saved notebooks. Literal retention does
not establish equivalent meaning, correct attribution or source truth; the
existing source audit remains necessary. Exact-quote behavior is unchanged.

## Start the scoped Claude Hook bridge without reverse DNS

The authenticated receiver still binds only `127.0.0.1` and an ephemeral port, but
fills its name/port from the bound numeric address instead of resolving a hostname.
A local getfqdn probe took 35.006 seconds; this is one environment observation, not a
universal speed promise. TCP binding options, activation, token checks, threading,
shutdown, provider permissions and global DNS settings remain unchanged. Bind
errors propagate and close the socket. This is not a Codex init latency claim.

## Evidence and limits

Source repairs #2694 and #2699 passed exact-head review and normal CI. The combined
rc26+repair tree passed 17,655 offline tests with 336 skipped in 125.48 seconds. An earlier
integration failed a provider-start marker check; it was diagnosed rather than
waived, and the original interruption/late-write assertions remain unchanged.
Version metadata, frozen dependency audit, build, installed-wheel and immutable
publication gates remain separate. The dated [acceptance record](https://github.com/openonion/connectonion/blob/v1.9.3rc27/docs/acceptance/1.9.3rc27/README.md)
and associated version PR/workflow record those results against the exact candidate.

Future page content and introductory placement can change. Reader templates, CSS,
source-popup/focus structure and scheduling are unchanged by this backend scope.
The reviewed backend manifest does not establish native UI acceptance. No fresh
real REM init, provider/model/mail/scheduler trial or real notebook rewrite is
claimed; isolated synthetic tests are not memory-product maturity.

Pending reader, translation, navigation, accounting and quote-word-boundary
candidates retain their own gates and are not included. Current desktop/phone,
privacy/accessibility, useful first-run insights and morning recall still need
proper acceptance.

## Install after publication

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc27'
```
