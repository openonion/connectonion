# ConnectOnion 1.9.7rc1 (release candidate)

Stable is **1.9.6**. Python **3.11+**.

## A Host on Claude Code you can expose, and no silent co/ model

- **`restricted:` in `.co/host.yaml`** (#3253), next to `model: claude-code/<model>`: the commands and skills a
  turn may use and a system prompt. Each turn runs the claude CLI with only those tools,
  `--permission-mode dontAsk`, project settings only, no MCP, the verified caller's address in the prompt, and a
  fail-closed PreToolUse guard that refuses any call no rule names (a chained `; cat .env` included). Without the
  block nothing changes.
- **No silent co/ model** (#3253): a Host whose host.yaml names `claude-code…` or `codex…` refuses to start when the
  agent it serves runs on another model, instead of sending every message through the managed default. `/info`
  names models as provider/model (`co/gemini-4-hydrogen`, `claude-code/claude-sonnet-5-5`).
- **New commands from contributors:** `co obsidian` reads selected folders of a local vault (#3039); `co asana`
  reads tasks and writes after a preview (#3034). The memory tool keeps a single file's header (#3035).
