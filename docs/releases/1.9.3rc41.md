# ConnectOnion 1.9.3rc41 (release candidate)

Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

## The first run, honest and short

- The consent summary shown by `co rem start` and by the REM step of `co init` is one screen:
  one line per source, then Model, Permissions, Schedule, Daily cap and Background, ending in
  `Details: co rem config`. 13 lines where there were 55; the question is on screen. The JSON
  summary, the consent fingerprint and `co rem config` are unchanged (#2758, #2765).
- The first-run estimate plans your own page only when there is material for it and scales its
  cost by the mail items and usable sessions actually mapped. A map with no people, no projects
  and no material prints `Nothing to write yet: connect a mailbox (co auth google|microsoft) or
  work in a project with Codex, then run co rem init` and exits without the estimate pause or a
  skill page; before, it asked for 13.8M tokens and 71 minutes (#2761, #2766).
- `Agent sessions: ... 3 skipped (program prompt)`: the import line says why files were skipped.
- `co rem show NAME` resolves a bare name across people, projects, orgs and skills (path, title,
  project folder, alias or email); several matches list their paths; the error names what was
  searched (#2762).

## Install after publication

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc41'
```
