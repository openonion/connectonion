# 1.9.7rc15

Release candidate for 1.9.7. Stable remains 1.9.6.

## The Control Center has one name (#3336)

- An agent's page is `.co/control_center.html`. The Host looks for `.co/control_center.html`, then
  `.co/dashboard.html`, then `dashboard.html` in the project root, and serves the first that exists without moving it.
- When an old name is the one being served, `co host` prints at startup:
  `Control Center: rename <path> to .co/control_center.html`.
- The snapshot frame is `CONTROL_CENTER_SNAPSHOT`. For one preview cycle each snapshot is followed by the same frame
  typed `DASHBOARD_SNAPSHOT`, so O Chat builds from before the rename keep rendering. It is removed in a later preview.
- The builtin skill is `control-center` (was `dashboard`): `/control-center put this week's numbers on my page`.
- `ws_router/dashboard.py` is folded into `ws_router/control_center.py`. Docs: `docs/network/control-center-page.md`
  (was `dashboard.md`). `co rem status` calls its summary a status card.
