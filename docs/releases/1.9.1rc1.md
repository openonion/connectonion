# ConnectOnion 1.9.1rc1 (release candidate)

## Install this candidate

Stable remains 1.9.0. Install the 1.9.1 release candidate by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.1rc1'
```

## What 1.9.1b5 measured

A full 180-day first run on the owner's real Gmail and Outlook, public 1.9.1b5
wheel, Codex with gpt-6-luna:

| | 1.9.1a2 | 1.9.1b5 |
|---|---|---|
| First pass, all 280 pages | about 160 min | 82 min |
| Whole run | 169 min | 145 min, including deepening 55 people with 934 older messages and attachments, and decisions/principles |
| API-equivalent cost | US$10.66 | US$11.19 |
| People / projects / organisations / skills | 84 / 14 of 20 / 27 / 147 | 84 / 19 of 20 / 25 of 27 / 146 |
| Decisions / principles | none | 5 / 1 |

Six of 336 investigations did not land. Two were lock waits that sixteen
workers and a background mail backfill made too short; this candidate fixes
those. The others were one network timeout, one model turn timeout and two
pages the review refused.

## Locks that wait long enough

Writing work already done (a fetched mail, a page, a stamp) waits up to ten
minutes for the notebook lock instead of 30 or 60 seconds: a promotion can hold
it for minutes while its cited-claim audit runs. A provider token refresh waits
up to two minutes for the credential file, which Gmail and Outlook share.

## Verification and limits

The co rem unit suite and the provider credential tests passed, with
regressions for both waits. One more full first run on this candidate decides
1.9.1.
