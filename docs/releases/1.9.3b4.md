# ConnectOnion 1.9.3b4 (beta)

## Install this preview

Stable remains 1.9.2. Install this opt-in beta by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.3b4'
```

## A handoff is the context of a session, not a task

A handoff carries a whole conversation: what was discussed, decided and still
open. The words around it said "handed you a task" (#2523). They now say what
arrives:

| Where | Before | Now |
|---|---|---|
| The pasted line | Mia handed you "…" / Mia 把「…」交给了你 | Mia handed you the context of "…" / Mia 把「…」的上下文交给了你 |
| The mail subject | Could you pick up "…"? / 能帮我接着做「…」吗？ | Handing you the context of "…" / 把「…」的上下文交给你 |
| The mail's button | See what I'm passing you | See the context I'm passing you |
| `co handoff --help` | hand a task | hand the context of your session |

The report's `## Task` section and the instructions to the receiving agent are
unchanged.

The handoff page at o.openonion.ai changed the same day, separately from this
package: the summary and the original conversation are two labelled parts, the
conversation reads like claude.ai or chatgpt.com with nothing folded, and the
diagram fits a phone.

The prompt now pins 1.9.3b4. Handoffs already sent keep the version they were
sent with.
