# ConnectOnion 1.9.0a27 (preview)

## People: institutional and service desk senders

Issue #2201 keeps correspondents with institutional display names out of
`people/`. Names containing Centre, Institute, Foundation, Hub, Labs, Team, or
会议, among other institutional terms, are classified as service desks. They
remain visible in the map report and can contribute to organisation mapping,
but do not receive a person page. Similar letters within an ordinary personal
name do not trigger this rule.

## Projects: a stronger entry gate

Issue #2202 keeps dated scratchpad task folders and prompt fragment folders
without a project manifest out of `projects/`, even when sessions recur there.
Folders with project evidence, such as a repository or a `pyproject.toml`,
`package.json`, `Cargo.toml`, `go.mod`, or `Makefile`, can still be mapped as
projects.

These changes apply when `co rem` builds a map. Stable remains 1.8.10.

## Install this preview

```bash
python -m pip install --upgrade 'connectonion==1.9.0a27'
```

To refresh an existing notebook's map without model investigation, run
`co rem init --no-investigate`.
