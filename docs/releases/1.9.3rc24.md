# ConnectOnion 1.9.3rc24: 1.9.3 freeze candidate

Opt-in preview. Stable stays 1.9.2.

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc24'
```

## Freeze

rc24 is the freeze candidate for 1.9.3. From this candidate on, the 1.9.3 line
takes only release-blocking fixes. If rc24 holds up end to end, it is promoted
unchanged to 1.9.3. A blocking fix would ship as rc25 and restart that check.

## What is new since rc23

**REM cites what it read.** When an investigation's evidence overflows one
turn and is folded into an evidence index, the originals it cites stay
reachable. The claim audit and page promotion now find them, so a page is no
longer marked insufficient because its citations pointed through the index
([#2661](https://github.com/openonion/connectonion/pull/2661)).

**REM translations keep their sources.** The `## Sources` section is copied
back byte-identical instead of being translated. A failed check (citations,
quotes, privacy labels, headings) gets one repair turn with the exact
difference before it is reported. Amounts and names are preserved, and the
translation estimate is measured
([#2622](https://github.com/openonion/connectonion/pull/2622)).

**Your company is the one you named.** A domain counts as the owner's company
only when the owner page names it, or when an owned project's domain is one the
owner writes from. A university, employer, hosting platform or client address
is never treated as the owner's company, and that company page reads only
company mail ([#2615](https://github.com/openonion/connectonion/pull/2615)).

**Muse studies what a page does not know yet.** Proposals look for new ground
instead of rewording existing bullets. The insight critic can read git history
in checkouts REM already maps, and it judges twice
([#2612](https://github.com/openonion/connectonion/pull/2612)).

**One diary-folder rule.** Sessions, project notes, file listings and page
material all skip diary folders unless the owner opted the folder in. A project
under `~/Personal` stays private until it is investigated on purpose. Leads and
open threads now agree, and History keeps a line per recent thread
([#2618](https://github.com/openonion/connectonion/pull/2618)).

**A device Host that survives the terminal.** `co init --background` prepares
a dedicated profile, and `co host` can run as a macOS user service. Formal
Watch connector and complete device onboarding are not part of this release
([#2685](https://github.com/openonion/connectonion/pull/2685)).

**An address you do not own is an error.** `co email inbox --address` with an
address this account neither owns nor can read now exits 1 and lists your
addresses, instead of reporting an empty inbox
([#2688](https://github.com/openonion/connectonion/pull/2688)).

The rc23 ASR preview (`co asr`, Python `asr()`) is unchanged. See
[ASR configuration and recovery](../asr.md).

## Requirements

Python 3.11+. The existing security floors are retained.
