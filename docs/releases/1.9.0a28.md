# ConnectOnion 1.9.0a28 (preview)

## Investigation: context over control

ConnectOnion 1.9.0a28 implements the architectural principle of **context over control** in `co rem investigate`:

1. **Tools authorized upfront**: Investigation turns for Codex (`--sandbox danger-full-access`) and Claude Code (`--permission-mode bypassPermissions`) have shell tools pre-authorized. Models can use `rg`, `git log`, `git show`, and file tools to actively search the supplied evidence index, local mail archives, and project repositories rather than relying on heavy pre-concatenated prompt dumps.
2. **Live repository paths**: Project investigations supply the live local repository path(s) directly to the model for direct inspection of manifests (`pyproject.toml`, `package.json`, `README.md`) and Git commits.
3. **Traceability afterwards**: Run records in `.state/runs/run_<id>.json` retain the complete evidence inventory (source IDs, file paths, timestamps) and the model's full inspection report. Page review rejects repository path leads when cited as if they were verified file contents.

Design rationale is documented in `docs/design-decisions/076-context-over-control-investigation.md`.

These changes apply when `co rem` investigates pages. Stable remains 1.8.10.
