# ConnectOnion 1.8.6a5

**Preview.** `pip install --pre connectonion` — a plain `pip install` stays on
stable 1.8.5.

You can find a conversation and read it back.

## The chat id comes from a command now

`send` and `reply` both take a chat id, and nothing printed one. The only way to
get one was to grep the log — which is the first thing anybody did with a new
inbox, four times, in four slightly different shapes.

```
$ co whatsapp chats
126121882435737@lid       direct  4  4  2026-09-17T04:59:17Z  Eric Fu  你好
120363410170505910@g.us   group   7  2  2026-09-17T05:00:24Z  Eric Fu  @bot 开始
#  id                     kind    n  for-us  last            who      what
```

A list of ids is useless — they all look alike. What lets you pick one is the
last thing said, who said it, and when.

**`for-us` is the column worth having.** The gap between `messages` and `for-us`
*is* the conversation happening around the bot: seven messages in that group,
two addressed to it, five that `--context` exists to carry.

Rows are tab-separated with the id first, so `cut -f1` gives exactly what the
other verbs take.

## `log` takes filters

```bash
co whatsapp log --chat 120363410170505910@g.us -n 50
co whatsapp log --sender "Eric Fu" --since 7d
```

The messages that never named the bot are in all of it. `mention_only` decides
**when the bot speaks**, not what it may read back.

- `--sender` matches an id *or* a name, because the id is unreadable and the
  name is what a person knows.
- A filtered `log` answers from the record and stops; `-f` tails the inbox.
  Both at once would be a third feature.
- `--since` takes the mail CLI's spelling — `30d`, `2w`, a date — rather than
  growing a second grammar for one idea.
- `-n` keeps the **most recent**, because a conversation is read backwards from
  its last turn.

## A note on old records

Messages written by an earlier preview come back exactly as they were stored —
no `sender_name`, no `kind`, no `quoted`. Fields are not invented for records
that predate them, which is visible in this release's own capture.

## Verified

Offline suite: 10,335 passed.

## Known, and not fixed here

- `chat_name` — a group's subject is not in the local store, so it is an API
  call per group.
- Edits, revokes, forwards, group lifecycle and view-once have no defined shape
  (#1590). The owner has said these are all inbox events; the remaining question
  is whether each one wakes a consumer or only joins the record, and that is
  being settled row by row rather than in a bug fix.
