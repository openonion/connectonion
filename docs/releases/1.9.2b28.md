# ConnectOnion 1.9.2b28 (beta)

## Install this preview

Stable remains 1.9.1. Install this opt-in beta by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.2b28'
```

## As you edited it

- **Your edits reach the session copy.** A sentence you rewrite or remove with
  `--edit` goes as you left it, in the page and in the copy; a message you did
  not touch keeps the AI's whole reply.
- **Chinese names masked in every form.** A co rem page titled "谢 红瑛" masks
  "红瑛" and "谢红瑛" as well.
- **The preview points at sensitive messages.** Messages that mention health,
  visas, the law or money (签证, 睡眠, lawyer, salary…) are listed by number, so
  you read them and drop any with `--edit`. Nothing is removed for you.
