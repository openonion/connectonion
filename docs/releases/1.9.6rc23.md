# ConnectOnion 1.9.6rc23 (release candidate)

Stable remains **1.9.5**. Python **3.11+**.

## Link WhatsApp without being at the screen

- **`co whatsapp listen --phone <number>`.** Instead of a QR code, the listener prints an
  8-character pairing code and the path on the phone: WhatsApp > Settings > Linked devices >
  Link a device > Link with phone number instead. The code lasts minutes and can be sent as
  text to whoever holds the phone. A QR changes about every 20 seconds and has to be seen.
- A number WhatsApp will not issue a code for stops the listener with exit 3 and WhatsApp's
  reason. `--phone` cannot be combined with `--restart`.
- The "not linked" and "logged out" messages name both ways to link.

Not yet run against real WhatsApp in CI; the first live pairing is on a Windows dev box.
See [docs/cli/whatsapp.md](../cli/whatsapp.md), #2161 and #3114.
