# 1.9.6rc29

Release candidate for 1.9.6. Stable remains 1.9.5.

Three things the owner found by using rc27 and rc28:

- **A source's title opens its original (#3134).** In Full memory's Sources band only the small number was a link;
  the title did nothing. The title now opens the mail, file or session in the side card. Opened from the list the
  card is the source alone, without a page line to quote.
- **A calendar event shows its own details (#3135).** REM now reads the meeting link (Google Meet, Microsoft Teams,
  Zoom, Webex: from the provider's conference data, the location or the notes), the organiser and the notes. The
  detail leads with "Join Google Meet" and ends with the provider's page as a quiet link, instead of only
  "Open in Outlook".
- **The Investigate menu and "What changed" float over the page.** The record head's rise animation made it a
  stacking context, so later cards were drawn over its popovers. The head that holds 调查 is now lifted above them.
  Tests check the opened card is topmost on a 5×5 grid.
