# ConnectOnion 1.9.0a32 (preview)

## Install this preview

Stable remains 1.8.10. Install this opt-in preview by exact pin, then follow
the [first-run guide](https://docs.connectonion.com/rem#start):

```bash
python -m pip install --upgrade 'connectonion==1.9.0a32'
```

## A Skill page should open the work it describes

Skill pages keep the mapped invocation name as their title, so a later
investigation can still find the Skill's run history. The page writer now
distinguishes the Skill's intended output from an observed, inspected result.
It links an openable artifact beside a concrete output-quality finding; when
only a run report survives, it says the result was reported and leaves the
uninspected artifact details Unknown. See
[#2241](https://github.com/openonion/connectonion/issues/2241) and
[#2234](https://github.com/openonion/connectonion/issues/2234).

The owner-only reader now shows the full bounded cited Skill run part instead
of stopping at 4,096 characters. Absolute local artifact links can open their
files from the local reader. Those files may move or change, so the page does
not claim they are immutable retained snapshots. See
[#2245](https://github.com/openonion/connectonion/issues/2245).

## Trial limits

A private 90-day first run mapped 157 Skills. One Skill needed three accepted
writer candidates to make its most useful finding checkable. The final
investigation used 715,246 input tokens (611,072 cached) and 5,319 output
tokens. Its final page distinguished the intended Skill contract from observed
drafts and linked the local files needed to inspect its output-quality finding.

Independent role-based AI review opened all 14 displayed source dialogs and
the linked local drafts and image in the rendered desktop and phone reader.
The final sampled Skill flow had no remaining P1/P2. This was an AI role review,
not human founder participation or a check of all 157 Skill pages. The long raw
run dialogs still need claim-focused navigation on phones, and the local files
are mutable and may be absent on another machine. The review did not verify
live publishing, external article claims or all 96 session parts. See
[#2246](https://github.com/openonion/connectonion/issues/2246).
