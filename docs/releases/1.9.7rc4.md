# ConnectOnion 1.9.7rc4 (release candidate)

Stable remains **1.9.6**. Python **3.11+**.

- **WeChat as a co rem source (#3270, #3261).** \`co rem sources add wechat\` reads every one-to-one chat (people);
  co rem reads WeChat for Mac's own databases in memory at read time, with no copies under \`~/.co/inbox\`. A group
  is read only when named. \`co wechat key capture\` deletes its 1.4 GB re-signed copy when done.
- **One-click key import (#3276, #3274).** The REM Keys page imports every saved login from Chrome, Edge or Brave:
  the value goes to the macOS Keychain, a page is written per login (service, account, URL, never the value), and
  the reply is counts only. 1Password/LastPass stay the CSV path for now.
