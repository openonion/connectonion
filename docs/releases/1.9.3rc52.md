# ConnectOnion 1.9.3rc52 (release candidate)

Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

## Scheduled REM keeps working after its saved time (#2814)

- A scheduled Codex turn usually finished one task and ended, so the rest of the round waited a
  day. After each saved time, Codex now checks again every 15 minutes, until the next saved time or
  for up to three hours, and continues the pending task. A follow-up with nothing due exits before
  reading any source. Run `co rem start` once after upgrading to register the follow-ups; saved
  times and consent are unchanged.
- `co rem next` prints a short header (task, stage, workspace, the file to write, the submit
  command) so it survives truncated tool output, and long material is split into readable lines.
- A refused `co rem submit` prints the reason, the file with the corrections, the file to edit and
  the command to submit again. A resumed refused task is shown as a repair with the corrections
  first, instead of the whole investigation brief.
- Changing the schedule no longer invalidates a pending task; settings that change the prepared
  material still do.
- The claim auditor is shown how to jump from a citation to its original instead of reading the
  whole packet, and leaves out a claim whose original is not supplied.

## Install after publication

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc52'
```
