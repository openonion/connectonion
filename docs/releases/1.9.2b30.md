# ConnectOnion 1.9.2b30 (beta)

## Install this preview

Stable remains 1.9.1. Install this opt-in beta by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.2b30'
```

## From whichever agent you used

- **Five more agents to hand off from.** `co handoff send` drafts from a Gemini
  CLI, opencode, droid (Factory), Cursor or Grok session, as well as Codex and
  Claude Code. Each is read where that agent keeps its own sessions; only what
  was said goes, never tool calls or their output. Without `--agent`, the newest
  session of any of them for the folder you are in is the one drafted;
  `--agent gemini|opencode|droid|cursor|grok` picks one.
- **Cursor is read without touching it.** Its conversations are read from
  Cursor's own database, opened read-only, and copied out as a session file.
- **A wait that survives a hiccup.** `co handoff status --wait` keeps waiting
  through a brief server error or dropped connection, instead of ending on a
  traceback. A refusal still stops it.

## Verification and limits

- Each format was checked against sessions the agent itself wrote on a real
  machine; a test on a synthetic session in each format fails without its reader
  and passes with it. The handoff tests pass.
- A real Gemini CLI session was drafted end to end, preview only.
- Copilot's CLI and Warp are not read yet.
- The install floor stays 1.9.2b27.
