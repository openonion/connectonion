# ConnectOnion 1.9.2b17 (beta)

## Install this preview

Stable remains 1.9.1. Install this opt-in beta by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.2b17'
```

## A session copy with nothing secret in it

When the agent that took over your handoff asks a question, your agent answers
with a copy of the session. This preview removes one more kind of secret from
that copy: a credential the AI wrote into a file through a tool call. The copy
records a tool call as JSON, where every quote arrives escaped, and the removal
now matches those too (#2434).

## Verification and limits

- Found in the 1.9.2b16 two-machine release test by reading the copy the other
  machine received. On the whole three-day session the feature was built in,
  nothing client-secret-shaped and no handoff code is left after removal.
- The new test failed on 1.9.2b16 and passes; the handoff suites pass.
- The install floor stays 1.9.2b16: the change is on the sender's side.
