# ConnectOnion 1.9.6

## Install

```bash
python -m pip install --upgrade 'connectonion==1.9.6'
```

Python **3.11+**. 47 release candidates (1.9.6rc1–rc47) fed this release; rc39, rc40 and rc41
were tagged but never published. Beyond rc47 there is one reader polish: a related card shows its
sentence without the writer's prefix, and the page foot says "Copy the file path" (#3243).

## One command, and the Host is running

- **`co init` starts the Host and leaves it running** (#3170, #3175). It uses launchd on macOS, a
  systemd user unit on Linux, and a Scheduled Task at logon on Windows. `co host` shows its state,
  and `--stop` and `--uninstall` manage it.
- A Linux login with no systemd user session (a container, CI, or SSH without linger) has no
  background service. There `co init` says the Host was skipped and finishes; run `co host --serve`
  instead (#3216).
- **The model is one line in `.co/host.yaml`:**

  | `model:` | What answers |
  |---|---|
  | `claude-code` | The Claude Code you are logged into, with no API key |
  | `claude-code/<model>` | That Claude Code model |
  | `codex` or `codex/<model>` | Native Codex |
  | Any other model name | The co-ai agent on that model |

  The front end does not change when this line does.
- A `claude-code` Host names a missing Claude login. On Windows, a Host started from an elevated
  shell can read its profile, and counts as running only once it answers.
- A Host the relay refuses stops and gives the reason.
- Serving your own `agent.py` is now an explicit `co host --agent agent.py`.

## REM: the new desk

- **A redesigned reader.** It covers Today, person and organisation records, a People table, a
  Projects board by state and one Knowledge place.
- Today on a phone puts the letter first and no longer zooms out.
- The reader adds a calendar and agenda in Today, a reading measure, and tags everywhere.
- **A knowledge graph.** A tag links pages, and a tag that two or more pages share gets its own
  page (`co rem tag`, `co rem investigate tag`). A closed item stays closed.
- **Three privacy levels** in the top bar cover every place a passage shows.
- **Hand-offs to Codex and Claude you can watch.** Each one runs in its own tmux session with live
  steps, a one-line result in the notebook's language, and a way to continue it in Codex or
  Claude Code.
- **Mark done · Not now · Ignore** on every item, with ignored senders, real names and Send
  feedback.
- Source titles open the original, and a source card is never empty. Citation chips open their
  source beside the page.
- **The night is sturdier.**
  - A mailbox failure, an unreadable folder or a page past its deadline no longer stops the round.
  - Failed turns are recorded as failed, and each notebook has one lock.
  - Translation and tagging go on past the Codex floor up to a small ceiling.
  - An open tab survives an upgrade.

## Agents and inboxes

- **`co send` / `co receive`:** files between agents, verified by sha256 and resumable. Small files
  wait on the server for an offline recipient.
- **`co wechat`** reads your own WeChat for Mac history locally, read-only.
- **WhatsApp:**
  - It connects again and reads group history.
  - It can download older media.
  - `co whatsapp listen --phone` links by pairing code instead of a QR code.
- **`co browser`:**
  - `keyboard_type` pastes by default.
  - It inserts through CDP when a paste does not land.
  - It runs headless in Windows session 0.
- **Windows hosts** work end to end: the inbox, the listener log, announce within the relay
  limit, and bash through Git Bash or cmd.

## Trust and accounts

- Every automatic Host run is recorded in `co approvals`. Revoking a requester stops their turn
  between steps, even after they left (#3025).
- **`co server`** servers are paid monthly in advance, and destroying one refunds the unused part.
- **The default model is `co/gemini-4-hydrogen`** (Gemini 4 Hydrogen).

## Upgrading from 1.9.5

- `co init` now starts a background Host. Pass `co init --no-host` to skip it.
- An existing Mac profile keeps its one service and native Codex. The pre-1.9.6 flags still run.

Everything in [1.9.5](1.9.5.md) ships here. The candidates that built it are 1.9.6rc1–rc47; see
[release channels](../releases.md).
