# ConnectOnion 1.9.2b22 (beta)

## Install this preview

Stable remains 1.9.1. Install this opt-in beta by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.2b22'
```

## Everything arrives with accept

- **The agent does the work without waiting** (#2452). The block the person
  pastes now says to do what `accept` says, and to report afterwards. In
  1.9.2b21 its last step said "tell me what you will do", and two Codex versions
  stopped right there.
- **Your code travels with the handoff** (#2469). Commits on no remote go as
  `git format-patch`, and uncommitted changes, new files included, as a diff.
  The preview says what goes and the credential check reads it. `accept`
  rebuilds the repository in the recipient's folder and says where it is.
- **The session copy comes with accept.** It used to come with the first
  answer, which waited for the sender's machine to read its mail.
- **The opened thread waits for answers** (#2473). `co handoff open` keeps
  `status --wait` running, searches the session copy first, and the inbox names
  the sender by name.

## Verification and limits

- Found by the 1.9.2b21 stranger runs on Parrot (Codex 0.162.1) and
  melbourne-2 (Codex 0.156.1, empty home): both stopped after saying what they
  would do, in an empty folder.
- Each new test failed first; 127 handoff tests pass.
- Code over 1.5 MB does not travel; the preview says to push it. Untracked
  files are included, ignored files are not.
- The install floor is 1.9.2b22.
