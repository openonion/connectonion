# 1.8.7b2 — Wiki memory workflow preview

An opt-in preview following the initialization fixes in b1. Stable remains 1.8.6.

```sh
python -m pip install --upgrade --pre connectonion==1.8.7b2
co wiki open
co wiki review
```

New commands retain attributed corrections and reflections, review questions and
candidate connections, capture recognized local user messages into a durable queue,
and run maintenance followed by at most one bounded investigation. Explicit stage
routes enable saved questions, findings and method-review artifacts. Optional voice
responses use a locally installed whisper.cpp executable and model; there is no cloud
fallback. The reader shows review candidates with commands for recording decisions.

See [workflow commands](../cli/wiki-memory.md) and the
[acceptance scope](../acceptance/1.8.7/memory-preview.md). Raw reflections are retained;
compact views are lossless projections, not semantic summaries. Existing background
jobs still run sync. Budgets count model calls, not subscription percentages or dollars.
No automatic external sharing, raw-data deletion or executable skill rewriting.

The preview implements concrete parts of #1520, #1523, #1609, #1610 and #1611; it does
not close their remaining design and live-quality acceptance items. In particular,
citation validation is not proof that a model's conclusion is true.
