# ConnectOnion 1.9.7rc5 (release candidate)

Stable is **1.9.6**. Python **3.11+**.

## The Control Center has an admin section

For callers whose address is in the Host's `admins.txt`, the built-in Control Center now carries a folded
**Admin** card (#3263, #3268). Anyone else's page never contains it, and every admin command is checked against
`admins.txt` again when it arrives.

- **Admitted:** who joined and how (invite code, payment, added), when, last seen, with **Remove** and **Block**.
  An admin cannot be removed or blocked from here.
- **Invite code:** the current code, **Rotate** and **Turn off**, applied to the running Host with no restart.
- **Activity by caller:** turns, failures and last time per caller, never the prompt text.
- **Waiting for approval**, **Health** (model, version, relay, uptime, last failed run) and the last lines of the log.
- A `restricted:` Host lists its skills under Capabilities instead of "None published".

The buttons need O Chat's matching update (oo-chat#275). Known gaps (#3269): a removed caller keeps an
already-open socket until it reconnects, and the card refreshes on connect and after an admin action.
