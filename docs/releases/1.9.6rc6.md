# ConnectOnion 1.9.6rc6 (release candidate)

Stable remains **1.9.5**. Python **3.11+**. Dependency floors are unchanged.

## REM reader

- **Mark done is in the action strip.** Each row's strip (Codex, Results, Undo, Talk) now holds
  Mark done too, once per row, so finishing something no longer means looking for a separate button.
  A row REM already thinks is handled shows its strip without a hover (#2955).
- **One button switches the language.** Beside the day/night switch, one click changes the whole
  reader between 中文 and English and keeps your place on the page (#2955).
- **No old server serves the reader after an upgrade.** `co rem open` now uses a co ai only when its
  version is the installed one. The Host co rem itself started before the upgrade is replaced on its
  own port, so an open tab works again after a reload; it is replaced only when no run or scheduled
  turn is in flight. Any other co ai of another version (one you started by hand, on port 8000 or
  elsewhere) is never used or stopped; the reader shows its snapshot and one sentence names that
  server's port, version and process id (#2959, fixes #2937).

There is nothing to do: install this release and run `co rem open`.

## Install after publication

```bash
uv tool install 'connectonion==1.9.6rc6' --with onionwright --prerelease allow --force
```
