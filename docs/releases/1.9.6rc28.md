# 1.9.6rc28

Release candidate for 1.9.6. Stable remains 1.9.5.

## The night runs again (#3128)

- Since 2026-11-18 every night turn stalled 600 s five times at "preparing the next task": finishing a skill page
  waited on the maintenance lock that `co rem next` already held. It now passes the held lock down.
- The finishing step is named, so a stall parks that page and the round moves on; five unnamed stalls in a row
  hold that step for six hours and say so in status.
- The Codex quota is read by the launcher outside the sandbox and handed down, so the budget is no longer blind.

## Investigate appends to long pages (#3105)

- A page already over the length limit could never be appended to: the size check asked to fold History, the
  append rule refused any dropped line. Now the program moves the oldest dated History lines, word for word with
  their sources, to an archive beside the page and links it from History. Nothing is lost.
- A stopped run says why in one plain sentence, in the reader's language.

## The live reader recovers after an upgrade (#3112, #3130)

- A failed background rebuild retries as soon as the installed release changes; a manual rebuild says when another
  build holds the pages.
- A Host that died is replaced even while the relay still lists it.
- A new Host reuses the port it had when that port is free.

## Reply policy in one click (#3121)

- The reply card's and person page's ⋯ offer "以后直接发给他 / 以后先给我看", recorded with a reason, and "never" for
  drafts only. A reply REM sends itself never leaves before 07:00 local, and a reply carrying a private fact is held
  whoever it is for.

## Person header (#3131)

- Wrapped dotted lines never start with a dot; the overdue Today link is text; an address or link keeps one line
  with its qualifier under it.
