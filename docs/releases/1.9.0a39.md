# ConnectOnion 1.9.0a39 (preview)

## Install this preview

Stable remains 1.8.10. Install this opt-in preview by exact pin, then follow
the [first-run guide](https://docs.connectonion.com/rem#start):

```bash
python -m pip install --upgrade 'connectonion==1.9.0a39'
co rem open --local
```

## Open the source beside a Skill finding

The small numbered citation after a REM Skill finding could be hard to tap on
a phone. A cited finding now has separate, 44-pixel source links directly below
its lead statement. Each link opens that numbered archived original. The
existing **View sources** route and the full memory remain available, and
multiple links wrap instead of widening the page.

The links use a visible keyboard focus ring on the dark lead card. When the
finding is labelled personal or sensitive, hiding labelled passages also hides
its direct source links. This change addresses the sampled Skill finding in
[#2273](https://github.com/openonion/connectonion/issues/2273). It changes the
local reader's presentation, not saved memories or source bodies.

## Trial limits

An invented cited Skill and one read-only private Skill sample were inspected
in Chrome at desktop and phone widths. The check covered direct source links,
the existing View sources route, focus return, privacy hide/show, first-screen
layout and horizontal overflow. It does not validate the Skill's claims or
establish that every citation on every page has a 44-pixel direct target.
