# ConnectOnion 1.9.3rc37 (release candidate)

Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

## Stopping `co host` stops the agent

- `co host` used to start `./agent.py` as a child process. Stopping it with `kill <pid>`
  or closing its terminal ended only the `co host` wrapper; `agent.py` kept running with
  PPID 1 and held the port, so the next `co host` failed with "Port 8000 is already in
  use". On macOS and Linux, `co host` now becomes `agent.py` (`os.execve`): the same PID,
  terminal and environment. SIGTERM, SIGHUP and SIGINT reach the agent itself, and
  SIGINT ends with a clean shutdown instead of SIGKILL (#2748).
- Under `co host --background`, the pid launchd tracks, and `co host --status` reports,
  is now the agent's own. `co host --stop` already stopped the agent and still does.
- Listen channels from `.co/host.yaml` run inside `agent.py` and stop with it.
- Windows is unchanged: `co host` still runs `agent.py` as a child.

## Install after publication

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc37'
```
