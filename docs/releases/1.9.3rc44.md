# ConnectOnion 1.9.3rc44 (release candidate)

Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

## The native REM path works on a real notebook (#2778)

- `co rem submit` refused every task whose sources had later mail in two or more threads with
  "Task input changed", although nothing had changed: the later-in-thread list followed each
  process's string hash seed, so the source-view digest recorded by `next` never matched the one
  `submit` recomputed. The list is now ordered deterministically (sources sorted, rows oldest
  first, ties broken on id). Reproduced and verified on the owner's notebook: the same task now
  hashes identically under three hash seeds.

## Install after publication

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc44'
```
