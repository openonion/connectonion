# ConnectOnion 1.9.1b2 (preview)

## Install this preview

Stable remains 1.9.0. Install this beta by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.1b2'
```

## The first run no longer waits on your mailbox

On 1.9.1b1, with 16 pages in flight, 13 of them were waiting for Gmail or
Outlook: each person's first investigation fetched two years of mail from the
provider before the model could start.

Now the first pass reads only the mapped window, the last 180 days, whose mail
bodies init already saved on disk. Four background workers fetch the rest of
each person's two years into the same local archive at the same time. When the
first pass is done, people whose backfill found older mail get a second,
deepening pass: it reads those older messages from disk, in rounds, and adds
what they show to the page the first pass wrote.

A mail body already kept on disk is never fetched from the provider again.

## One citation is not a page, on every path

Project pages written for the first time from their own coding sessions go
through their own writer, which promoted once with no repair. 1.9.1b1's
last-resort line drop never reached it, and its first real project page was
refused for one untraceable citation. Both writers now share the same rule:
when only citations fail, the lines resting on them go and the page stays.

## Verification and limits

The co rem unit suite passed, with regressions that failed on 1.9.1b1 first for
the project writer and for reading kept bodies from disk. A full first run on
this beta decides whether it becomes 1.9.1.
