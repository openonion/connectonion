# 1.9.7rc32

Release candidate for 1.9.7. Stable remains 1.9.6.

## Modular REM Reader source tree, overnight quota window, atomic upgrades, and stable local port

- **Zero-build modular `connectonion/rem/reader_ui/` (#3478):** Replaces the 22,113-line `reader.html` monolith with 20 domain-cohesive files (`shell.html`, 6 stylesheets in `styles/`, 13 script modules in `scripts/`) assembled deterministically in memory under 2ms via `reader_template.py` (`ReaderTemplatePath`), preserving offline `file://` snapshots and pure-Python wheel installs with zero Node build steps.
- **Five-start `overnight` schedule profile (#3480):** Adds opt-in `schedule.profile = overnight` with five starts inside `00:00`–`03:00` (`00:00`, `00:45`, `01:30`, `02:15`, `03:00`) and a hard `03:30` continuation cutoff in `codex_schedule.fire_times()` so overnight upkeep finishes at least five full hours before daytime coding starts, keeping rolling five-hour agent quotas clean while leaving existing `default` and `dense` schedules unchanged.
- **Atomic overnight upgrades & morning REM open (#3363, #3474):** Adds `co rem upgrade` (`status`, `run`, `enable`, `disable`, `morning`) backed by staged verification in an isolated `UV_TOOL_DIR` with automatic rollback on swap failure, active REM turn lock deferral, post-upgrade `live.html`/`data.json` HTML cache prewarming + idle Host renewal, resilient scheduled command wrappers, and install-method guards that never touch editable checkouts, project virtualenvs, or system Python.
- **Stable local port `18765`, tab deduplication & extended upgrade reload:** Pins REM's local live Host to dedicated preferred port `18765` (stepping deterministically through `18765`–`18784` only if busy), tracks active reader heartbeats on `/rem/version` (`active_reader_age_s`), focuses existing local REM tabs on macOS before opening another, adds safe GUI-only daily-deduped `co rem open --morning`, and extends browser `waitForNewBuild` polling from 80s to 180s with a persistent `Newer page · Reload` fallback.

Install this preview with an exact version pin.

```sh
python -m pip install --upgrade 'connectonion==1.9.7rc32'
```
