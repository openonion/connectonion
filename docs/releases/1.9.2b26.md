# ConnectOnion 1.9.2b26 (beta)

## Install this preview

Stable remains 1.9.1. Install this opt-in beta by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.2b26'
```

## Nobody else's details

- **Other people's contact details stay home.** Email addresses, phone numbers
  (mobile, landline, 1300/1800, Chinese mobiles) and IP addresses that are not
  yours or the recipient's are masked on the page, in the mail and in the
  session copy, and so are the `co rem` page names and LinkedIn ids that point at
  a person. The preview says how many, in the brief and in the session copy.
- **Take a page down at once.** `co handoff withdraw <id>` stops its page and its
  pickup now, not after 30 days.
- **Choose the language.** `--lang en` or `--lang zh` writes the report and the
  mail in that language; your own words stay as you wrote them.
- **Status in one line.** "bob finished it · their file saved · 2 questions (you
  answered 1)". Your own answers show as yours; a question the session copy
  cannot answer waits on you instead of getting the same pointer again; after a
  patch comes back, Next is the `git apply` that applies it. `--verbose` adds
  addresses.
- **The page reads as a chat.** Your messages on the right, each AI turn's final
  reply on the left with how many steps came before it; a message typed twice
  shows once; long code scrolls.
- **From the right mailbox.** With Gmail and Outlook both connected, `--via
  outlook` names your Outlook address.

## Verification and limits

- Each change has a test that failed first; the handoff and trust tests pass.
- Masking was checked against a real 7 MB session that had run `co rem`: no
  real email address, phone number, IP or person page name survives, and
  ordinary words are unchanged. It takes about 7 seconds.
- The install floor is 1.9.2b26.
