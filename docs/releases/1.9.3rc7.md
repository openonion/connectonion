# ConnectOnion 1.9.3rc7 (maintenance release candidate)

## Install after publication

Stable remains 1.9.2. After the immutable-tag workflow publishes this candidate,
install only this exact preview:

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc7'
```

## REM must not remember its own prompts as yours

Windows drive and UNC task directories now receive the same internal-work
exclusion as POSIX REM task directories (#2318, #2548). A Codex model-access
probe or Claude repair instruction inside `.state/tasks` is not user context.
Skill invocation counts and cached evidence samples use the same path check.
Ordinary user sessions remain available, even when they share the
`connectonion` originator. Cached counts are filtered without a forced rescan.

## Verification and limits

- Ten invented collector cases and one cached-count case failed before repair.
  All 56 focused source-import/skill-sampling regressions pass after repair,
  including ordinary Windows user sessions and similar directory names.
- The fix PR passed Python 3.10–3.13, platform, metadata, blog and CodeQL CI;
  separate AI source review found no blocker.
- These are lexical producer-path checks and synthetic transcript replays,
  not a native Windows real-account first run or proof of generated-page quality.
- Already imported messages and claims are not purged or rewritten. #2318
  stays open for manual real-trial acceptance and existing-memory review.
- Reader appearance is unchanged. The separate source-modal keyboard fix
  #2546 remains draft pending native keyboard and screenshot acceptance.
- The remaining limitations from [rc6](1.9.3rc6.md) still apply. Durable morning
  recall, real nightly acceptance, mobile and accessibility maturity are not
  established by this maintenance candidate.
