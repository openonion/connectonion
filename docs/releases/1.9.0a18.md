# ConnectOnion 1.9.0a18 (preview)

REM's first-run owner page can now surface a cited change of decision and its
next step. Before the full writing turn, it collects a small packet of dated
coding-message excerpts. The packet keeps earlier and later source IDs even
when the quick pass already used one of them, so the writer can compare the
original words. The owner guidance requires an observed choice or result for
`Changed:` and treats requests as unverified intent.

The reader now puts the owner's change and next step ahead of the long note,
labels the owner's activity as activity, and links the first exact, cited
project mention to its project page. A separate citation fix lets a fact
restored from mail outside the quick-pass sample retain its original source
without failing promotion. Unidentified invented citations still fail.
Project README excerpts now name the file in prose while keeping the full
path in the citation ID, so long checkout paths do not consume the excerpt's
bounded text allowance.

## Evidence

The [visual review](../design-evidence/rem-owner-aha-a18/REVIEW.md) compares
an invented owner page before and after at desktop, intermediate and phone
widths. The phone check includes keyboard navigation into the related
project. All screenshots use synthetic data.

A fresh isolated private five-day init completed both owner writing passes and
reported no errors. Its owner page led with an actual earlier-to-later choice,
cited the original messages, kept the requested outcome unverified, and had
three cited Insight bullets and six internal links. No private page text or
screenshots are published. This single run is evidence of a useful first-run
path, not a distributional quality claim.
