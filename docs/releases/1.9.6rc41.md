# ConnectOnion 1.9.6rc41 (release candidate)

Stable remains **1.9.5**. Python **3.11+**.

rc39 and rc40 were tagged but never published. Both release builds stopped at the same wheel check,
which runs `co init --yes` offline under a temporary HOME. rc40 handled a machine with no systemd
user session, but the GitHub runner has one: the unit was written under the temporary HOME, which
the user manager does not read, so `systemctl --user enable` failed. That check is about global init
writing no project files, not about the Host, so it now passes `--no-host`. The code is rc40's.
See [rc39](1.9.6rc39.md) for what this candidate brings and [rc40](1.9.6rc40.md) for the init fix.
