# 1.9.6rc38

Release candidate for 1.9.6. Stable remains 1.9.5.

REM's fixes from the rc35 and rc36 bug hunts on the live reader.

## Changed

- **One header on every record page (#3203, #3131).** Person, organisation and project pages share one action slot,
  调查 then 查看来源 →, in the same place and style. When there is nothing new to read, 调查 stays the same button,
  disabled, with the reason in its tooltip. A person's header says each fact once: the organisation once, tags in the
  header, rows that repeat the organisation dropped, and a profile link listed twice shown once.
- **Organisations named as organisations (#3206, #3157).** People's organisation column and filter never show a code
  or a bare domain. A domain reads as its organisation page's name, and a short and a full name of one company are
  one organisation. A page linked under a unit's label goes by the organisation's own name.
- **不是人 (#3206).** A contact that mails from the domain of an organisation whose page describes an assistant or an
  automated service is filed under agents and services, not People. A 不是人 button on the People row and the person
  page moves anyone else out; the choice is remembered, the night follows it, and 是人 moves them back.
- **The cheap stages go on past the Codex floor (#3211).** Above `limits.quota_floor_percent` the night used to serve
  nothing. Translate, tag and tag pages now continue up to `limits.cheap_ceiling_percent` (default 97). Older
  releases reject this new config key, so don't downgrade a notebook that has saved it.

## Fixed

- **Text seams (#3204).** A date follows its own sentence's language, not the block's. After a hidden passage is
  removed, the next English sentence starts with a capital, and a stripped citation leaves no space before its full
  stop. Words on record pages sit at the 13px floor.
- **Hex ids inside links (#3209).** Only a hash that stands alone in prose becomes a 提交 chip. A URL's last segment,
  a page slug, a file name and an email keep their hex.
- **Today says what is happening (#3210).** An event that has started shows as 进行中 · 至 … above the next events,
  instead of heading the list with a future-looking time. A run of failures that share one code error says so and
  that an update fixes it, instead of "不需要你做什么". Dates no longer wrap across lines, and the three counts say
  how they relate.
- **No more 实体 (#3208, #3140).** REM's writer and translation rules never call an organisation an entity or 实体.
  Pages already written keep their wording until they change.
- **The People name column stays put** when the table scrolls sideways (a regression in #3206, fixed before release).
