# 1.9.7rc21

Release candidate for 1.9.7. Stable remains 1.9.6.

## A refused draft says so, and what happens next (#3398, #2235)

- When the page check refuses an investigation's draft, the page says it is unchanged, in the owner's words, with what
  the check found one click away.
- What happens next comes from the refusal ledger the night retries from: 今晚会再试一次 while a retry is left, or
  试了 N 次都没通过，已暂停 · 想再试就点调查. Nothing is promised the scheduler will not do.

## One night, one count (#3399, #3396)

- Today's 昨夜 heading adds up the curve's own stretches, with the captions' words: reads are items, not mails.
- The side line says what it counts (待办), and a stopped Codex task beside a running one reads as another task.

## An organisation's connections give their reason (#3400, #3397)

- A 关联 row gives the line that links the two pages, never the other page's version note. With no written reason it
  says which page names which: 这页里提到过 / 它的页面提到这里. The owner's own people are not drawn inside a client's
  org tree because a thread named them.
