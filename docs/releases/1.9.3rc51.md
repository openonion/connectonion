# ConnectOnion 1.9.3rc51 (release candidate)

Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

## REM investigations research beyond the mailbox (#2810)

- Pages read like ledgers of email: role, company, links and time zone stayed Unknown, and
  investigations ended on questions one web search answers. An investigation now starts from the
  one to three questions that would change your next step, and pursues them through your mail
  and outside sources: `co search`, `co fetch`, `co browser` (its own tab; LinkedIn pages are never
  opened), and read-only `co gmail` / `co outlook`, `lark-cli` and `gh`. The answers lead the page.
- What the agent read is saved with the task and checked like mail: quotes must match it.
- Pages are edited, not rewritten. A value already on the page is never replaced by Unknown, and
  a time zone is filled from an unambiguous cited location.
- Labelled inference ("Inference: … because …") is welcome; a single fixable audit finding goes to
  repair instead of rejecting the page.
- A Codex session file that disappears while REM reads sessions is skipped instead of failing the
  investigation.

## The native schedule no longer loses a slot (#2812)

- Preparing a new round takes about a minute. Codex's tool returned early with no output, a second
  `co rem next` said "busy", and the Scheduled session ended the slot without starting the round.
  `next` now prints progress at once, and a second `next` waits for the first and takes its task.
  `co rem start` refreshes the Scheduled prompt with the same rule; no new approval is needed.

## Mail consent follows `--mail` (#2809)

- `co rem init --mail gmail` approved every connected mailbox; now only the selected ones are
  approved, and background investigations read only approved mailboxes. File errors name the file.

## Install after publication

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc51'
```
