# ConnectOnion 1.9.6rc16 (release candidate)

Stable remains **1.9.5**. Python **3.11+**.

## REM reader: organisations

- **The Organisations table never prints «Unknown, not investigated yet» as a fact.** In rc15 an
  uninvestigated unit still showed the placeholder under «What they do» when it arrived through a
  cached relationship field in mixed languages. Every summary the list and the page print now
  passes one test, whichever field or translation carried it; a cell with nothing real shows a
  dash (#3036, #3037).
- **An organisation whose kind is `company` renders.** Translating that kind in the breadcrumb
  threw before the page mounted.
- **A long location is clamped to two lines** in the table; the full text stays in the title and on
  the organisation's page.

## Upgrade

```bash
uv tool install --force 'connectonion==1.9.6rc16' --with onionwright --prerelease allow
```
