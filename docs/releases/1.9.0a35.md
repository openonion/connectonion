# ConnectOnion 1.9.0a35 (preview)

## Install this preview

Stable remains 1.8.10. Install this opt-in preview by exact pin, then follow
the [first-run guide](https://docs.connectonion.com/rem#start):

```bash
python -m pip install --upgrade 'connectonion==1.9.0a35'
```

## Sources beside the first claim on a phone

Written REM pages with numbered sources now place the 44-pixel `View sources`
action inside the lead card, directly after the useful statement. Narrow-screen
spacing keeps the full action within the first 375×812 viewport on the five
sampled page types. The action still opens the record's Sources section; Full
memory stays permanently visible below the lead. See
[#2268](https://github.com/openonion/connectonion/issues/2268).

In a read-only snapshot of one private 90-day notebook, the action ended at
y≈798 for Owner and between y≈694 and y≈760 for Organisation, Person, Project,
and Skill. Each was 44 pixels high and worked. The same five pages were opened
at 1440×900; neither width showed horizontal overflow or JavaScript page
errors in this sample. An independent role-based AI founder/marketing/UI
reviewer reopened Home, four indexes, the five written page types, 15 sampled
source dialogs and five phone privacy states; no new P1/P2 appeared in that
sample. A final phone/desktop keyboard-focus recheck found a visible light
outline and working Enter navigation. An invented-notebook browser test also
exercises these five page types and source navigation.

## Trial limits

This round changes the reader layout only. It does not write or reinvestigate
pages, spend model tokens, or complete the 255 unfinished pages in the broader
first run. The five-page layout sample and invented-notebook test do not prove
every record or responsive width works, or that future claims are accurate.
