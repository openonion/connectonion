# ConnectOnion 1.9.2b25 (beta)

## Install this preview

Stable remains 1.9.1. Install this opt-in beta by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.2b25'
```

## A note in your own voice

- **The mail sounds like you.** "Hi, I've been working on … and I'd love your
  help taking it from here", signed with your name, from your own mailbox. In
  Chinese if you worked in Chinese, and never mixed.
- **The button shows everywhere.** Gmail on iOS dropped the button's colour and
  left a blank gap. It now carries its colour three ways, so every client draws
  it.
- **Your session shows up in their Codex app**, with each message labelled
  "(Aaron · 13 Oct)" at the time you said it.
- **Only the code you worked on goes.** That means the repository the handed-off
  messages worked in last; the preview names its files, and `--no-code` sends
  none.
- **Shorter AI replies, your words whole.** Each AI turn is quoted to 800
  characters, and everything you wrote goes word for word.
- **No waiting forever.** When the sender has not answered in about 10 minutes,
  the recipient's agent finishes with the most conservative choice and says
  "Assumed: …".

## Verification and limits

- Each change has a test that failed first; the handoff and trust tests pass.
- The install floor is 1.9.2b25.
