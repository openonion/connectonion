# 1.9.0a7 — what 1.9.0a6's acceptance run found

An opt-in preview of 1.9.0. Stable is 1.8.9. Everything here was found by
running 1.9.0a6 on a copy of the owner's notebook.

## Spend less for nothing

- **A refused page is not retried with the same material.** A project page over
  the 20k limit was refused, then retried and refused again every sync with the
  same messages: about 260k tokens a night for no change. It now waits for
  newer messages, and its prompt states the page's size and the limit (#2026).
- **The daily cap is 50 calls**, the owner's choice: the scheduled slots had used
  26 of 30 by 06:00, so a sync started by hand during the day was refused. A
  notebook still on the old default reads as 50; a value you set is kept
  (#2032).
- A company writing as itself (an investor update signed by the company) is a
  service, not a person to investigate (#2031).

## Your own page

- **It names what you are working on**: the busiest recent projects with dates,
  from the map. Claude Code and Codex are your tools, never a person you owe or
  last contacted (#2027).
- Addresses tidy folds into your page carry a citation saying why they are
  yours, and Uncertainties those folds settled are removed (#2028).

## Runs that say what they did

- `co rem sync` prints each step as it starts, also off a terminal (#2033).
- An investigation with nothing new exits 0 and points to `co rem show` (#2034).
- A refused task keeps no copied material (#2029); run records key stage times
  by stage (#2030).
- A stalled init mail archive shows in `status` and `doctor`, and the next sync
  resumes it, reusing every body already saved (#2035).
