# ConnectOnion 1.9.6rc4 (release candidate)

Stable remains **1.9.5**. Python **3.11+**. Dependency floors are unchanged.

## REM reader

- **Done, Undo and Skip are saved however much mail the notebook holds.** Once a notebook's mail
  history grew large, each mark was refused by the notebook, yet the page said it was saved on this
  device and waiting to sync. The mark never arrived and the thread kept coming back. Now each mark
  sends only what its own thread needs, so it reaches the notebook at any size. Marks left waiting
  in your browser from before go through on the next load. If the notebook does refuse a mark, the
  page says **Not saved** with **Try again** and the thread comes back; only a mark that got no
  answer is described as waiting to sync (#2944, fixes #2936).
- **Organisations, Projects, All records and Skills load while REM updates.** While REM was building
  a newer version of the reader, those pages failed with "Unexpected non-whitespace character after
  JSON", because the "Updating…" notice was added to the data they load as well as to the page. The
  notice now goes on the pages only, and the details load as usual (#2954).

There is nothing to do: install this release and reload the reader.

## Install after publication

```bash
uv tool install 'connectonion==1.9.6rc4' --with onionwright --prerelease allow --force
```
