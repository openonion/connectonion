# ConnectOnion 1.9.6rc40 (release candidate)

Stable remains **1.9.5**. Python **3.11+**.

rc39 was tagged but never published: its wheel check ran `co init --yes` on a GitHub runner,
which has `systemctl` but no systemd user session, and init exited 1. rc40 carries everything
from [rc39](1.9.6rc39.md) plus the fix.

- **`co init` on a machine with no user service manager** (#3216): containers, CI and SSH logins
  without linger now print "Background Host skipped" and finish with exit 0. A service manager
  that is present and then fails to start the Host still fails init.
- **Handoff floor** moves to 1.9.6rc40, so a recipient is never told to install rc39.
