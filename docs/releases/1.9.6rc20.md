# ConnectOnion 1.9.6rc20 (release candidate)

Stable remains **1.9.5**. Python **3.11+**. Everything here is REM (`co rem`).

## What a night costs

- **Workers run at the configured effort.** The runner now passes the notebook's `effort`
  (default `medium`) to every Codex worker and to the cited-claim audit. Before, it passed
  none, so workers inherited the global Codex setting. Measured over three real nights: 81 of
  81 worker turns ran at `max`, and one complete night took about 28 points of a Codex week.
  `co rem status` names the model, effort and speed of the last run. `co ai` gains `--effort`
  for Codex. Not yet measured: what a night costs at `medium`.
- **A round's own record no longer joins the day's runs into one quota group.** It charged the
  whole day's meter movement to investigation and held 332 pages for a budget that was not spent.
- **A spent investigation budget holds only new investigations.** Sessions, Abstract,
  translation and deepening go on.
- **Usage is summed over a task's turns**, and a parked or timed-out turn records what it used.

Still open: the points formula undercounts (it ignores cached input and the model), and the
default speed `fast` selects the priority service tier.

## One run per notebook

- **`co rem catchup`, `co rem exec` and the scheduled turn hold one lock.** The second to arrive
  says another REM run holds the notebook and starts nothing. Before, a scheduled turn could
  hand out the task a catchup worker was writing and discard it.
- **A worker turn that times out parks its page and the round goes on.** The turn is
  interrupted and its process group ended first. Two faults in a row still stop the round.
- **A task prepared by another version is not parked as "input changed"** because a new default
  limit appeared. A test now requires every limit to be classified.

## What a night does

- **Shares per stage.** A night takes up to 12 investigations (skill pages last, at most 3),
  and between portions writes summaries, runs an Abstract round, translates and deepens, so no
  stage waits for another to finish its backlog.
- **A preparation that passes its deadline is interrupted inside the round**, the page is
  parked, and its batch keeps the scan progress it made.
- **Abstract refuses a decision page that says its own reason or alternative is unknown or
  inferred**, and asks for the `not-a-decision` verdict instead. Pages already written are not
  revisited.
- **Repairs that could not succeed now can.** A capture entry that is neither a URL nor a
  source ID gets a repair turn; a dropped source counts only if a sentence cited it; when only
  dropped-source errors remain, the removed lines are put back and the page is accepted (a
  line removed on purpose comes back too).
- **Mail.** A citation of an attachment resolves to its message without a mailbox request, and
  a mailbox read refused with a 4xx parks that page only.
- **Paths.** A file name too long for the file system is skipped rather than ending the round.

## What the night says

- The night's line reads "81 pages written (66 of them decisions)", gives each parked cause in
  a few words with its count, and counts a page whose enrich turn failed as not deepened. Raw
  refusal text, source IDs and local paths are no longer printed there.

the version digest were written after the last real night and are covered by unit tests only:
