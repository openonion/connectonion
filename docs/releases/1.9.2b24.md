# ConnectOnion 1.9.2b24 (beta)

## Install this preview

Stable remains 1.9.1. Install this opt-in beta by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.2b24'
```

## One line to paste, and a page to read first

- **See it before installing anything** (#2478). The mail's first button opens
  `o.openonion.ai/h/<id>`. There the person reads who passed them what, what
  was discussed, decided and still open, the diagram and the conversation. It
  works on a phone or a computer, in their language.
- **Then one line into Codex.** The page's "Copy to Codex" button, or a
  triple-click in the mail, copies a single sentence. It names a page that holds
  the rest, and their Codex reads it, installs co, accepts and starts. Without
  network access it asks for it once, in one sentence.
- **Handoffs, not keys to your machine.** When you accept someone's handoff,
  they can send you handoffs and questions, but they can't run tools on your
  machine. Your own handoff's recipient still can use what your Host allows.
- **A name, never an address.** A sender with no name shows as "Someone".

## Verification and limits

- The one-line import was tested on Codex 0.156.1 from an empty home folder.
  With network it went from paste to done with no person steps; without network
  it asked once and stopped.
- The install floor is 1.9.2b24.
