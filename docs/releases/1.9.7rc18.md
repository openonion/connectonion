# 1.9.7rc18

Release candidate for 1.9.7. Stable remains 1.9.6.

## The night cannot loop on one task (#3377, #3376)

- Tagging checks every page before it writes any. A page whose Tags line cannot be set without touching other lines is
  left as it was, still waiting, and named among the refusals; the others are written. Before, it raised "nothing
  written" after writing the pages before it.
- A scheduled `co rem next` parks a pending task whose input changed since it was prepared (its submit could only fail
  "Task input changed") and goes on to the next job. On rc17 one such task held a whole night.

## Today opens with the night (#3371)

- A sleep curve on top: runs that changed pages are 快速眼动, read-only runs 浅睡, early stops 清醒, gaps 深睡; the night's
  work sits under it on the same time axis. On phone, up to three stretches are listed one per line.
- "N 件在等你" is the desk's title above the first card; each card has one primary action.

## People and WeChat

- A WeChat-only person page says the last contact, who wrote last, the 90-day count and the earliest chat, with a
  one-line preview curtained by privacy; the raw WeChat id lives under ⋯ → 这个人 → 复制微信号 (#3374, #3372).
- Backfill retitles punctuation-only names (#3368). Privacy chips read 敏感 / 私人.
- The People filters are labelled 来源 and 标签; course codes and bare domains read as names (#3373).

## CLI

- `co wechat` and `co rem` help pages are written for the AI that runs them (#3361).
