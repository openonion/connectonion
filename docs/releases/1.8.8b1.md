# 1.8.8b1 — Wiki moves to the 1.8.8 preview line

Wiki is now on the 1.8.8 feature line. Version 1.8.7 is reserved for the dashboard
patch based on stable 1.8.6. Previously published 1.8.7b1–b4 previews keep their
original tags and artifacts; this release does not rename or overwrite them.

This retains the Wiki features from 1.8.7b4, with corrected package version and
release-channel documentation. It also fixes `sync --all --dry-run` losing its
inspection-only behavior: dry runs now take precedence over execution modes. The published 1.8.7 dashboard transport fix is carried forward. It includes prompt-free initialization, People /
Organizations / Projects / Skills maps, Skill source snapshots, readable CLI
output and workflow help, page discovery, and validated candidate updates.

```sh
python -m pip install --upgrade --pre connectonion==1.8.8b1
co --version
co wiki --help
co wiki open
```

Existing notebooks and configuration stay in place. Upgrading does not start a
model, enable scheduling, or rerun initialization. The remaining factual-quality
and broader Wiki design limitations from b4 still apply. Structural checks are
not a guarantee that generated conclusions are correct.

See [previous functionality and acceptance](1.8.7b4.md). The separate stable release is 1.8.7.
