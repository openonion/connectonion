# 1.8.7b3 — Start Wiki initialization without questions

`co wiki init` now maps connected mailboxes without asking interactive questions.
Local projects and skills are still mapped when no mailbox is connected. Afterward,
setup tips show `co auth google` and `co auth microsoft`; authenticate separately
and rerun init to add People.

Use `--mail gmail` or `--mail outlook` to restrict the mail sources. Initialization
reads correspondent metadata, not mail bodies, and does not enable background jobs.
Requested or connected sources that fail still report partial failure and preserve
completed maps. Stable remains 1.8.6.

```sh
python -m pip install --upgrade --pre connectonion==1.8.7b3
co wiki init
co wiki open
```

Regression checks cover prompt-free connected and disconnected startup, explicit
mail selection, custom-root setup tips, and partial mail failures.
