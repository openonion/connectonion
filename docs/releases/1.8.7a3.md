# Wiki initialization preview 1.8.7a3

People initialization offers connected mail metadata sources and accepts `co wiki init --mail outlook` or `--mail gmail`. Without mail it explains how to populate People. No schedule is installed.

Skills displays one name with links to all installed copies; source pages and user notes are retained. Temporary execution folders and removed Codex worktrees are excluded from discovery.

251 focused tests passed. Real local initialization mapped 158 people from 30 days of Outlook metadata, 20 projects and 159 skill names. These are mapped skeletons, not investigated facts. Gmail was not selected. Public publication remains subject to the release workflow; this preview is locally installable.
