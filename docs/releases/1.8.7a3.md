# 1.8.7a3 — local Wiki preview

UI and interaction enhancements for `co wiki open` offline reader:

1. **Brand aesthetic aligned**: Replaced amber/yellow search highlights with clean moss green tint (`--mark: #d5ecd9; --mark-ink: #11422b;`), adhering strictly to green-and-white minimal aesthetic.
2. **Organisations category support**: Registered `orgs` category label ("Organisations") and descriptive intent in reader navigation and overview.
3. **Record header actions**: Added one-click "Copy Path" and "Copy Markdown" actions with temporary confirmation feedback.
4. **Muted boilerplate noise**: "Unknown — not investigated yet" boilerplate sections are softly styled to keep verified knowledge prominent without omitting structure.
5. **In-page jump navigation**: Pages with 3 or more sections feature an in-page navigation bar to quickly jump to headings.
6. **Heading anchor links**: Added direct `#` anchor links on headings for easily sharing and bookmarking deep sections.
7. **Search clear & keyboard controls**: Added `✕` clear button to search input, `Escape` key search reset, and hidden WebKit native double-cancel buttons.
8. **Code block copy button**: Discreet "Copy" button appears on hover in code blocks for easy command copying.
9. **Theme switcher**: Added 3-way toggle (Auto / Light / Dark) in sidebar footer with persistent local preference.
10. **Mobile navigation & back button**: Added top "← Back to [Category]" breadcrumb on mobile and improved drawer usability.
