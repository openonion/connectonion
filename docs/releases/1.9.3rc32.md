# ConnectOnion 1.9.3rc32 (release candidate)

Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

## REM: the owner's own page stays current

The page pinned as You was written by the first build and never read again: the
daily rounds rewrote the pages around it while it stayed as of its first day (#2720).
Now the first later run of a day whose owner page was last read before today runs
the same reading as `co rem investigate me` over the days since then (at most 30),
ahead of other pages. It is marked tried before it starts, so a refused or failed
reading waits until the next day, and it stops at the same quota floor as every
other page (#2736).

## Install after publication

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc32'
```
