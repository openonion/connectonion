# ConnectOnion 1.9.0a36 (preview)

## Install this preview

Stable remains 1.8.10. Install this opt-in preview by exact pin, then follow
the [first-run guide](https://docs.connectonion.com/rem#start):

```bash
python -m pip install --upgrade 'connectonion==1.9.0a36'
```

## Outlook HTML keeps its field boundaries

When Outlook returns HTML mail, `co outlook read` and new REM source captures
now keep breaks between paragraphs, lines and table fields in the
provider-rendered text. A cancelled meeting's time, reason and follow-up no
longer run together in one line. Link labels and their destination URLs remain
available. This addresses [#2266](https://github.com/openonion/connectonion/issues/2266).

A synthetic cancellation email was rendered in an invented REM notebook. Its
source dialog displayed each clause on its own line at 1440×900 and 375×812,
with no horizontal overflow or page error. The Outlook and link-preservation
unit checks passed (93 tests). The source dialog still labels the text as a
provider rendering, not original MIME.

## Trial limits

This round changes how **new** Outlook HTML reads become text. It does not
rewrite already saved mail excerpts or re-fetch a private mailbox. The
synthetic dialog does not prove that every Outlook template has useful field
boundaries or that any REM page has gained a new source-backed finding. No
model investigation ran in this round; the broader 90-day cohort remains
unfinished.
