# ConnectOnion 1.9.3rc57 (release candidate)

Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

## Hotfix: `co init` offline no longer waits on a package manager

- 1.9.3rc56 was merged and tagged but never published: the release workflow runs `co init --yes`
  from the built wheel on a machine without Codex and without network, and init spent 80 seconds
  in `npm install -g @openai/codex` retrying through a dead proxy before giving up.
- When the official installer cannot be downloaded, there is no network for npm or brew either, so
  init now stops there in under a second and prints the one command to run later
  (`Codex CLI: not installed: no network for the installer (…); run npm install -g @openai/codex`).
  With network, the installer path is unchanged.
- Everything described in [1.9.3rc56](1.9.3rc56.md) ships here: decisions persist across devices,
  the reader opens before the notebook is parsed, one date grammar, overrunning scheduled turns end
  with their process tree, `co init` proceeds without a browser login, `no_reply` verdicts.

## Install after publication

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc57'
```
