# ConnectOnion 1.9.1b3 (preview)

## Install this preview

Stable remains 1.9.0. Install this beta by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.1b3'
```

## The first pass touches no network for people

1.9.1b2's first pass read each person's 180 days from disk, but in a fresh
notebook it still asked the provider for every archived message's attachments:
about one lookup a second across the whole run, with 14 of 16 pages waiting on
it. The first pass now reads no attachments. The background backfill fetches
them with the older mail, keeps them on disk, and counts them, so those people
are deepened with their attachments as well as their older mail.

## A throttled mailbox is waited for

Sixteen workers plus the backfill drew Microsoft Graph's HTTP 429 and lost an
organisation page. A 429 now backs off and retries, and Outlook is read four
messages at a time, the limit Graph allows one mailbox; Gmail stays at twenty.

## Verification and limits

The co rem unit suite passed, with regressions that failed on 1.9.1b2 first. A
full first run on this beta decides whether it becomes 1.9.1.
