# ConnectOnion 1.9.2b1 (beta)

## Install this preview

Stable remains 1.9.1. Install this opt-in beta by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.2b1'
```

## Each pass improves the page

In 1.9.1 every investigation pass edited the page in place, but every prompt
told it to keep what was there and none told it it could remove anything. Pages
only grew: one person's page carried sixteen "not established" hedges after its
rounds.

A pass now edits the page the way a coding agent edits code: add what the
evidence adds, change what it corrects, delete what it supersedes, what the page
says twice, and doubts it settles. The final round edits as an editor: it
merges repetition and keeps at most five Uncertainties, each one that would
change the user's next step.

A Person's Facts also no longer take a phone number or address that the source
gives as someone else's (an organiser's number in event copy), and relay
addresses are not listed as the person's email.

## Verification and limits

The co rem unit suite passed (2,461 tests), with a regression that fails on
1.9.1: the round and final-round notes and the investigation instructions say
delete. Re-investigating real pages with this beta is how it is judged.
