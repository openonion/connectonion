# ConnectOnion 1.8.7 — Control Center size patch

A dashboard above 2 MiB previously disappeared after reconnect even while its
Agent was healthy. This patch accepts 128 MiB HTML, keeps ordinary Unicode as
UTF-8 through direct and sealed/relay JSON, and sets the Python client/Host
WebSocket budget to 256 MiB. Load failures display an explanatory Control Center
page rather than removing the entry point. A failed send is eligible for retry.

The HTML file limit is distinct from the encoded transport limit. Pathological
JSON escaping can exceed the envelope and yields a visible error. This does not
change the dashboard protocol, allow scripts/external resources, or relax trust.

## Deployment

Self-hosted relay operators must set Uvicorn `--ws-max-size 268435456` (or
`UVICORN_WS_MAX_SIZE=268435456`) and restart it before serving large snapshots.
Upgrade Python clients too; older clients may retain their library's 1 MiB
receive default. The larger per-message budget increases peak memory use.

## Release scope

This stable patch starts from v1.8.6. Personal Wiki (#1443 / #1454) is deferred to
1.8.8. Published 1.8.7b1–b4 artifacts remain unchanged historical previews and are
