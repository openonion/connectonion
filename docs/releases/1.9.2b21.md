# ConnectOnion 1.9.2b21 (beta)

## Install this preview

Stable remains 1.9.1. Install this opt-in beta by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.2b21'
```

## A handoff that opens on what you discussed

The person you hand work to now sees your session first, not an install guide.

- **The mail is a reminder** (#2459). It says who handed them what, then gives
  one line on the work, what you discussed, what you concluded and what is
  still open. The block they paste is three lines: install co if needed, then
  `co handoff accept <code>`, then tell the person what it is about.
- **The handoff is picked up by code** (#2459). It waits on the backend under
  an id the code carries. `accept` fetches it, refuses it unless it is exactly
  what you approved, and prints the report and where the code is.
- **The brief reads like a report** (#2460). It opens with who worked on what,
  with which AI and on what day, then Discussed, Concluded, Still open, and a
  small ASCII diagram. The detail and the conversation follow. You are named
  by your git name, not an address.
- **The AI's own words, not a summary of them.** Each AI turn is quoted, and a
  long one keeps its start and its end.
- **Questions reach you** (#2453, #2454). Any hosted agent answers questions on
  handoffs it sent, however it was started: `co host`, `python agent.py`,
  `co deploy` or `co ai`. It checks every minute. Each new question is also
  mailed to your git email with the line that answers it, because your session
  cannot answer a question you left open.
- **`co handoff open` replays your session as a Codex thread** (#2462). The
  thread is named after the handoff. Your messages and your AI's appear as
  labelled bubbles, then a short report you can read on a phone, ending with
  "You can keep asking me here".
- **"Done" reaches you as a person** (#2470). The recipient's `co handoff done`
  is mailed to you once, with a small patch inline.
- **No failed install in the minutes after a release** (#2457). `install.sh`
  waits for a version PyPI has not listed yet.

## Verification and limits

- Each new test failed before the change and passes now.
- A live run against production with two fresh identities and a real Codex
  session: the handoff was dropped, picked up by `accept`, a question was
  answered with the session copy, and the sender's mailbox got the notice.
- The install floor is 1.9.2b21, because `accept` fetches the handoff that a
  coh3 code points to. coh2 and coh1 codes still work.
- The notice needs `git config --global user.email`. Without it, the sender
  hears about a question only through `co handoff status` or a running host.
