# ConnectOnion 1.9.0a33 (preview)

## Install this preview

Stable remains 1.8.10. Install this opt-in preview by exact pin, then follow
the [first-run guide](https://docs.connectonion.com/rem#start):

```bash
python -m pip install --upgrade 'connectonion==1.9.0a33'
```

## Keep the start of a relationship honest

The Person investigation prompt now distinguishes the earliest retained message
from the first contact. If that message refers to an earlier application,
introduction or conversation whose date is missing, it asks the writer to keep
`First contact` as `Unknown` and name the gap in `Uncertainties`. A dated
acknowledgement can still appear in History with its own citation. See
[#2261](https://github.com/openonion/connectonion/issues/2261)
and the wider [claim audit #2223](https://github.com/openonion/connectonion/issues/2223).

Fact extraction no longer labels the earliest retained mail as `First contact`.
The People index takes that date only from an explicit page fact, including
when it reads an index built by an earlier preview. Existing pages with a
previously written first-contact claim still need their sources reviewed.

## First-run costs and release wait

The first-run preview now uses planning rates from a partial 90-day concurrent
run and separate full Person and Skill reads. It uses the notebook's own
completed-run medians when available. The terminal shows the configured
investigation target (35% of a weekly allowance by default) and the configured
safety floor (90% by default). The target is advisory; the floor stops new
pages, while pages already running finish. Input-token estimates include cached
tokens and are not weekly quota points. See
[#2260](https://github.com/openonion/connectonion/issues/2260) for the remaining
measured-progress work.

The release workflow now builds the tagged package beside the test matrix.
PyPI publication still waits for both jobs to pass, and the built wheel still
gets its installed-package check. This removes a serial wait; the actual time
saved will be measured on this release.

## Trial limits

On one protected five-source Person sample, the public a32 wheel produced an
accepted page with a false `First contact` date. An independent role-based AI
review compared all five cited originals in the rendered desktop and phone
reader and found that P2. A fresh run with the full a33 change produced an
accepted page with `First contact: Unknown`; the People table also shows no
first-contact date. It used 215,394 input tokens (186,240 cached) and 3,476
output tokens. The full 258-page first-run cohort has not been completed on
this preview. One corrected page does not establish that all Person claims or
pages are accurate.
