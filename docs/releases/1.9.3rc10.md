# ConnectOnion 1.9.3rc10 (release candidate)

## Install this preview

Stable remains 1.9.2. Install this release candidate by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc10'
```

## What changed

1.9.3rc9 with one correction. The package ships the repository's `docs/`, and
rc9's copy of the handoff blog post "A conversation of its own" told its story
with a real person and their own business. rc10 tells it with a fictional
sender and a neutral task, as every other example in the docs does. The code
is unchanged from rc9.

## Verification and limits

- The whole tree that is packaged was searched before tagging: no line of the
  real story remains in it.
- Everything in the [1.9.3rc9 notes](1.9.3rc9.md), including its known issues,
  still applies.
