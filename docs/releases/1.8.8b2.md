# ConnectOnion 1.8.8b2 — Wiki preview and browser request inspection

This opt-in preview continues the 1.8.8 Wiki feature line introduced in b1 and
adds `co browser requests` and `co browser request <id>` for inspecting network
requests made by the active browser page. The browser captures selected textual
request and response bodies from the page's own instrumentation; it does not
install a proxy or change normal navigation behaviour.

```bash
co browser requests
co browser requests --url-contains=/api/ --method=POST
co browser request 7
```

Sensitive-looking header values are shaped by default. `--raw=true` shows raw
values when explicitly requested. The per-tab buffer is bounded to 500 records.
WebSocket frames are not captured. Browser validation was performed against a
local page using headless Chromium; anti-bot sites and Windows/macOS were not
covered by this feature's acceptance run.

The Wiki workflows and other features already present in the published b1
preview remain part of this preview line. Cloud Code's local CLI connector is
not included in b2: PR #1630 remains draft, and the web Work Room OIP handover
is not implemented there yet.

Install the preview explicitly:

```bash
python -m pip install --pre --upgrade connectonion
# or pin this preview
python -m pip install connectonion==1.8.8b2
```

Stable remains 1.8.7. This preview does not change the default `pip install`
channel.
