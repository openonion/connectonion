# ConnectOnion 1.9.6rc32 (release candidate)

Stable remains **1.9.5**. Python **3.11+**.

## co on a Windows PC

- **`co browser` starts headless where Windows has no desktop.** OpenSSH logins, services and
  scheduled tasks run in session 0, where a headed Chrome never shows a window; `go_to` waited
  120 seconds there. It now starts headless, as on Linux with no display (#3168, #3171).
- rc31 carried the rest of the Windows pass from the same PC: `co rem` init, investigation and
  the reader (timezone from the registry, UTF-8 text everywhere, POSIX notebook paths, long
  prompts on stdin, the index closed before it is replaced) and the onionwright install (#3166).

The WTF Browser has a Windows build that is not published yet; until it is, use the system
Chrome engine on Windows (#3167).
