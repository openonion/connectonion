# ConnectOnion 1.9.3rc58 (release candidate)

Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

## Hotfix: a page task is no longer refused for a source id that only changed spelling (#2877)

- On a real notebook the scheduled round had retried one page task since the previous day: every
  `co rem submit` answered `Dropped source id the page had: gmail:…` although the id was listed and
  cited in the candidate. `resolve_sources` rewrites mail ids into their archive-digest form while
  the page as it stood still listed the long form, and the retention check compared the two as
  strings. Each retry cost a Codex turn; `co rem status` said `Last turn: completed · exit 0` while
  Today said `nothing ran yet`.
- Both promotion paths now compare and restore source ids in their resolved form: a spelling change
  is neither a drop nor a duplicate Sources line. Verified by replaying the refused candidate on a
  copy of that notebook: the same submit now passes the retention check and moves on to the claim
  audit.
- Everything in [1.9.3rc57](1.9.3rc57.md) and [1.9.3rc56](1.9.3rc56.md) ships here.

python -m pip install --upgrade 'connectonion==1.9.3rc58'
