# ConnectOnion 1.9.3rc34 (release candidate)

Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

## REM: one person, one page

The map makes a page per address, so someone who writes from two addresses, or
under a nickname, could end up on two pages with their facts split (#2724).

- Code finds pairs that look alike: a name or alias in common, one name inside the
  other, or a page whose Email line lists the address another page was made from.
- The new `rem-same-person` Skill reads both pages and each one's six newest sent
  mails, and answers yes or no with what the shared address is (their own, an
  assistant's, a shared mailbox ...). When unsure it answers no.
- Yes folds the less written page into the more written one: archived, aliased,
  links rewritten. Every answer is kept in `.state/same-person.json`, so a pair is
  asked once.
- The daily round asks about two pairs a run, and only above the quota floor.
- A merge keeps one line per fact, splitting values on semicolons only (#2740).

## Install after publication

python -m pip install --upgrade 'connectonion==1.9.3rc34'
