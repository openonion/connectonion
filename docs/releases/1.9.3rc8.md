# ConnectOnion 1.9.3rc8 (maintenance release candidate)

## Install after publication

Stable remains 1.9.2. This candidate is not published until its reviewed merge
commit passes the immutable-tag release workflow. After publication, install
only the exact preview:

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc8'
```

## A subject correction must survive promotion

A saved page can change which person or organisation it describes while keeping
its file path. Promotion previously restored old contact dates and refilled an
extraction packet without checking that continuity. It now skips those automatic
restorations after a subject-title change unless an explicit unqualified email
or domain anchor is retained (#2550, #2551). Candidate-provided facts remain.
Case-only edits, unchanged titles and anchored first-write renames retain normal
recovery. Routing anchors are not proof that two identities are the same.

## The status footer summarizes the latest pass

On the next successful pass, the Investigation footer keeps the latest dated
mapped, written, investigated and enriched segments (#1988, #2552). Same-day
last values win; custom dated metadata stays. Exact obsolete placeholders and
exact/colon-prefixed standalone requested-window notes are removed. Other
unrecognized legacy formats are retained.

The legacy unfinished-list investigated_passes field counts visible stamps,
not lifetime work. The operational queue still uses the latest investigated or
written date. Existing run records retain separate execution history. No bulk
notebook migration or article-length cap is included.

- Footer: four new regressions failed before repair; 54 file/queue and 343
  related tests passed. Independent AI source review approved both fixes;

  isolated installed-wheel checks passed 13 tests. [Candidate record](https://github.com/openonion/connectonion/blob/v1.9.3rc8/docs/acceptance/1.9.3rc8/README.md).

  unsupported biographical claims remain separate work.

  early return (#2334); this candidate does not claim instant correction apply.

  #2546 remains draft without native keyboard/screenshot acceptance. No new
  screenshot evidence is available, and no blocked-preview workaround was used.
- Real nightly usefulness, morning recall, phone and accessibility maturity
  remain unverified. The dated audit lists ten priorities and remaining work.
- The handoff recipient install floor advances with the package version.
