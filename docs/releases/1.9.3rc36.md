# ConnectOnion 1.9.3rc36 (release candidate)

Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

## REM: an early scheduled run serves its slot

- Codex desktop fires a scheduled task a few minutes either side of its time. A run
  fired at 02:59 for the 03:00 slot found the previous evening's slot already served,
  reported "not due" and did nothing, so the 03:00 slot was lost. A scheduled sync up to
  10 minutes before a saved time now serves that time (#2745).
- The `co rem start` note now says the wake job opens Codex shortly before each saved time.

## Install after publication

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc36'
```
