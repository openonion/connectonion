# ConnectOnion 1.9.3rc48 (release candidate)

Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

## `co rem doctor` names the right install command (#2798)

- When spreadsheet support was missing, `co rem doctor` and the note left for an unread XLSX
  attachment said `python -m pip install 'connectonion[rem]==…'`. On a `uv tool install` that
  installs into whichever `python` is first on PATH, and the check stayed red.
- For a uv tool the advice is now `uv tool install --force 'connectonion[rem]==…'` with the
  `--with` packages and `--python` recorded in the tool's receipt, so companions such as
  onionwright stay installed. Otherwise it is pip through the absolute interpreter that runs co.

## Steadier release checks (#2797)

- The macOS remote-browser egress tests failed now and then on unrelated changes (a 0.75 s
  wall-clock bound) and once hung until cancelled. They now assert the timeout behaviour with
  a margin, and each test has a 30 s watchdog so a hang names the test and fails fast.
