# ConnectOnion 1.9.3rc60 (release candidate)

Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

## The night does the work; the morning is one click

- **Every item owed by you gets an outcome overnight**: a prepared reply, the work done, "already
  handled" (your newest message answered it), or "no reply needed". The nightly budget covers the
  whole Today queue in Today's order; `co rem status` says what tonight produced.
- **Originals are fetched, not skipped**: when a cited mail is not archived, the round reads it from a
  mailbox REM may already read, then drafts. Today never offers "open in Outlook/Gmail" as the main
  action.
- **批准全部 / Approve all**: one sheet lists every prepared outcome; confirming sends replies with a
  10-minute hold and Undo, marks handled items done and queues tasks. A reply that still holds a
  【需要你：…】 slot cannot be sent until it is filled.
- **Tasks are dispatched, not just described**: `co rem task run / status / stop` hands an owed piece
  of work to Codex with a receipt; a finished task shows its deliverable and a reply that carries it.
- **Cards say what is true**: an owner-last thread reads "你已回复…——如果这件已经办了，标为完成" with
  completion as the primary action, unless you promised work; the channel badge stays; one Today
  ranking drives both the cards and the night's drafts.

## Pages redesigned

- **People** and **a person's page**: grouped "在等你 / 最近联系", a focus card, a four-number strip,
  open items as one card, a month-by-month timeline, a quiet rail.
- **Organisations**: grouped by what waits on you; organisation data (kind, what it is to you, teams,
  project links) and the start of a hierarchy (units with a cited Parent, people in units, rolled-up
  open items, conflicts as questions).
- **Projects** as a board by recency with the busiest project first, and **Sessions** grouped by day
  with private work behind a curtain; projects now carry priority 0–4 with cited reasons, health,
  merge suggestions and promised dates.
- Translation of pages into the language you read starts from the reader's language choice; removed
  date clauses no longer leave stray punctuation; "All records" moved below the categories.

## Models and mailboxes

- REM work runs on the top model; only summaries use the small model. Changing models no longer
  discards a pending task.
- Scheduled Outlook reads keep their token's file provenance (the cause of repeated credential
  failures), and mailbox failures record a safe code and the command that fixes it — never the
  provider's message.

## Known limits

- Organisation hierarchy and project views are the first of three planned rounds; a Bauhaus-light
  organisation page and three classic project views (list / board / timeline) follow.
- Topic pages (knowledge entities) and the global graph are not in this candidate.

## Install after publication

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc60'
```
