# 1.9.7rc8

Fixes a regression in 1.9.7rc7.

## Topic link reviews are not asked twice
rc7 changed a topic link review's question from the page's file path to its title ("Does Ellis concern this topic?" instead of "Does people/ellis.md concern this topic?"). Reviews were deduplicated on their kind, their two pages **and the question text**, so after the upgrade none of the stored link reviews matched the new wording and the next night would have proposed each of them again — on a clone of a real notebook, 36 pending link reviews became 77 — and a link the owner had already decided would have been asked again.

A link review is now the same link whatever its wording: it matches on its two pages. A pending link found under the old wording takes the new wording, so the path questions shown today migrate to page titles. A decided link stays exactly as written. Questions (one-page reviews) still match on their words. On the same clone: 36 → 41 pending (5 genuinely new pairs), none worded with a path, and 41 again the next night ([#3292](https://github.com/openonion/connectonion/pull/3292), regression from [#3286](https://github.com/openonion/connectonion/pull/3286)).

Stable remains 1.9.6.
