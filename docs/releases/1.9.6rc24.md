# ConnectOnion 1.9.6rc24 (release candidate)

Stable remains **1.9.5**. Python **3.11+**.

## co whatsapp on Windows

Three fixes from the first live run on a Windows 11 PC:

- **`check` and `consume` beside a running listener.** They crashed with `PermissionError`,
  because Windows makes a locked file unreadable to other processes and the listener's pid was
  inside `listen.lock`. The pid now lives in `listen.pid`; the lock still decides who listens.
- **Incoming messages are kept.** WhatsApp gives message times in milliseconds. Read as seconds,
  Windows raised `OSError 22` and every incoming message was skipped. On macOS and Linux each
  message was silently stamped with the time it was read; it now carries the time it was sent.
- **`consume` replies in UTF-8.** It used the locale encoding, cp1252 on Windows, so replies
  arrived garbled (`â€¢`). It now uses UTF-8 both ways and sets `PYTHONIOENCODING=utf-8` for
  the command. `PYTHONUTF8=1` is no longer needed.
