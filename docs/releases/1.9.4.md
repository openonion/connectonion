# ConnectOnion 1.9.4

## Install

```bash
python -m pip install --upgrade 'connectonion==1.9.4'
```

Python **3.11+** and the existing dependency floors are retained.

## Hotfix: `co rem open` never waits on a build

- After upgrading from 1.9.3rc64 to 1.9.3, the first `co rem open` could wait minutes (17 were
  measured on a busy laptop), printing one line. 1.9.3rc64 did not list the file page in its saved
  manifest, so 1.9.3 found no page, waited for the rebuild the upgrade had started, and rendered
  again in the foreground.
- The reader now never waits on a build. Any saved page, an older release's included, opens at
  once with a quiet "Updating…" ("正在更新…") line and rebuilds behind it; the open tab moves to the
  new render when it lands. A page from an older release rebuilds at once rather than at the next
  ten-minute check.
- With no saved page at all, `co rem open` renders once, never twice beside a build already running,
  and prints progress every few seconds.
- On a copy of a 31,000-file notebook: 38.5 s before, 0.77 s after.
