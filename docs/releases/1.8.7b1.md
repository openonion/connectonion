# 1.8.7b1 — Wiki beta preview

An opt-in preview of the Wiki branch, with initialization and reader reliability fixes from PR #1613. Stable remains 1.8.6.

```sh
python -m pip install --upgrade --pre connectonion==1.8.7b1
co wiki init --mail outlook
co wiki open
```

Use `--mail gmail` for Gmail or omit mail to map projects and skills only. `init` does not install a schedule or call a model. Selected mail-source failures produce a partial result and nonzero exit while preserving completed work.

Repeated initialization refreshes generated project metadata; skill source metadata stays separate from authored notes. Skill search and navigation group installed copies with links to their original pages. Git transport aliases share project identity. Automated correspondents are visibly labelled. Custom-root recovery commands preserve their target. Reader copy and diagnostics no longer claim unsupported completion or maintenance.

Validation: 10,756 offline tests passed, 29 skipped; nine Chrome reader acceptance tests passed separately, including keyboard/mobile/search. Live Outlook metadata initialization was verified over 30 days. No new model investigation or live Gmail test was run. This beta does not guarantee factual correctness of generated investigations. Existing unrelated or legacy pages are preserved, not automatically deleted or merged.
