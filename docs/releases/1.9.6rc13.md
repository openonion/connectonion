# ConnectOnion 1.9.6rc13 (release candidate)

Stable remains **1.9.5**. Python **3.11+**.

## Host trust and approvals

- **Every automatic run is recorded.** When a contact's message makes the Host edit a file and then
  start two Codex runs, `co approvals` and the operator console now show three entries, each with
  its own outcome. Before, only the first was recorded and a later failure was invisible (#3025).
  The notice to the requester is still shown once per session.
- **Revoking stops a turn even after the requester left.** The Host re-checks trust before every
  tool or model step of a requester's turn. A blocked or downgraded requester's turn stops before
  its next step, connected or not; a step already running finishes unless they are still
  connected (#3026).
- **`co trust add`, `unblock` and `admin add/remove` print the file they changed**, like `remove`
  and `block` already did (#2819).
- `docs/features/trust.md` states what Auto mode allows a contact's Codex: shell commands without
  prompts, in a sandbox that can read the whole disk and has no network.

## Upgrade

```bash
uv tool install --force 'connectonion==1.9.6rc13' --with onionwright --prerelease allow
```
