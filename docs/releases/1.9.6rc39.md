# ConnectOnion 1.9.6rc39 (release candidate)

Stable remains **1.9.5**. Python **3.11+**.

## One command, and the Host is running

- **`co init` starts the Host and leaves it running** (#3170, #3175): launchd on macOS, a systemd
  user unit on Linux, and on Windows a Scheduled Task at logon that runs `co host --serve` and
  starts it again if it exits (no admin). `co host` shows it; `--background`, `--status`,
  `--stop` and `--uninstall` manage it.
- **The model is one line in `.co/host.yaml`:** `model: claude-code` (or `codex`, or a model
  name). With `claude-code`, your logged-in Claude Code answers through the Host, over the relay
  and in O Chat, with no API key. Checked on macOS: a message from chat.openonion.ai came back
  from Claude Code with its task card.
- **WTF engine:** requires onionwright 0.0.16, the first with Windows support (#3184).

Not yet run on a real Windows PC: the Scheduled Task is covered by tests with a fake `schtasks`;
the live check on a Windows 11 PC follows.
