# ConnectOnion 1.9.0a19 (preview)

`co rem open --live` now opens `https://chat.openonion.ai/<address>/rem`.
The deployed O Chat frontend serves this route and permanently redirects old
`/<address>/wiki` links, preserving the requested page. Its reader, offline
and access-denied screens use **co rem**.

The GitHub README introduces co rem as your agent's memory, explains the
local notebook and its source limits, and links to the reader demo and guide.
The homepage's generated connection cards use co rem too, so refreshing the
README does not bring the old command name back. Current documentation uses
co rem and redirects the old CLI guide addresses.

Install the exact preview to keep dependency selection on stable releases:

```bash
python -m pip install --upgrade 'connectonion==1.9.0a19'
co rem open --live
```

The signed reader protocol and existing browser sessions are unchanged.
Notebook migration still accepts the former `.co/wiki` directory. Historical
release notes keep the names used when those versions shipped.

## Evidence

The [reviewed screenshot manifest](assets/v1.9.0a19/manifest.yml) records the
reader at desktop and phone widths, an offline host and an access-denied
browser. The fixture uses invented notebook content. CLI tests check both
direct and relay-only live URLs; browser checks cover the canonical route,
old links, signed reads and reader errors.

This release completes the public name and URL change. Owner recall,
correction and overnight memory quality still have their existing acceptance
gates; this release does not claim they are complete. It is an opt-in alpha;
stable remains **1.8.10**.
