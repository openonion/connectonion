# ConnectOnion 1.9.3rc33 (release candidate)

Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

## REM: the wake job opens Codex before the slot

Codex desktop fires a scheduled run a few minutes either side of its slot: on a
real notebook the 19:00 slot was due at 18:55. With the app closed, the wake job
opened it at 19:00, after that moment, and the run was missed. The wake job now
opens a closed Codex 15 minutes before each slot, wrapping across midnight; an open
app is still left alone (#2738).

Run `co rem start` once after upgrading so an existing wake job moves to the new times.

## Install after publication

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc33'
```
