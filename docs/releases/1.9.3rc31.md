# ConnectOnion 1.9.3rc31 (release candidate)

Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

## Outlook drafts

`co outlook send ... --draft` and `co outlook reply <#> ... --draft` save the message
to Drafts (a reply stays in its thread) and print a link that opens it in Outlook.
`co outlook drafts` lists unsent drafts, numbered; `co outlook send-draft <#> [--at]`
sends one as it is now or schedules it, and `co outlook delete-draft <#>` deletes one.
Both check the message is still a draft first, and refuse anything received or sent.
`--draft` with `--at` is refused: a draft is not sent (#2732).

## REM pages

- A limit is stated only when it matters to a claim or the next step; the people and
  organisation review fails a sentence that only says an irrelevant matter is not
  established (#2727).
- Pages written from a business card cite a numbered `1. <text>` source line; the
  reader now opens that line from the citation. The write check accepts such a line
  only when it is carried over unchanged (#2730).

## Tests

Two people-page tests use one clock instead of mixing a fixed date with the wall
clock (#2731).

## Install after publication

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc31'
```
