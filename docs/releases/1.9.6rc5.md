# ConnectOnion 1.9.6rc5 (release candidate)

Stable remains **1.9.5**. Python **3.11+**. Dependency floors are unchanged.

## REM reader

- **Every place on the rail says what it is.** The rail on the left used to show shapes (a rounded
  square, a triangle, three linked dots) whose names appeared only on hover. Each place is now a
  picture with its word under it: Today, Waiting on you, People, Organisations, Projects, Skills, All
  records, then More and Settings. In English, three names that do not fit under a picture show a
  short word (Waiting, Orgs, All); screen readers still read the full name (#2960, fixes #2953).
- **Skills has its own place on the rail** instead of sitting under More. On a phone the tab bar is
  unchanged and Skills stays under More.
- **A low window scrolls the rail** rather than cutting off Settings, and the More menu stays beside
  its button.
- **REM has its own mark**, a sleeping face, top left and in the browser tab.

There is nothing to do: install this release and reload the reader.

## Install after publication

```bash
uv tool install 'connectonion==1.9.6rc5' --with onionwright --prerelease allow --force
```
