# ConnectOnion 1.9.6rc9 (release candidate)

Stable remains **1.9.5**. Python **3.11+**. soupsieve's floor moves to 2.10 (see below).

## REM

- **One mailbox failure no longer stops the night.** A page whose mail could not be read (a timeout,
  a message gone from the server, attachments that would not list) is set aside and tried again later
  (1 hour, 6 hours, then daily), and the night goes on with the next page. A mailbox that keeps failing
  or whose login expired is left alone for the rest of that turn. Today's night card says what happened
  in one sentence and lists the pages set aside (#2986).
- **Today has one count and one primary action per card.** The header, the sidebar badge and Waiting on
  you show the same number. The rail's numbers became worded actions («一键批准这 N 件», «看 N 件在等谁 →»).
  Each card leads with one action; 标为完成 · 暂不处理 · 忽略 and 交给 Codex / 交给 Claude stay visible
  words. Long-quiet promises fold under the desk with «都标为完成（N）» and one Undo (#2987).
- **Record pages lead with what you open them for.** A person's open threads come first; the 原文 chip
  above titles is gone (a quiet line says when a translation is on its way); you no longer appear in
  your own «连接最多»; an organisation's Today link counts exactly what Today counts (#2988).
- **Your language is one rule.** Drafts, the reader and the night's translation agree on your language
  (your first non-English one). Draft gists, reasons and the blanks only you can fill are written in it;
  the reply body follows the thread. Untranslated rows say 原文, and the pages behind Today's rows are
  translated first (#2989).
- **A research capture that is not text is refused by name** instead of stopping every round (#2963).

## Dependencies

- soupsieve is past CVE-2026-126192 and CVE-2026-126190 (4.1 on Python 3.11.5+, 2.10 below) (#3008).

There is nothing to do: install this release and run `co rem open`.
