# ConnectOnion 1.9.3rc53 (release candidate)

Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

## Scheduled REM runs through `codex exec` (#2844, #2856)

- On macOS, new notebooks use a new scheduler, `schedule.runner: codex-exec`. A launchd job runs
  `codex exec --ephemeral` at each saved time, and that one session keeps working
  across tasks until the round is done. Desktop automation turns could end after about a minute
  whatever the task. `--ephemeral` keeps these turns out of the Codex app's history. Existing
  notebooks keep their runner; switch with `co rem config set schedule.runner codex-exec` and
  `co rem start`.
- When `codex` is not on `PATH`, REM uses the CLI that ships inside the ChatGPT or Codex desktop
  app.
- Each turn leaves a receipt in `.state/turns/` and `.state/last-turn.json`. A turn that cannot
  start records why, and `co rem status` shows it. Startup has five minutes before it counts as
  hung, so a slow, heavily loaded machine no longer records a false failure.
- `co rem start` keeps a Codex thread that is still being written to instead of stopping with
  "already has an active writer".

## `co init` sets REM up without asking

- Global `co init` grants the local sources, refreshes connected mailboxes, installs upkeep and
  builds, then prints how to undo each step.
- If no background scheduler can be installed (no systemd user session, Windows), init still
  finishes. It says why upkeep is not installed and names `co rem start`.

## Rounds do more and pages start fuller

- First and last contact, time zone and company are filled from the mail itself. Coverage counts
  say what is really known.
- People are admitted every round. Likely same-person pairs are proposed early. Your own addresses
  never become a contact. Role mailboxes such as `info@`, `hello@` and `support@` are no longer
  dropped as automated.
- A round investigates first, writes at most five summaries, runs up to 8 jobs and audits once at
  the end. The daily runner budget is 200 calls.
- A prepared task depends only on its own inputs, so unrelated edits no longer invalidate it.
  Tasks prepared by an older version submit cleanly.
- The claim audit only skips a citation when its notes show the checkpoint was actually done.

## Reader

- Opening a citation shows only the cited messages and their neighbours, not the whole thread.
  Dates are shown in local time.
- The source dialog closes when you navigate, and the page header stays pinned while scrolling.

## Install after publication

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc53'
```
