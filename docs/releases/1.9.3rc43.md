# ConnectOnion 1.9.3rc43 (release candidate)

Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

## Hotfix: tidy leaves links outside notebook content alone (#2773)

- 1.9.3rc42 (#2771) routed tidy's dead-link check through the archive path, which validates its
  argument; a page linking to a path outside notebook content (a dot-folder, an absolute path, a
  path above the notebook) made `co rem tidy`, every scheduled sync and `co rem next` stop at once
  with "Hidden paths and traversal are not notebook content". Such links are now left as they
  are, before any archive lookup, and a link above the root is no longer mistaken for an archived
  page of the same name. Checked read-only over a 1,004-page notebook: no error, no change.

## Install after publication

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc43'
```
