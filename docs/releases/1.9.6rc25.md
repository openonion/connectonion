# ConnectOnion 1.9.6rc25 (release candidate)

Stable remains **1.9.5**. Python **3.11+**.

## A Windows PC can host

- **`co host` registers with the relay on a PC with many adapters.** Disconnected Wi-Fi,
  Bluetooth and virtual adapters each carry a link-local 169.254.x address, and every address
  was published twice. Over the relay's limit of 10 endpoints the host was refused and nobody
  could reach it. Link-local addresses are no longer published, and the list is capped at 10,
  keeping the public address.
- **`co call` works against a Windows host.** The bash tool refused Windows. It now runs Git
  Bash when installed and falls back to `cmd /c`.
- **The background listener's log is UTF-8** on Windows, so the 👀/✍️ lines read back correctly.

See #3122, #3123, #3124 and #3120.
