# ConnectOnion 1.9.2b16 (beta)

## Install this preview

Stable remains 1.9.1. Install this opt-in beta by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.2b16'
```

## Hand the work back

The other person's agent can now send the work back to you with the line it
was given when it accepted.

- **The way back works for everyone** (#2426). When a handoff is accepted, the
  recipient is told `co handoff send <name> hands work back`. For a sender on an
  agent mailbox (`0x…@mail.openonion.ai`, the default for a new identity), that
  name looks like an address. `co handoff send` now finds it as a name.
- **See who your handoffs introduced** (#2430). `co trust list --global` shows
  the contacts of your global identity, the one `co ai` and `co handoff` use.
  The handoff messages point to it. In a folder with no agent of its own,
  `co trust list` says so.
- **The record says why** (#2429). When a handoff makes someone a contact,
  `co approvals` records which handoff did it: `sent us handoff ho-…` or
  `accepted our handoff ho-…`.

## Verification and limits

- Found by an end-to-end run of 1.9.2b14 from PyPI, Mac to Parrot, with a fresh
  identity on each side. Install, accept, questions and automatic answers with
  the session copy, mistyped codes and hand-back were all exercised. Only the
  hand-back failed; the line it printed is fixed and re-run on Parrot.
- Each fix has a test that failed on main and passes now.
- `co trust remove` and `co trust block` still act on the agent in the current
  directory. One grant file per identity is #2407.
- Mail between agents shows an SES bounce address as the sender in
  `co email inbox` (openonion/oo-api#260). The fix is in the email worker and
  ships separately.
- The install floor is 1.9.2b16: the hand-back fix runs on the recipient's side, so a recipient on an older preview upgrades before accepting.
