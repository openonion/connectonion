# ConnectOnion 1.9.2b16 (beta)

## Install this preview

Stable remains 1.9.1. Install this opt-in beta by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.2b16'
```

## A first handoff mail a stranger can read

The first `co handoff` to someone new is an email, and it is often their first
contact with ConnectOnion. It now reads like an introduction (#2431, #2415):

- **Who and what first.** Who sent it, what ConnectOnion is in one line, then
  the task, where it stands and what is still open.
- **One thing to do.** Three numbered steps, then a single block marked START
  and END to paste into Codex or Claude Code. Only that block is shaded.
- **Promises it keeps.** The steps say exactly what the agent does: install co
  if it is missing, tell the sender you have it, then ask before touching files.
- **Works in every inbox.** A table layout that holds in Outlook; the pasted
  block stays whole when Gmail clips a long mail, keeping the newest part of a
  long conversation and saying how much it left out.
- **A shorter install.** One line from the release's own `install.sh` on macOS
  and Linux, one `uv tool install` on Windows. The install floor is 1.9.2b16.

## Also in this preview

- `co handoff status --wait` returns for an answer that arrived before the wait
  began, instead of waiting for the next message.
- An accepted handoff stays accepted when its acceptance mail falls out of a
  busy mailbox.
- The brief never passes on permissions the sender gave their own AI: an owed
  merge, release or payment waits on the sender unless they granted it to the
  recipient by name (#2404).
- The line `co handoff accept` prints for handing work back now works when the
  sender uses an agent mailbox (#2426).
- The record says which handoff made each side a contact (#2429), and
  `co trust list --global` shows the identity co ai and co handoff use (#2430).
