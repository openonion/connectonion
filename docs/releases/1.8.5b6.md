# ConnectOnion 1.8.5b6 — beta

Beta, 14 September 2026. The paid browser's driver comes from PyPI now.

Stable stays **1.8.4**. This is not Latest and needs an explicit pin or
`--pre`:

```bash
python -m pip install --pre connectonion==1.8.5b6
co --version
```

## Change

**`onionwright` is on PyPI, so ConnectOnion installs it from there.**

Until today PyPI held a name reservation — one file, a docstring, and
`__version__ = "0.0.3"` — while the real client travelled a licence-gated
endpoint: authenticate, fetch a signed manifest, verify an Ed25519 signature
against a pinned key, resolve a download grant, stream the wheel, hash it,
compare, then install the local file. That was a deliberate design
(`openonion/onionwright#9`: one distribution mechanism rather than two, so the
wheel and the browser binary shared a manifest, a signature and a checksum).

`onionwright` 0.0.14 is now published normally, so ConnectOnion's installer is
289 lines shorter and does what its name says. Two things follow:

```bash
pip install 'connectonion[wtf]'      # pin the driver in your own requirements
co browser --engine wtf <verb>       # or let the command install it on demand
```

The version is a floor (`>=0.0.14`), not a pin: oo-api records
`minimum_client_version` per artifact and refuses a client below it, which is the
check that actually protects a paid download. Pinning here would only stop people
getting fixes.

**The browser binary is still licence-gated**, and the runtime licence is still
checked at launch. Publishing the driver is not publishing the browser — there is
a test asserting exactly that, because it is the kind of thing that could be lost
quietly and would announce itself with no error at all.

The credential handling went with the download path. An install that needs no
token cannot raise `AmbientCredentialError`, and catching an exception that can
never arrive tells the next reader it can.

## Known limits

Unchanged: the no-loss-across-a-reconnect gate in #1462 has not passed, which is
why stable is still 1.8.4 — that gate is the Feishu inbox, not the browser, and
nothing in this release moves it. A chat message can command the agent and there
is no sender allowlist until 1.9. A browser that exits on its own takes the tab
registry with it (#1513, targeted 1.8.6).

On an externally-managed interpreter (Homebrew, most distro Pythons) the
on-demand install still stops and asks for `--break-system-packages`. That is
deliberate: PEP 668's marker is a person or an OS saying *I manage this one*, and
overriding it inside a command someone ran for another reason is the kind of help
that surfaces weeks later as a broken package manager.
