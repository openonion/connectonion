# ConnectOnion 1.9.1b4 (preview)

## Install this preview

Stable remains 1.9.0. Install this beta by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.1b4'
```

## The first run reads your coding sessions once

We profiled one person's first-pass gather on 1.9.1b3: 363 seconds, of which
mail took about ten. 350 seconds went to re-reading every local coding-session
transcript and re-hashing its prefix, to catch a rewritten history. That check
ran for every person, one at a time behind a lock, so sixteen workers queued on
it and people pages barely moved.

Within one run the session window is now kept in memory for half an hour: the
first person pays the scan, the rest reuse it. Between runs nothing changes;
the on-disk window and the rewrite check work as before.

## Verification and limits

The co rem unit suite passed, with a regression that failed on 1.9.1b3 first. A
full first run on this beta decides whether it becomes 1.9.1.
