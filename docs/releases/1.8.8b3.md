# 1.8.8b3 — Personal Wiki preview after real-use repair

This opt-in preview carries the finished Wiki work since 1.8.8b1. The next
public preview number is b3; there was no published b2 artifact. Stable remains
1.8.7, and the full Personal Wiki acceptance target remains 1.9.0.

A real first-run test had produced zero accepted people pages out of three even
though the model wrote candidate pages. The default model was unavailable to a
ChatGPT account, initialization did not make connected mail available to
investigation, and the validator rejected citations to fetched messages. The
repair was retested on the same notebook: 11 of 11 selected people pages were
accepted, including an address-merged contact and a 201-message contact. The
retained candidates, material and reviews remain local, not in this package.

Initialization now explains the state of each source and asks about likely
owner aliases rather than silently merging them into people. The Wiki can read
explicitly selected WhatsApp chats from the local listener's files. `co wiki
open` can open a private full page through the Host OIP route. Delegated Wiki
runs use a stable task workspace, so related Codex turns stay together; the
scheduled daily round can maintain the notebook and investigate at most one
unfinished page under its call cap. Candidate validation and review evidence
still guard promotion of a generated page.

Install this exact preview with:

```sh
python -m pip install --upgrade 'connectonion==1.8.8b3'
co --version
co wiki --help
```

This is not the 1.9.0 stable acceptance. The harness audit (#1629), end-to-end
quality for project and Skill investigations, model cost limits, and page-sharing
boundaries still require review. The real-person retest proves the repaired
sample, not that every generated claim is correct. A skipped or unavailable
source must remain visible in coverage. Keep reviewing citations and source
visibility before sharing a page.
