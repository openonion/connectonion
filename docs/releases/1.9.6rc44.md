# ConnectOnion 1.9.6rc44 (release candidate)

Stable remains **1.9.5**. Python **3.11+**.

- **Global `co init` on Windows from an elevated shell:** it picked `model: claude-code` (Claude Code
  logged in, Codex not) and said the Host was running, but the logon task printed
  "No .co/host.yaml here" every ten seconds. The Host profile folder had the same owner-only ACL
  that rc43 removed from the logs folder; it now inherits normal permissions.

Checked on a Windows 11 24H2 PC over SSH as an admin: plain `co init --yes --no-rem` with no
host.yaml edits chose `claude-code` and a free port, and a relay message was answered by the local
Claude Code in 12 s. If an earlier candidate already made `~/.co/runtime/host` from an elevated
shell, delete that folder and its `~/.co/host-services/<id>` and run `co init` again.
