# ConnectOnion 1.9.3rc50 (release candidate)

Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

## Fictional people in fixtures, docs and examples (#2804)

- Tests, the docs that ship in the wheel, and docstrings, comments and skill examples used the
  maintainer's real name and personal addresses, and a few other real people, as sample data.
  They now use fictional people and example domains; each test keeps its meaning.
- `tests/unit/test_no_personal_identifiers.py` fails if those addresses or names come back.
- No behaviour change.

## Install after publication

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc50'
```
