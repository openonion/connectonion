# ConnectOnion 1.9.0a17 (preview)

REM's first written project page now has a better chance of telling the owner
something they missed. Before the writing turn, code gathers a bounded local
packet from the project's recorded checkout: README, package manifest,
checkout freshness/current ref and up to five recent commit subjects. Each is
separately citable. The writer compares these with the owner's own coding
messages. It treats a request as intent and a local commit as a local commit;
neither is proof that tests passed or a release reached users.

After investigation, the page keeps core state, insight, paths, open threads,
uncertainties and sources, plus only optional sections with supported content.
The unfinished map scaffold remains explicit before investigation. Existing
supported sections and mapped `Sessions`, `First seen` and `Last seen` survive
updates. This addresses the first project-page evidence and density slice of
[#2122](https://github.com/openonion/connectonion/issues/2122).
Fenced diagrams keep their exact position while empty sections are removed,
including in pages with CRLF line endings.

## Evidence

Two isolated private five-day candidate inits exited successfully. Each mapped
3 projects, finished with 3 project files, wrote the owner and 1 selected
project, and reported 0 source errors. The first a17 run still led with dated
requests despite the new source packet. After tightening the writer guidance,
the second run's project page had 14 headings, 1 `Unknown` in required Facts,
and 3 cited Insight bullets. One joined a real local commit with a repeated
request and said explicitly that a commit does not establish a passing test.
The installed a15 baseline had 17 headings and 7 `Unknown` occurrences. This
is one project across separate runs, not a distributional quality claim. No
private page text is published.

An invented notebook shows the page before and after at desktop and phone
widths in the [visual review](../design-evidence/rem-init-page-ahas-a17/REVIEW.md).
The combined REM, Gmail and review-action unit suite passed 1,402 tests;
203 relevant CLI end-to-end tests and 9
opt-in reader design browser tests passed. The public screenshots use only
synthetic data. The built a17 wheel also installed in a fresh environment and
reported `co 1.9.0a17`; publication still depends on review and CI.

## Remaining work

The real candidate project page still had no internal links; canonical
relationships remain under [#2060](https://github.com/openonion/connectonion/issues/2060).
The owner page still lacked a coherent REM-centered memory recap, tracked by
[#2008](https://github.com/openonion/connectonion/issues/2008). Broader project
types, truthful source interpretation, nightly verified changes, correction,
retrieval and recall still need owner-reviewed acceptance. REM remains a preview.
