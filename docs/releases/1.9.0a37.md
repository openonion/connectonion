# ConnectOnion 1.9.0a37 (preview)

## Install this preview

Stable remains 1.8.10. Install this opt-in preview by exact pin, then follow
the [first-run guide](https://docs.connectonion.com/rem#start):

```bash
python -m pip install --upgrade 'connectonion==1.9.0a37'
co rem open --local
```

## Project purpose stays beside its evidence

When a recent pass rewrites a Project page, its Home card now shows a short
purpose separately from the current finding. The card's **Read the page and
sources** link opens the detail page. On that page, each source already cited
by the purpose has its own link beside the displayed purpose, including on a
phone. Where no current finding was supported, the purpose leads the page
once instead of appearing twice. A long purpose shows three lines initially,
with **Read full purpose** to expand it; Full memory keeps the complete text.
The Home link and desktop
**Hide labelled passages** control also have 44-pixel click targets.

These are reader changes for [#2258](https://github.com/openonion/connectonion/issues/2258)
and [#2270](https://github.com/openonion/connectonion/issues/2270). They do not
rewrite a Project memory, add a source, or validate the existing purpose's
claims.

In one private 90-day notebook, we opened an investigated Project with three
purpose citations. At 375×812, its separate 44×44 source links occupied
y454–498 and the main **View sources** action ended at y797, inside the first
screen. Each of the three links opened a distinct original-source dialog at
375 and 1440 widths. A changed Project card on Home displayed purpose and
finding separately with a route to its page and sources. The desktop privacy
control measured 44 pixels high. An invented longer Project page also kept its
full **View sources** action inside the 375×812 first screen. The sampled pages
had no horizontal overflow or script errors.

## Trial limits

This layout check covered one written Project and its Home card. It did not
review every Project, prove that every cited purpose is accurate, or run a new
model investigation. The current notebook's saved Markdown and archived
source bodies remain unchanged.
