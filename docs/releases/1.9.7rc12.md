# 1.9.7rc12

Release candidate for 1.9.7. Stable remains 1.9.6.

## Keys: the vault, listed and grouped by site (#3327, closes #3326)

- The Keys page lists every key REM files in the Keychain-backed vault, grouped by site (registrable domain).
- Above 30 keys every site starts folded as one row, "<site> · N 条"; search opens only the groups it matches.
  Single-entry sites are one-row groups, sorted with the rest.
- Rows lead with the account; the host shows only where it differs from the group; a column whose values are all
  the same is dropped. On a phone the vault is a two-line list.
- One summary line says what is there ("钥匙串里 N 条 · co 自己用的 M 项"); the empty line shows only when both are empty.
- co's own keys from `~/.co/keys.env` are grouped by service, one row each with 已连接 and a count; settings that
  are not secrets fold under 设置项. Values stay hidden.
- A test pins that no model stage (translation, tagging, deepen, tag pages, investigation queues) reads a `keys/` page.

## Tags as quiet chips (#3313, closes #3308)

- Tags render as small chips on every page kind (person, org, project, skill, decision, knowledge, session): grey
  text, a light fill and a hairline border, about 24px tall, so they read as labels and not as actions.
