# ConnectOnion 1.9.0a20 (preview)

The reader now uses **co rem** in the morning overview, recall prompt,
empty-state guidance and archived-source dialogs. An independent AI role-based
review of rendered pages found these standalone REM labels after the public
URL rename in 1.9.0a19. This is a wording correction; notebook data, citations
and the signed reader protocol are unchanged.

The paired frontend update opens selected-note bookmarks inside the private
reader, including older `/wiki` addresses. The documentation sample retains
its invented, frozen data while using current labels. The trial page keeps
installation instructions clear of the automatic GitHub promotion.

```bash
python -m pip install --upgrade 'connectonion==1.9.0a20'
co rem open --live
```

[Reviewed visual evidence](assets/v1.9.0a20/manifest.yml) uses an invented
notebook at desktop and phone widths. The independent review records its
sampled pages, interaction states and remaining coverage gaps; it does not
claim an all-page pass or participation by a human founder.

This remains an opt-in alpha. Stable remains **1.8.10**; the broader memory
quality gates remain open.
