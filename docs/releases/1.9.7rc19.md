# 1.9.7rc19

Release candidate for 1.9.7. Stable remains 1.9.6.

## Today's night curve tells the truth (#3382, #3379)

- A parked or discarded run draws at 清醒, like a stopped one. A stuck stretch of 15 minutes or more stands on its own,
  captioned 卡住 N 分钟 · 已自动跳过; on rc18 the night's 108 stuck minutes drew as 快速眼动 "改写了 1 页".
- Short stopped runs inside a busy stretch still fold into it; the changed-pages dot sits on the run that changed pages.
- A phone names two levels: the highest the night reached and 深睡, so a stuck night says 清醒.
- When fewer cards are shown than items wait, the title says so: "18 件在等你 · 先看这 4 张".

## WeChat friends' facts card (#3381, #3372)

- A friend not investigated yet no longer shows the raw WeChat id under 账号 or 别名, nor counts it as a known fact;
  最近联系 shows the last chat, marked 微信. The id stays under ⋯ → 这个人 → 复制微信号.
- Before investigation the card says 其余 N 项，调查后补上, folded; 未找到 is said only after investigation. Person,
  organisation and project pages share this card.

## The upgrade backfill reaches upgraded notebooks (#3380, #3368)

- The backfill is versioned. A notebook backfilled by an older release runs it once more on the next page build, so the
  retitle of punctuation-only and one-character names and the first/last-chat fields reach notebooks backfilled on rc17.
  Local only: no model, no network, no new pages.

```bash
python -m pip install --upgrade 'connectonion==1.9.7rc19'
```
