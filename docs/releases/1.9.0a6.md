# 1.9.0a6 — two fixes that should not wait

An opt-in preview of 1.9.0. Stable is 1.8.9. Both fixes were found by running
1.9.0a5 on a copy of the owner's notebook the same day it shipped.

- **`co rem investigate me` no longer stops on one mail.** A Gmail message whose
  date carried no timezone raised an error that ended the whole gather, so your
  own page, and the first run's first page, could not be written. A date without
  a timezone is now read as UTC, and a saved mail whose date cannot be read is
  skipped, not fatal (#2013).
- **Daily maintenance changes pages again.** 1.9.0a5 refused any written page
  that still carried a "not investigated yet" placeholder. That rule was meant for
  a page's own investigation; applied to maintenance, it refused every page not
  yet investigated: one night spent 290k tokens and changed nothing. It now
  applies only to investigation (#2014).

Everything else is as in [1.9.0a5](1.9.0a5.md).

## Install

```sh
python -m pip install --upgrade 'connectonion==1.9.0a6'
co rem status
```

## Known limits

- The owner page can keep stale lines after tidy folds addresses into it
  (#2017); a fresh map can recreate service pages tidy set aside, and free-mail
  domains become org pages (#2018); a daily update can grow a page past its size
  (#2019); an immediate re-investigation re-reads mail it already cited (#2015).
