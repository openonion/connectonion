# 1.9.0a6 — what 1.9.0a5's acceptance run found

An opt-in preview of 1.9.0. Stable is 1.8.9. Everything here was found by
running 1.9.0a5 on a copy of the owner's notebook the same day it shipped.

- **`co rem investigate me` no longer stops on one mail.** A Gmail message whose
  date carried no timezone raised an error that ended the whole gather, so your
  own page, and the first run's first page, could not be written. A date without
  a timezone is now read as UTC, and a saved mail whose date cannot be read is
  skipped, not fatal (#2013).
- **Daily maintenance changes pages again.** 1.9.0a5 refused any written page
  that still carried a "not investigated yet" placeholder. That rule was meant for
  a page's own investigation; applied to maintenance, it refused every page not
  yet investigated: one night spent 290k tokens and changed nothing. It now
  applies only to investigation (#2014).

- **A same-day re-investigation calls no model** when the only mail it finds is
  mail the page already cites; run records now say how long each stage took
  (#2015, #2016).
- **Your own page stays clean after tidy**: the "possibly also yours" lines and
  the map's own history lines are rewritten each map, not appended (#2017).
- **Services and mail providers make no pages**: tidy runs again after every
  map, the service rule catches role desks (portal@, booking@, otp@…) and brands
  in the display name, and yahoo.com.hk, hotmail.co.uk or luma-mail.com never
  become organisations. On the owner's notebook: 8 more services and 2 provider
  "organisations" set aside, nothing deleted (#2018).
- **A page stops growing past its size**: a candidate over 20,000 characters
  that is longer than the page it replaces is refused and kept with the reason;
  the skills keep a page near 15k (#2019).

Everything else is as in [1.9.0a5](1.9.0a5.md).

## Install

```sh
python -m pip install --upgrade 'connectonion==1.9.0a6'
co rem status
```

## Known limits

- A page already over 20,000 characters (the owner's connectonion project page
  is 24.6k) is saved only when an update makes it shorter.
