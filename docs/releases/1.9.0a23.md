# ConnectOnion 1.9.0a23 (preview)

## Reader and contact provenance

Alpha **1.9.0a23** clarifies the origin of last-contact dates on mapped person
pages and fixes mobile table header visibility during horizontal scroll:

- **Map-derived contact dates**: The reader uses the mail map date when the census
  date is empty, labels it as map-derived in the person view and People table,
  and explains why the uninvestigated note has no corresponding fact.
- **Mobile table header visibility**: On 375px phones, scrolling horizontally to
  the Last contact column in the People table keeps the column heading fully
  legible beside the sticky Name column, preventing sticky column overlap (#2205).
- **Mapped-page investigation flow**: The investigation command appears earlier
  on phones with an accessible 44px primary action button.

## Verified fixes

- Resolves #2199: Clarify mapped contact dates in the reader.
- Resolves #2205: Keep the Last contact header visible in the mobile People table.

## What is in this preview

- `connectonion/rem/reader.html`: data fallback for mapped dates, sticky header padding fix on mobile.
- `tests/e2e/cli/test_rem_reader_design_browser.py`: browser regression coverage for mapped date display and 375px sticky table header visibility.
- `docs/blog/2026-10-03-the-date-was-in-the-map.md`: Design Journal record of the change.
