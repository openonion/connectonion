# 1.9.7rc14

Release candidate for 1.9.7. Stable remains 1.9.6.

## Pages, not file paths, in what the owner reads (#3338)

- Owner-facing text no longer shows raw `[[orgs/…md]]` links or bare `people/…md` paths. One function names the
  page by its title, a link where the page exists, in summaries, rendered passages, the relation card basis,
  Today's connection card and the review page (#3318).
- The breadcrumb above a record title is only as wide as its text, so a click on the blank strip beside the title
  no longer jumps to the list (#3319).

## The knowledge graph is alive (#3330, #3309)

- On a computer the graph opens in 3D: a live layout that settles, drag empty space to rotate, the wheel to zoom,
  drag a node and its neighbours follow, hover lights a node and its neighbours, and search flies the camera to the
  page. Four muted kind colours with a legend, hub names in full.
- Three.js and 3d-force-graph are vendored with their licences. The Host serves the 3D engine the first time 3D
  opens; the offline snapshot and the phone never carry it. Nothing loads from a CDN.
- On a phone, with reduced motion, or without WebGL, the 2D map is live too: drag, hover dimming, long press on a
  phone. A 2D/3D switch is in the header where 3D is offered.

## 不是人 for WeChat people (#3341, #3339)

- 不是人 now works on a WeChat-only person page, from the header ⋯ menu (这个人 · 不是人, then 是人 to undo).
- A contact marked not a person is not created by `co rem map` or the night, and an existing page for it leaves
  People. Verified WeChat accounts are filtered from the people map.
- The map summary prints each count with its own names.

python -m pip install --upgrade 'connectonion==1.9.7rc14'
