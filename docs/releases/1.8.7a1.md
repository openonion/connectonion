# 1.8.7a1 — local Wiki preview

Local-only test artifact from Wiki PR #1454, source 080487ba0be61ecc4f9b3abf56a0561fbd261d6f. Not published to PyPI or tagged as a public release.

Includes deterministic people/project/skill maps, canonical templates, isolated investigation candidates and validation, retained skill run evidence, and a local HTML reader. `co wiki open` renders a snapshot; `co wiki start` installs background maintenance and runs a first batch. Opening the reader does not call a model.

Use a separate virtual environment. Existing investigations can still produce factual or citation errors; generated drafts require review. Full-repository tests are not green, and the docs site has not been updated for this local artifact. This build does not claim release readiness.
