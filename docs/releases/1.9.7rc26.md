## Agent email attachments

Send a file with `co email send alice@example.com "Report" "See attached." --attach report.pdf`.
Repeat `--attach` for up to 100 files and 20 MiB total. Use
`co email attachments 123` to find an attachment ID and
`co email download 123 456 --to ./downloads` to save the file with SHA256 verification.
Received mail also supports downloading the original MIME. Sent mail has its
own attachment list and downloads.

Python callers can pass `attachments` to `send_email()` and use
`get_email_attachments()` and `download_email_attachment()`.
Attachment delivery requires the corresponding hosted mail backend.
