# ConnectOnion 1.9.0a29 (preview)

## The next step on a mapped page

After a first `co rem init`, a Person, Project or Skill page may contain only
source metadata. On a phone, its investigate command now appears immediately
after the page lead, before facts and connected context. The copy target is at
least 44px high. A mapped Project lead says how many coding sessions were found
and that its purpose and current state have not yet been investigated. The local
path stays available in Facts and Full memory.

The open phone Browse menu gives **Hide/Show labelled passages** a 44px target
that fits within a 375×812 first screen. The control still hides private
passages and raw source/conversation excerpts, and keeps keyboard focus as its
label changes.

## What was checked

A real, private 90-day map of two connected mailboxes and local coding sessions
completed with no map or mail-body archive failures. An independent role-based
AI founder/marketing/UI review opened Home, People, and one mapped Person,
Project and Skill at 1440×900 and 375×812. On the sampled phone pages, the
investigate buttons moved from below the first screen to y592–636, y691–735
and y638–682; the mapped Project no longer led with a local path. The review
also checked navigation, Full memory and privacy. Focused browser tests passed.
This is sampled mapped-page coverage; it does not assess written memories or
the quality of a model investigation. See [#2227](https://github.com/openonion/connectonion/issues/2227).

Stable remains 1.8.10. Install this opt-in preview by exact pin:

```bash
python -m pip install --upgrade 'connectonion==1.9.0a29'
```
