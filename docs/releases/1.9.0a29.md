# ConnectOnion 1.9.0a29 (preview)

## Full-cohort concurrent onboarding and investigation

ConnectOnion 1.9.0a29 eliminates dry-run capping on onboarding and CLI investigations, making full-cohort memory synthesis fast, parallel, and scalable under real-world mailboxes and repositories:

1. **Full-cohort onboarding by default**: `co rem init` and `co rem investigate` investigate all mapped candidate people, all mapped projects with evidence, and all mapped organizations by default instead of truncating to small sample caps (`--first-*` flags remain available for opt-in dry runs).
2. **10-worker concurrent investigation pool**: `co rem investigate` and onboarding page synthesis run across a `ThreadPoolExecutor(max_workers=workers)` pool (default 10 workers). A notebook with dozens of entities completes end-to-end within 10 to 25 minutes.
3. **Thread-safe mail client sessions**: Mailbox tools isolate API connections per thread (`threading.local()` for Google client sessions) to ensure high-throughput parallel fetching without socket buffer collisions.
4. **Sandboxed task mask isolation**: Parallel runner processes maintain private temporary task masks (`private_task_mask()`) preventing concurrent tasks from clearing active permissions or review staging areas.

Design rationale is documented in `docs/design-decisions/077-concurrent-onboarding-investigation.md`.

These changes apply when `co rem` investigates pages. Stable remains 1.8.10.

## Install this preview

```bash
python -m pip install --upgrade 'connectonion==1.9.0a29'
```
