# ConnectOnion 1.9.0a38 (preview)

## Install this preview

Stable remains 1.8.10. Install this opt-in preview by exact pin, then follow
the [first-run guide](https://docs.connectonion.com/rem#start):

```bash
python -m pip install --upgrade 'connectonion==1.9.0a38'
co rem open --local
```

## Find a passage inside a long archived source

A long Skill run can leave a source dialog with tens of thousands of characters
of archived context. The source was openable, but finding the words behind a
claim meant scrolling through the entire excerpt. Long source dialogs now offer
**Find a word or phrase in this source** and **Next match**. Search highlights
one match in place and jumps to it; the controls stay in reach while reading
the excerpt. Clearing the search restores the same archived text. The input
and Next button remain inside the privacy-hidden original-source section.

When the notebook retained only a prefix, the dialog says that the excerpt is
truncated and that Find searches only the text shown. This change addresses
[#2245](https://github.com/openonion/connectonion/issues/2245). It does not
retrieve omitted content, validate the cited claim, or change saved sources or
memory pages.

## Trial limits

An invented long Skill source was checked in Chrome at desktop and phone widths
with two matches, Next, privacy hide/show, source close and keyboard focus. The
reader tests verify the original excerpt remains intact and that the dialog
has no horizontal overflow. One read-only private Skill page also showed the
control on a retained 40,000-character run part at both widths; the part's
existing scope note was present in the dialog. This layout and interaction
check is not a new model investigation or a validation of the Skill's claims.
