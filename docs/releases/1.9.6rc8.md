# ConnectOnion 1.9.6rc8 (release candidate)

Stable remains **1.9.5**. Python **3.11+**. Dependency floors are unchanged.

## co server

- **Servers are paid by the month, in advance.** `co server new` says the first month is charged now
  and each next month at its start, from your credits, and shows your balance after the first month.
  After create it prints what was charged and the date the server is paid until (#2981).
- **Destroy gives back what you did not use.** `co server destroy` says the unused part of the month is
  refunded before you type the name, and afterwards prints the amount and its credit note
  (`co server invoice <name> <number>` shows it). A server in its grace days has a month that was never
  paid, so there is nothing to refund; the days it ran are owed (#2981).
- **`co server ls`** shows `paid until <date>, renews from credits`, or that the month in progress is
  not paid, and when an owing server stops and is deleted (#2981).
- **1.9.6rc7 cannot create a server.** It described arrears billing ("nothing is charged now"), which
  is not how servers are billed, so the backend refuses it with an upgrade message. Install this one.

16 GB (e2-standard-4) and 32 GB (e2-highmem-4) machines and `--disk 20|100|200|500` are unchanged
from rc7.

## Install after publication

```bash
uv tool install 'connectonion==1.9.6rc8' --with onionwright --prerelease allow --force
```
