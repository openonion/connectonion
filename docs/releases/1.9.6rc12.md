# ConnectOnion 1.9.6rc12 (release candidate)

Stable remains **1.9.5**. Python **3.11+**. The `whatsapp` extra now pins **neonize 0.10.0**.

## WhatsApp

- **A fresh install connects again.** WhatsApp started refusing the client in neonize 0.4.3 at
  connect ("Client outdated (405)"), so a new `connectonion[whatsapp]` install could not link at
  all. The pin is now neonize 0.10.0. An existing session opens as it is; there is nothing to pair
  again. If WhatsApp refuses a client as outdated in future, the listener stops with exit 3 and
  prints the command that upgrades it, and `co whatsapp check` flags an older neonize (#3028).
- **Group history on joining.** When the account is added to a group, the history WhatsApp sends
  with the invitation is read into the inbox, marked as history and never queued as new work
  (#2853).
- **`co whatsapp download <id>`** fetches older pictures and files from stored keys; exit 4 means
  WhatsApp no longer has the file.

## co ai

- Its modes and messages say what they do (#2849).

## Upgrade

```bash
uv tool install --force 'connectonion[whatsapp]==1.9.6rc12' --with onionwright --prerelease allow
co whatsapp listen --restart
```
