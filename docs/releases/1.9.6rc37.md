# 1.9.6rc37

Release candidate for 1.9.6. Stable remains 1.9.5.

## Fixed

- **The night runs again (#3205).** Since 1.9.6rc35, every scheduled REM turn that reached a tag page failed before
  serving its task, with `'str' object has no attribute 'values'`, so the night wrote nothing. The tag-node stage
  (#3140) carries its page as one string, and the native turn read every `before` as `{record: text}`. One reader of
  that field now accepts both shapes, in the source view, the task's inputs and a recovered acceptance.
