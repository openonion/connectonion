# 1.8.9b12 — remove Host-owned watchers

This opt-in preview removes the Host-owned file, timer and push watcher runtime
introduced in 1.8.9b9. Stable remains 1.8.8. The Host no longer starts watch
observers or delivers watch events, and the `co watch` command is removed.

The copyable `watch_events` Agent plugin remains. It accepts a caller-supplied
event callback and inserts claimed events as internal, user-role reminders at
`before_iteration`; an event arriving during a final model call can request
one more iteration through `after_iteration`. Run `co copy watch_events` to
edit the plugin for your Agent.

The plugin works only while an Agent turn is running. A persistent watch that
wakes the Agent's **original session** still needs the session-owned event
runtime tracked in [#1788](https://github.com/openonion/connectonion/issues/1788).
This preview does not provide that replacement. Existing `watch:` entries in
`.co/host.yaml` no longer trigger work; remove them when upgrading. Any
`.co/watch-state.sqlite3` files from b9–b11 remain on disk but are no longer
consumed. Deploy sync still excludes those files so old private observations
are not copied to a server.

The historical [1.8.9b9 notes](1.8.9b9.md) describe the published Host
preview. The removal is [#1806](https://github.com/openonion/connectonion/pull/1806).

## Install

```sh
python -m pip install --upgrade 'connectonion==1.8.9b12'
co --version
```
