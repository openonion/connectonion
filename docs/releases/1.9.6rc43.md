# ConnectOnion 1.9.6rc43 (release candidate)

Stable remains **1.9.5**. Python **3.11+**.

## The Windows logon Host starts, checked on a real Windows 11 PC

- **`co host --background` from an elevated shell** (SSH as an admin, "Run as administrator"): the
  Scheduled Task used to exit at once with no log. Python's `mkdir(mode=0o700)` gives an owner-only
  ACL on Windows, and an elevated shell's files are owned by Administrators, which the task's
  limited token cannot write. The logs folder now inherits the profile's permissions.
- **`run-host.cmd` line endings:** one CR per line instead of CR CR LF.

Checked on a Windows 11 24H2 PC with Python 3.12.10: `co init ./`, `model: claude-code`,
`co host --background` over SSH, then a message over the relay answered by Claude Code in 7 s.
If an earlier candidate already created `~/.co/host-services/<id>` from an elevated shell, run
`co host --uninstall`, delete that folder, and run `co host --background` again.
