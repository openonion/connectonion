# ConnectOnion 1.9.3rc46 (release candidate)

Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

## REM schedules on Linux (#2790)

- `co rem start` on Linux ran the first batch, then raised "Background scheduling is macOS-only"
  at the scheduler install. The worker was never enabled, so `co rem sync --scheduled` never served
  a slot: no Linux notebook ran a night round.
- With `systemctl` available, `co rem start` now writes a user `.service` and `.timer` under
  `~/.config/systemd/user/` that run `co rem --root <notebook> sync --scheduled` every five
  minutes (`Persistent=true`); `sync` decides whether a saved time is due, as with launchd.
  `co rem stop` disables and removes both units, and `co rem status` reads "scheduled with systemd"
  with the next slot.
- The timer runs while you are logged out only with linger on: `loginctl enable-linger`. `start`
  says so when linger is off.
- Verified on a Linux machine: the timer fired every five minutes and each tick exited in about a
  second when no slot was due.
- Windows and Linux without systemd keep the manual path: run `co rem sync` yourself or with cron.
