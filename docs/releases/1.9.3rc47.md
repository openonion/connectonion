# ConnectOnion 1.9.3rc47 (release candidate)

Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

## A new scheduled slot no longer waits on old translations (#2794)

- On the native Codex schedule, each round ends with one translation per changed page. The
  scheduled session finished about one translation per slot and then ended its turn; the next
  slot was offered the same round's next translation. One round could hold every slot for days,
  and `co rem status` showed no new items read.
- A scheduled `co rem next` in a later slot now discards the old round's pending translation,
  records each untranslated page as `skipped` with the reason in `co rem logs <run>`, closes the
  round and starts a new one in the same call. Translation stays best effort, as on the child
  runner.
- Manual `co rem next`, a session that keeps going in the same slot, a translation claimed by a
  live process and investigation portions that resume in the next slot are unchanged.

## Install after publication

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc47'
```
