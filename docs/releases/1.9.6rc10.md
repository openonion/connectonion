# ConnectOnion 1.9.6rc10 (release candidate)

Stable remains **1.9.5**. Python **3.11+**.

## The default model is Gemini 4 Hydrogen

- **`co/gemini-4-hydrogen` is what you get when you name no model**: in `Agent`, `llm_do`, `transcribe`,
  `co ai`, the built-in `plan` and `explore` subagents, and the `.env` that `co init` and `co create`
  write. It is Google's everyday Gemini 4 model for coding and agents: 1,048,576 tokens of context,
  65,536 of output, tool calls, structured output and `reasoning_effort`.
- **What it costs**: $1.50 input / $7.50 output / $0.075 cached per 1M tokens, twice what 3.8 Flash costs
  until 3.8 Flash's promotional price ends on 2027-01-01, then the same.
- **It works on the free $5 credits.** Checked from a freshly created account: a tool-calling Agent and
  an audio transcription both completed.
- **Roll back** by naming `co/gemini-3.8-flash`. For harder reasoning, name `co/gemini-4-carbon` or
  `co/gemini-4-argon` ($2.00 / $10.00 until both double on 2026-12-01).

If you already set `MODEL=` in `.env` or pass `model=`, nothing changes for you.
