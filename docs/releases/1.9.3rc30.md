# ConnectOnion 1.9.3rc30 (release candidate)

Stable remains **1.9.2**; Python **3.11+** and the existing dependency floors are retained.

This candidate fixes ways a REM page could say something its sources do not.

## Citations stay with their own claims

- Related-page cards no longer show the destination page's introduction under the
  origin's citation; a card keeps its own excerpt or shows only its title (#2625).
- A cached translation is reused only when its Sources match the original's, so a
  citation number cannot point to a different source in another language (#2718).
- Quote checks keep word boundaries: "not able" no longer matches "notable" (#2719).

## Overdue stays overdue

A deadline that has passed is counted as overdue, not "due soon", and does not age
out of open threads. Writers close a thread only on evidence of an answer, delivery,
cancellation or withdrawal; a passed date alone settles nothing (#2717).

## A shared name picks no one

When several people share a name, `co rem show`, reader search, morning cards and
inferred links list the candidates or leave the mention unlinked instead of picking
one. Matching is by whole name (#2725).

![Searching a first name two invented people share: the reader lists both with company, role and email](assets/v1.9.3rc30/name-picker-desktop.png)

## Reader

The live reader reads each archived mail file once per process, gives mail
citations their originals first within the page budget, and no longer treats a
weeks-old notebook as a first build (#2716).

## Install after publication

```bash
python -m pip install --upgrade 'connectonion==1.9.3rc30'
```
