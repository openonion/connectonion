# 1.9.6rc33

Release candidate for 1.9.6. Stable remains 1.9.5.

REM: the hourly bug-hunt's fixes (#3165) and the knowledge-graph model the owner approved.

## The knowledge graph (#3140)
- One kind of point, the page; a tag is a link to a page. A tag naming an existing person, organisation or project links
  to it; a tag shared by two or more pages gets its own tag page.
- `co rem tag` tags pages (`co rem tag person "X"` for one). `co rem investigate tag "AI Agent"` reads every page
  carrying the tag and writes or appends its tag page; `co rem investigate tags` does every due one. Kind first, then name;
  `topic` is an alias of `tag`. Both help pages open with a Words glossary; the decision is in docs/cli/rem-naming.md.
- Every page kind shows its tag row; the reader says 知识图谱 / knowledge graph throughout.

## A closed item stays closed (#3174)
- Old done/ignored marks are migrated to the thread's sources, so a night rewording keeps them closed.
- Before each night, a digest of the owner's day (marks, replies, hand-offs, investigations, policy changes, undos) goes
  into the memory every stage reads; a draft re-adding a closed item as open is refused.
- Only new inbound mail from the counterpart reopens an item, and it says why.

## Privacy (#2840, first slice)
- One control in the top bar beside EN/中: 全部显示 / 遮住敏感 (default) / 只看公开. Sensitive passages are curtained; Public
  only removes personal and sensitive text. A phone or remote reader starts at Public only.
- The level covers every place a passage is shown, not only page prose: search results, list rows, Today and the open
  list draw a labelled line the same way, so at the default no sensitive text is legible anywhere. A page's raw
  `Tags:` line is never shown as its summary.

## Sources and citations (#3165 deep hunt)
- A source card never opens empty: the live reader fetches the original the snapshot lacked; link sources offer their page;
  profile sources take a tap on touch devices.
- A citation chip opens its source beside the page and never navigates away.
