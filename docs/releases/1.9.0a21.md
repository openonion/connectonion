# ConnectOnion 1.9.0a21 (preview)

REM now displays **Full memory and sources** on every record without an
expansion click. On phones, the original note appears directly below that
heading and its auxiliary Facts/Usage panels follow the note. Source jumps,
citations and private-mode behavior remain available. Project openings prefer
a lasting `Pattern` finding over a later routine update when both are recorded.

The phone rail now keeps the snapshot and next-pass state visible when Browse
notebook is closed. Search, Browse and the category back link have 44px targets.
The privacy action names its actual scope: it hides labelled passages and raw
source/conversation excerpts, while other page details remain visible.

The first run investigates every eligible person and queued project in its
**current map**, plus related organisations and installed skills, with up to
12 page workers at once. Routine Codex investigation now has a 35-point weekly
budget and stops starting pages when the whole week reaches 90% used. The
first-run 35% target remains advisory: selected pages can finish beyond it
until that safety floor. Existing notebooks that saved the old defaults adopt
the new values; limits explicitly set through `co rem config set` stay as set.
`co rem status` reports
the effective limits. No new model work starts when the current week is already
past the floor.

This preview also improves source retention and claim review for person,
project and skill pages. It preserves more original mail, project and skill
material for citation and keeps unknown outcomes visible instead of turning
them into unsupported current tasks. These changes have focused source checks
and sampled manual page reviews. They do not certify every generated claim.

Install this opt-in preview by pinning its exact version:

```bash
python -m pip install --upgrade 'connectonion==1.9.0a21'
co rem open
```

The [independent AI founder/UI review](../design-evidence/rem-full-memory-review-2026-10-03/REVIEW.md)
records actual sampled page types, interaction states, problems and rechecks;
its public screenshots use invented content. The reviewer was an AI in that
role, not a human founder. A 730-day read-only mail scan found 1,193 raw
addresses absent from the current 90-day map. Broader historical discovery
remains open in [#2176](https://github.com/openonion/connectonion/issues/2176),
and whole-notebook usefulness and source accuracy remain open in
[#2190](https://github.com/openonion/connectonion/issues/2190).

Stable remains **1.8.10**. This release is an opt-in alpha.
