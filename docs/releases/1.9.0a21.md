# ConnectOnion 1.9.0a21 (preview)

**co lark** and **co feishu** now work on a fresh install. The Feishu SDK
(`lark-oapi`) ships with connectonion, so `co lark listen` and `co auth lark`
need nothing else installed first (#2163).

`co auth lark` and `co auth feishu` print the approval link before the QR and
flush it. An agent relaying the link, a tmux pane or a log file now sees it
while the scan is still waiting, so a person away from the machine can approve
from their phone (#2162).

```bash
python -m pip install --upgrade 'connectonion==1.9.0a21'
co auth lark --app-id cli_…
co lark listen
```

This remains an opt-in alpha. Stable remains **1.8.10**.
