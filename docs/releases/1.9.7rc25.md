# 1.9.7rc25

Release candidate for 1.9.7. Stable remains 1.9.6.

## Models follow the work (#3426)

- Levels 1–3 use Luna at medium effort. Translation, extraction and ordinary summaries join tagging at level 1; level 2 handles narrow judgements and plans; level 3 handles routine upkeep, project pages, drafts and orchestration.
- Abstract belongs to level 4, alongside Muse, independent audits, synthesis and owed work: Sol at low. Abstract still writes decisions, knowledge and principles.
- Independent investigation, Enrich and page rendering use Sol at low.
- Old shipped defaults migrate. Explicit model/effort choices, global effort settings, stage overrides and other runners' models are preserved. Help, status and docs agree with runtime routing.

This release validates routing and upgrade behaviour; no live quality or cost improvement is claimed. Audit the next real run before drawing those conclusions.
