# 1.9.7rc25

Release candidate for 1.9.7. Stable remains 1.9.6.

## Models follow the work (#3426)

- Levels 1–3 use Luna at medium effort. Translation, extraction and ordinary summaries join tagging at level 1; level 2 handles narrow judgements and plans; level 3 handles routine upkeep, project pages, drafts and orchestration.
- Abstract belongs to level 4, alongside Muse, independent audits, synthesis and owed work: Sol at low. Abstract still writes decisions, knowledge and principles.
- Independent investigation, Enrich and page rendering use Sol at low.
- Old shipped defaults migrate. Explicit model/effort choices, global effort settings, stage overrides and other runners' models are preserved. Help, status and docs agree with runtime routing.

This release validates routing and upgrade behaviour; no live quality or cost improvement is claimed. Audit the next real run before drawing those conclusions.

## Related-page privacy (#3427, #3425)

This candidate also includes the separately reviewed mainline privacy fix: sensitive relationship reasons are curtained, stray privacy marks in rendered text and tooltips no longer expose the underlying words, and session quotes retain the owner's literal typing. The fix passed 24 new browser cases across desktop/mobile and all privacy modes; see [PR #3427](https://github.com/openonion/connectonion/pull/3427).

[Desktop comparison](assets/v1.9.7rc25/privacy-1440.png) · [Mobile comparison](assets/v1.9.7rc25/privacy-390.png), fictional demo data, reviewed before inclusion.

## Other reviewed mainline fixes included in this candidate

- Obsidian exposes read-only `changes --since ...` and live `show` JSON commands within explicitly selected vault folders (#3064). This is the standalone source CLI; the generic REM caller remains separate.
- A no-change sync no longer points at a run log that was never saved; project batches also bring their linked agenda pages without dropping named project leads (#3055).
- Memory search returns an actionable invalid-pattern error instead of raising when a regex cannot compile (#3255).

## Standing requirements ledger (#3059)

This candidate includes model routing, the related-page privacy fix, standalone Obsidian source commands, sync/agenda lead fixes and invalid-regex handling. All other ledger requirements—stage behaviour and real-night acceptance; Agenda/day planning; Today triage, context and handoff; entity-page and reader design, privacy, graphs, calendars, tags and actions; organisation enrichment; icons and designer review; responsiveness, page/session/source displays; CI duration and background failure reporting; release bug hunts—are **not in this release's change scope** and are not newly claimed complete. The privacy rendering fix is the only Reader change claimed here.
