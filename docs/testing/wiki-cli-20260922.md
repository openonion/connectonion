## Help as a workflow prompt

The overview and group help now share the same task guide. Help teaches the
procedure before the command catalog: first map, discover observed page paths,
select one page, check evidence and remaining unknowns, then explicitly update.
It explains root/JSON flag placement, error codes and the effect of --help.
Init/investigate/sync help add input selection, outcomes, side effects and recovery.
Sync help accurately states the current prerequisite: start authorizes source
access and also installs the background schedule. The Skill points to help for
command usage instead of defining another syntax.

**323 Wiki unit/CLI/process tests passed, 10 browser opt-in skips** after this
change. Wheel build and diff check passed. New regressions assert that workflows
appear before command lists and the main help pages expose recovery and outcomes.
