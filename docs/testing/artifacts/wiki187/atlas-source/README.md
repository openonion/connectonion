# Atlas
Atlas is a local command-line word counter for writers checking draft length.
Run `python3 count.py draft.txt` from this directory; it prints the word count.
Input: UTF-8 text file. Output: word count on stdout; no files changed.
There is no deployed website, hosted service, account system, or sharing feature.
The only implementation is count.py. The sample draft has three words.
The output.txt artifact records the sample command result (3).
The idea of a hosted version is not implemented.
