# Atlas

## What it is

Atlas is a local command-line word counter for writers checking draft length. It reads a text-file path and prints the whitespace-separated word count; the current implementation does not require a hosted service, account, sharing feature, or file-writing step.

## Current state

Atlas is being kept as a local pilot so reviewers can work without a hosted account. There is no hosted release or deployed website. This is the current pilot scope, not a permanent rejection of hosting; a future hosted version remains an open possibility rather than an adopted plan.

The supplied local prototype and sample flow are documented in the existing project material: run `python3 count.py draft.txt` to print the count for a UTF-8 draft.
